BookNest — єдиний UI-набір іконок (99 шт.)

ПІДКЛЮЧЕННЯ
• Спрайт: підключи ui-icons.svg один раз на сторінці, далі —
    <svg width="20" height="20"><use href="#i-home"/></svg>
• Або окремий файл: svg/<id>.svg
• Колір — з CSS color (іконки на currentColor):  .ic{ color: var(--primary); }

ЗВЕДЕНІ ДУБЛІ (стара назва → канонічна)
  i-cal → i-calendar
  i-chev-down/left/right → i-chevron-down/left/right ; i-chevron → i-chevron-down
  i-photo, i-cover → i-image
  i-dots → i-more ; i-stack → i-layers ; i-bars → i-menu
  i-star-line → i-star
  i-alert, i-alert-tri → i-alert-triangle ; i-acircle → i-alert-circle
  i-trend → i-trend-up ; i-spark → i-sparkles
