Dropdown

Меню, що відкривається з тригера: контекстні дії (⋮ у рядку книги), «Сортування», фільтри, меню акаунта. Пункти з іконками, шорткатами, вибором (radio/checkbox) і деструктивними діями. Повна клавіатура й закриття кліком повз.

Анатомія

Статус
trigger
кнопка/іконка з aria-haspopup="menu" + aria-expanded
menu
role="menu"; вирівнювання .end (праворуч)
item
іконка + підпис + опц. шорткат/значення; danger, disabled
checkable
menuitemradio (вибір 1) / menuitemcheckbox (кілька)
label / sep
заголовок секції та роздільник

Варіанти

Натисни тригер. ↑↓ рух, Enter вибір, Esc закрити.

Поведінка

Відкрити
клік по тригеру або ↓ на ньому; фокус переходить у меню
Навігація
↑↓ по пунктах (циклічно), Home/End
Вибір
Enter/клік; radio закриває й оновлює тригер, checkbox лишає відкритим
Закрити
Esc (фокус назад на тригер), клік повз, Tab з меню
Семантика
role="menu" + menuitem/radio/checkbox; тригер — aria-expanded

Використання

Дії (⋮)
контекстні команди над елементом; деструктив — окремо під роздільником
vs Select
Select — вибір значення у формі; Dropdown-radio — швидке перемикання (сортування/вигляд)
vs Modal
проста дія/вибір → меню; складна форма чи підтвердження → модалка
Кількість
багато пунктів — групуй секціями (.dd-label); не вкладай підменю без потреби
