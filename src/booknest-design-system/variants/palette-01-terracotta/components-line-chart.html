Бібліотека компонентів Line Chart

Line Chart

Лінійний графік для трендів у часі: сторінки/книги по місяцях, динаміка читання, порівняння періодів. З осями, hover-тултипом, мультисерією та sparkline.

осі + сіткаhover-тултипмультисеріяsparklinedraw-in

Анатомія

SVG-графік: осі з «гарними» поділками й сіткою → лінія → точки → заливка під лінією → наведенням зʼявляються напрямна й тултип.

Сторінки прочитано · 2025

Наведи на графік

  • Вісь Y — «гарні» поділки (0…макс) + сітка
  • Вісь X — категорії (місяці)
  • Лінія — серія даних, round-joins
  • Точки — вузли; на hover більшають
  • Заливка — мʼякий тінт під лінією
  • Напрямна + тултип — значення під курсором

Варіанти

Мультисерія з легендою та компактний sparkline для stat-карток.
