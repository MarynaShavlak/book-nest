Bar List

Ранжований список зі смужками для розподілів — «топ-жанрів», статистики. Ширина смужки відносна до решти даних (це й відрізняє його від Progress, де база — 100%). Це твій макет v4.

Анатомія

label
назва пункту (ліворуч), --text
value
число або % (праворуч), --ink, табличні цифри
track
доріжка --surface-alt, заокруглена
fill
смужка --primary; ширина = value ÷ база

Дві бази нормалізації + акцент, компакт, порожньо, завантаження.

Топ жанрів

Використання

База
за максимумом — для «топ-N» (лідер повний); за сумою — для часток %
Сортування
завжди за спаданням значення
vs Progress
Bar List — порівняння між пунктами; Progress — завершеність одного (0–100%)
Колір
єдиний --primary; не розфарбовуй кожен рядок по-різному
Доступність
значення — текст; смужка декоративна (aria-hidden) або role="img" з підписом «Жанр: N»
