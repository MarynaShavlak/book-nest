TagInput · поле тегів

Стандартне поле тегів: введені теги стають знімними токенами усередині самого поля. Вводиш, обираєш підказку або тиснеш Enter — додається токен; × прибирає. Для «Обрані теги» в «Додати книгу».

Анатомія

Токени всередині поля + typeahead. Спробуй: вводь «fan»/«dark», обирай зі списку, Enter додає новий, Backspace прибирає останній, × — конкретний.

Натисніть Enter або кому, щоб додати тег.

token
знімна пілюля тега (×) усередині поля, стиль accent-soft
input
ввід після токенів; Enter/«,» додає, Backspace прибирає останній
typeahead
підказки популярних тегів + «створити» для нового
clear
«Очистити все» зʼявляється, коли є теги
клавіатура
↑↓ — підказки, Enter — обрати, Esc — закрити

Стан: вимкнено

Токени видно, але редагувати/прибирати не можна.

Використання

Призначення
довільний набір тегів, які користувач додає/прибирає
Розташування
токени — усередині поля (стандартний патерн), не в окремому блоці
Додавання
Enter / кома / вибір підказки; дублі ігноруються
Видалення
× на токені, Backspace на порожньому вводі, або «Очистити все»
vs Chip-group / Badge
chip-group — вибір із фіксованого набору; badge-tag — лише показ; тут токени вводяться/прибираються
