Action List · Quick Actions

«Швидкі дії» — це не один компонент, а композиція: Card + заголовок + Action List зі рядків-дій (Action Row). Перевикористовуваний атом тут — Action Row; панель лише складає їх.

З чого складається

Card
контейнер: --surface + бордер + --shadow-card + --radius-md (вже в системі)
Заголовок
«Швидкі дії» + опційна акцент-іконка --primary (сприг/zap)
Action List
вертикальний стек рядків; деструктив відділяється роздільником
Action Row (атом)
іконка (--icon) + підпис + опційний trailing: шеврон (відкриває далі) / значення / badge

Який стиль рядка

Обведений (скрін 1) vs м'який (скрін 2–3). Рекомендую м'який.

Обведений
Важче: багато бордерів = «коробки», б'ється з лляною м'якістю.
М'який (рекомендовано)
Легше: фон проявляється на hover/active; структуру тримає картка, не кожен рядок.

Стани Action Row

Trailing-елемент кодує сенс, а не стиль.

Default
Іконка --icon + підпис.
Hover
Фон → --surface-alt.
Active (натиск)
Фон → --accent-soft.
Focus
:focus-visible кільце.
Навігаційний (›)
Шеврон = відкриває пікер/підекран.
Зі значенням
Поточне значення --muted + шеврон.
Деструктив
Іконка й текст --danger; hover --danger-bg.
Disabled
opacity .45, без реакції.

Використання

Trailing = сенс
› лише коли відкриває далі (пікер, підекран); миттєва дія — без шеврона
Значення / badge
показуй поточний стан (Читаю) чи лічильник (12) у trailing
Деструктив
один --danger-рядок, відділений .action-sep унизу
Іконки
лінійні --icon єдиного стилю; кружечки-беджики — лише для stat-card
Семантика
дія → <button>; перехід на сторінку → <a>; відкриває діалог → aria-haspopup
Доступність
нативні Tab/Enter/Space; деструктив бажано з підтвердженням
