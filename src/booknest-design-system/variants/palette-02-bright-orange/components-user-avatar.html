Спробуй

Клікни по аватару або беджику → обери картинку. Завантаження → прев'ю → «Видалити».

Використання

Фолбек
немає фото → ініціали; немає імені → іконка. Завжди є що показати
alt
для фото — ім'я користувача; декоративні (стек) — порожній alt
Редагування
тригер — справжня <button> (беджик) з aria-label, не лише клік по картинці
Завантаження
валідуй тип/розмір (як у Dropzone), показуй спінер, став aria-busy
З підписами
аватар + ім'я + email — готовий варіант .user (рядок / .profile хедер / .compact); сам аватар лишається атомом для списків і стеків
