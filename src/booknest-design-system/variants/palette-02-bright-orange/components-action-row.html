Action Row

Атомний рядок «іконка + підпис + опційний trailing». Один компонент із пропсами, що складається в Action List, меню, налаштування, навігацію. Сам по собі — клікабельний рядок з повним набором станів.

Анатомія

Чотири слоти.

Змінити статусопис (необов'язково)
Читаю
icon
лідер-іконка --icon, 20px (опційно)
label
основний підпис --text
description
другий рядок --muted (опційно)
trailing
слот праворуч: шеврон / значення / badge / будь-який вузол

Leading, trailing, дворядковий, danger, посилання.

Розміри

md за замовчуванням; sm — для щільних меню (на дотик тримай md, ≥44px).

Спробуй

Список із selected: клік робить рядок поточним (як у сайдбарі).
