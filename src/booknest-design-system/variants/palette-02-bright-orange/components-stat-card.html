Stat Card

Картка-показник для дашборда: беджик-іконка + підпис + велике число + допоміжний рядок (звичайний підпис або тренд зі стрілкою). Число — серифом (--ink), беджик — --accent-soft.

Анатомія

Чотири частини; усе на токенах.

badge
кругла іконка-медальйон: фон --accent-soft, іконка --primary (або --icon для варіанту)
label
підпис зверху: --text-secondary, .875rem, medium
value
число: --font-serif bold, --ink, 2rem, табличні цифри
caption / trend
рядок під числом: звичайний --muted або тренд зі стрілкою --success/--danger

Варіанти

Базова, тренди, акцент іконки, клікабельна, компактна, завантаження.
