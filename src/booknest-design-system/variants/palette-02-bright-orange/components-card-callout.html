Картка-порада

М'який блок-підказка з сайдбарів («Корисна порада»): іконка + заголовок + текст + опційна кнопка. Семантичні варіанти (порада / інфо / успіх / увага / помилка) — для будь-яких контекстних повідомлень.

Анатомія

Корисна порада

Додай теги та серії, щоб легше знаходити книги та відстежувати прогрес читання.

ico
іконка в кольорі акценту (легкий фон)
title
короткий заголовок поради
text
пояснення в 1–2 речення
actions
опційна кнопка (м'яка, у кольорі акценту)
close
опційний × — закрити (для тимчасових)

Семантика

Колір = сенс. Фон і акцент беруться з токенів статусів.

Порада

Одна книга може бути в кількох списках одночасно.

До відома

Зміни синхронізуються між пристроями автоматично.

Готово

Книгу додано до бібліотеки зі статусом «Хочу прочитати».

Увага

Видалення списку не видаляє книги з бібліотеки.

Помилка

Не вдалося зберегти зміни. Перевір зʼєднання та спробуй ще раз.

Опції

Без кнопки · можна закрити (натисни ×) · компактна для інлайн-підказок.

Без кнопки

Іноді потрібен лише короткий контекст — без жодних дій.

Імпорт завершено

Перенесено 128 книг. Можна закрити це повідомлення.

Без обкладинки картка показуватиме плейсхолдер.
