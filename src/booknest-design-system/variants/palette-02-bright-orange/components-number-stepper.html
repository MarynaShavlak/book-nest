NumberStepper

Поле-лічильник «− N +» для точного числа: сторінки за день, кількість, ціна. Кнопки змінюють значення кроком, можна вводити вручну; на межах кнопки блокуються. Не плутати зі Stepper (послідовність кроків).

Анатомія

Як у «Оновити прогрес» → «Прочитано сьогодні». Тисни −/+, утримуй для швидкого повтору, або вводь число; ↑↓ теж працюють.
