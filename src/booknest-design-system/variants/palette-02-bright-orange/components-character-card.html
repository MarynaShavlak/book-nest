CharacterCard

Картка персонажа книги: аватар, імʼя, роль, опис із підтримкою спойлерів, риси та дії. Композиція на card-примітиві.

Анатомія

Профіль персонажа книги: аватар-ініціал → імʼя → бейдж ролі → книга → опис → риси → дії (улюблене / меню). Опис підтримує спойлер-блюр.

Е

Елайджа Кравен

Головний герой
з книги «Дім солі та смутку»

Молодший син прибережного роду, що приховує рідкісний дар. Розривається між обовʼязком перед родиною та власним покликанням.

ЗагадковийВідданийВпертий
  • Аватар — ініціал на теплому градієнті (або портрет/іконка)
  • Імʼя — serif
  • Роль — бейдж із тоном
  • Книга — звідки персонаж
  • Опис — коротка довідка (опц. спойлер)
  • Риси — чипи-теги
  • Дії — улюблене ✕ меню
