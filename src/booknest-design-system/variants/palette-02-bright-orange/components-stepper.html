Stepper · Послідовність

Нумерована послідовність зі стрілками — «Порядок читання» книг серії. Просто рекомендований порядок або зі станами, що лягають на прогрес: прочитано · читаю · не прочитано.

Анатомія

Як на ескізі сторінки серії — рекомендований порядок без станів.

Використання

Призначення
порядок/послідовність кроків; у нас — рекомендований порядок книг
Стани
лягають на читання: done = прочитано, current = читаю, upcoming = попереду
Орієнтація
горизонтально для 2–4 кроків; вертикально для довгих/вузьких
Клік
крок може бути лінком на книгу (тоді — фокус і hover)
vs Tabs/Progress
таби перемикають розділи; progress — одна шкала; stepper — впорядкована послідовність зі станами
