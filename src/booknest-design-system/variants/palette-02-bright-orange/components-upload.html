Поведінка

Логіка та валідація.

Відкриття
клік по зоні або кнопці відкриває діалог вибору файлу (<input type="file">)
Drag & drop
перетягування підсвічує зону (dragover); скидання — приймає файл; скидання поза зоною не відкриває файл у браузері
Валідація
лише image/jpeg, image/png; розмір ≤ 5 МБ — інакше стан error з повідомленням
Прогрес
після прийняття — індикатор завантаження (у демо симульований)
Прев'ю
мініатюра (через FileReader), назва, розмір; кнопки «Замінити» / «Видалити»
Tab / Enter
кнопка фокусується й активується з клавіатури; зона має доступну альтернативу через кнопку

Спробуй

Перетягни картинку або клікни. Спробуй не-зображення чи файл >5 МБ — побачиш error.
