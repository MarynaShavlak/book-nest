Button

Уся «кнопкова» мова проєкту в одному компоненті: 7 варіантів за вагою, три розміри, іконки й стани. Усі solid-CTA — на одному --primary (без різнобою відтінків з макетів).

Анатомія / API

variant
primary · secondary · tonal · ghost · danger · danger-ghost · social
size
sm · md (типово) · lg
icon
leading / trailing <svg>, або .icon для лише-іконки
width
.block — на всю ширину
state
hover · active · focus-visible · :disabled · .is-loading

Варіанти за вагою

Наведи / клікни — hover, active й focus живі.

Primary
Головна дія. Один на екран/блок.
Secondary (outline)
Друга за важливістю дія.
Tonal
Тепла filled без ваги primary.
Ghost / text
Низька вага. .accent — теракотовий текст-лінк.
Destructive
Червоний solid для підтвердження; ghost — для danger-зони.
Social
Нейтральна + лого бренду.

Розміри

sm — тулбари · md — типово · lg — герой-CTA

Стани

Hover/active/focus живі на кнопках вище. Нижче — disabled і loading. Усі :hover під guard :not(:disabled).

Disabled
Реальний disabled — hover не спрацьовує.
Loading (клікни)
Спінер по центру, ширина не стрибає, aria-busy.
Focus-visible
Кільце --focus-ring лише з клавіатури.

Правила пар

Як кнопки стоять разом — з твоїх макетів.

Футер модалки
ghost «Скасувати» + primary.
Деструктивне підтвердження
У footer'і delete-модалки.
Hero сторінки
primary + outline.
Empty-state
Бібліотека поки порожня
один primary + text-дія.
Авторизація
або

Використання

Один primary
не більше однієї головної кнопки на екран/блок; решта — secondary/ghost
Колір primary
завжди --primary; не вживай яскраво-помаранчевий/коричневий з ескізів — це був різнобій
Disabled
усі :hover під :not(:disabled); стан — реальний disabled
Loading
.is-loading + aria-busy; блокує кліки, ширину тримає
Icon-only
обов'язковий aria-label; деструктив не лише кольором — додай іконку/підтвердження
Семантика
дія → <button>, навігація → <a class="btn">
