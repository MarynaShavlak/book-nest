ChipGroup

Група вибору з пілюль-чипів. Два режими: одиночний (radiogroup — рівно один обраний, як «Статус володіння») і множинний (перемикачі — як жанри). Обраний чип залитий --chip-bg, решта — обведені.

Стани чипа

Один елемент у різних станах.

Default
Обведений: --border + --surface.
Hover
Бордер → --accent-border, фон → --surface-alt.
Selected
Залитий --chip-bg, текст --chip-fg.
Focus
:focus-visible — кільце --focus-ring.
Disabled
opacity .45, не фокусується/не обирається.
З іконкою
Опційна іконка зліва (16px).

Поведінка

Залежить від режиму.

Одиночний
role="radiogroup", чипи role="radio" + aria-checked; рівно один обраний
Множинний
role="group", чипи — кнопки aria-pressed; перемикаються незалежно
Клавіатура (одиночний)
←→/↑↓ рух і вибір (roving tabindex, з обгортанням), Home/End — край
Клавіатура (множинний)
Tab по чипах, Space/Enter — перемкнути
Disabled
чип пропускається при навігації й не реагує на вибір

Спробуй

Одиночний — стрілками; множинний — Tab + Space.

Використання

Який режим
взаємовиключні варіанти (статус) → одиночний; ярлики/жанри → множинний
Іконки
опційні, для статусів — корисні; для довгих списків (жанри) краще без них
Розмір
клас .chips--sm для щільніших груп
Звідки колір
обраний — --chip-bg/--chip-fg; це не «теги з ×» (ті — в мультиселекті)
