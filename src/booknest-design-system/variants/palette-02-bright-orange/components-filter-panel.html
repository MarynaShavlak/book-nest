Filter panel

Попап фільтрів під кнопкою «Фільтри»: групи (статус, жанр, вік, автор, видавництво, мова) + «Тільки улюблені», «Скинути всі» та «Показати результати» з лічильником. Селекти — кастомні (у темі BookNest), без стандартного синього списку браузера.

Спробуй

Відкрий «Фільтри», розкрий будь-який селект — список оформлений у темі (теплий ховер, обране з галочкою). Зміни значення — лічильник і бейдж оновлюються.

Пошук книги, автора, видавництва…

Використання

Селект

під кнопкою «Фільтри»; закривається кліком назовні, ×, Esc
Активність
