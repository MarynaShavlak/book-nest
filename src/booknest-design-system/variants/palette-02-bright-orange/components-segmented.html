Segmented Control

Злита доріжка для 2–4 взаємовиключних варіантів — «Соло книга / Частина серії», «Серія завершена / ще виходить», перемикач вигляду. Активний сегмент позначає повзунок-thumb, що ковзає. Компактна альтернатива до ChipGroup.

Анатомія

track
доріжка --field + бордер, заокруглена --radius-full
thumb
повзунок активного сегмента: --surface + --shadow-card, ковзає
segment
кнопка-опція: --muted, активна → --ink; опційна іконка

Варіанти

Усі — живі: клікни або стрілками. Thumb ковзає під різну ширину сегментів.

2 сегменти
Типовий бінарний вибір.
3 сегменти
Фільтр-перемикач. Тримай ≤4 сегменти.
З іконками
Перемикач вигляду.
Accent (теплий)
Thumb --accent-soft — як на твоєму макеті.
На всю ширину
.block — рівні сегменти на ширину контейнера.
Розміри
sm / md.

Стани

Знімки (статичні, без thumb).

Активний / неактивний
Hover (неактивний)
Неактивний світлішає до --text.
Focus
:focus-visible кільце.
Disabled (увесь)
Disabled (сегмент)
Окремий сегмент можна вимкнути.

Поведінка

Семантика
role="radiogroup", сегменти role="radio" + aria-checked
Клавіатура
←→/↑↓ рух і вибір (roving tabindex, з обгортанням), Home/End — край
Thumb
ковзає до активного сегмента; ширину міряє по сегменту (різні підписи — ок); перераховується на resize
vs ChipGroup
Segmented — 2–4 взаємовиключних у злитій доріжці (компактний тумблер); ChipGroup — окремі пілюлі, багато опцій та/або мультивибір
