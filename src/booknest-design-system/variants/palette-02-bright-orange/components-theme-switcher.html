Theme switcher

Вибір вигляду в налаштуваннях: режим (Світла / Темна / Системна) та акцентний колір. Усе застосовується наживо до цієї сторінки — обери режим або колір і дивись.

Анатомія

Секція «Зовнішній вид» зі сторінки налаштувань.

Зовнішній вид

Застосовано наживо до сторінки
режим
Світла / Темна / Системна — картки-перемикачі (radiogroup)
Системна
слухає prefers-color-scheme і змінюється з ОС
акцент
палітра кружечків; обраний — ✓ + кільце
застосування
акцент перефарбовує токени (--primary, --accent-soft …)

Компактні форми

Той самий перемикач у стиснутому вигляді — усі синхронні між собою.

Segmented
Toggle (світла ↔ темна)
Іконка

Використання

Три режими
Світла / Темна / Системна; «Системна» поважає налаштування ОС
Збереження
вибір зберігається; застосовується до першого кадру (без блимання)
Акцент
один колір на весь застосунок; решта тонів — похідні через color-mix
Форма
картки/segmented — у налаштуваннях; іконка/toggle — у шапці
Доступність
radiogroup для режиму й кольору; role="switch" для toggle
