Rating

Зіркова оцінка на 5 балів із півкроком (0.5). Один теплий --rating замість різнобою кольорів; порожні зірки — контур; точне дробове заповнення для середніх (4.2 → 84%).

Анатомія / API

4.8(12 541)
зірки
шар порожніх (--rating-empty, контур) + шар заповнених (--rating), обрізаний по ширині
value
0–5, дріб; ширина заливки = value/5 (півкрок для вводу)
число
серифне для зведеного, опційне для бейджа
count
опційна к-сть оцінок, --muted
