# Feature: Delete Book

## 1. Purpose

Фіча **Delete Book** дозволяє користувачу видалити книгу зі своєї бібліотеки.

Видалення книги має бути підтверджене користувачем, оскільки дія є destructive і впливає на пов’язані дані книги.

---

## 2. Delete type

Для BookNest рекомендовано використовувати **soft delete**.

Це означає, що книга не видаляється фізично з бази одразу, а отримує поле:

```ts
deletedAt: Date
```

Після цього книга:

* зникає з **Моєї бібліотеки**;
* не показується в пошуку;
* не враховується в summary cards;
* не показується в списках, черзі, улюблених, позичених, книгах у дорозі;
* не враховується в основній статистиці.

---

## 3. Entry points

Користувач може видалити книгу з таких місць:

| Entry point       | UI                         |
| ----------------- | -------------------------- |
| Book card         | action menu `...`          |
| Book list row     | action menu `...`          |
| Book details page | button / action menu       |
| Bulk actions      | mass delete selected books |

---

## 4. Delete confirmation modal

Книга не має видалятися одразу після кліку на action **Видалити**.

Потрібно показати confirmation modal.

### Modal content

```text
Видалити книгу?

Книга зникне з бібліотеки, списків, черги читання та пов’язаних розділів.
```

### Actions

```text
Скасувати
Видалити
```

### Behavior

* **Скасувати** закриває modal без змін;
* **Видалити** підтверджує видалення;
* під час видалення кнопка має бути disabled;
* після успішного видалення modal закривається.

---

## 5. Delete logic

Після підтвердження видалення система має:

1. знайти книгу поточного користувача;
2. перевірити, що книга існує і не видалена;
3. встановити `deletedAt`;
4. прибрати книгу з основних списків відображення;
5. оновити UI;
6. показати success message.

Example:

```ts
book.deletedAt = new Date();
```

---

## 6. Related data behavior

Після soft delete книга не має показуватися у пов’язаних розділах.

| Related data     | Behavior                                                      |
| ---------------- | ------------------------------------------------------------- |
| Favorites        | книга більше не показується в улюблених                       |
| Reading queue    | книга прибирається з активної черги                           |
| Custom lists     | книга не показується у списках                                |
| Series           | книга не показується у деталях серії                          |
| Notes            | нотатки залишаються в базі, але не показуються в основному UI |
| Quotes           | цитати залишаються в базі, але не показуються в основному UI  |
| Characters       | персонажі залишаються в базі, але не показуються              |
| Borrowed books   | книга зникає з активного списку позичених                     |
| Books in transit | книга зникає з активного списку книг у дорозі                 |
| Books to buy     | книга зникає зі списку книг до покупки                        |

---

## 7. UI behavior after delete

Після успішного видалення:

* книга зникає зі списку;
* summary cards оновлюються;
* active filters залишаються без змін;
* search залишається без змін;
* sorting залишається без змін;
* view mode залишається без змін.

Якщо книга була останньою у результатах пошуку або фільтрів, потрібно показати відповідний state:

* empty library;
* no search results;
* no filtered results.

---

## 8. Success message

Після успішного видалення показати toast:

```text
Книгу видалено
```

Optional action:

```text
Скасувати
```

Якщо undo реалізований, система має прибрати `deletedAt`.

---

## 9. Error behavior

Якщо книгу не вдалося видалити, показати error message:

```text
Не вдалося видалити книгу
```

Behavior:

* книга залишається в UI;
* modal не закривається або показується error state;
* користувач може повторити спробу.

---

## 10. Permissions

Користувач може видаляти тільки власні книги.

Система не має дозволяти видалення книги, яка належить іншому користувачу.

---

## 11. API requirements

Recommended endpoint:

```http
DELETE /books/:bookId
```

Recommended behavior:

* endpoint виконує soft delete;
* фізично запис не видаляється;
* backend перевіряє `userId`;
* якщо книга не знайдена або не належить користувачу, повертається error.

Possible responses:

```text
200 OK
404 Not Found
403 Forbidden
500 Internal Server Error
```

---

## 12. Acceptance Criteria

* Користувач може відкрити delete action з book card.
* Користувач може відкрити delete action зі сторінки деталей книги.
* Книга не видаляється без confirmation modal.
* Користувач може скасувати видалення.
* Після підтвердження книга отримує `deletedAt`.
* Видалена книга не показується в **Моїй бібліотеці**.
* Видалена книга не показується в search results.
* Видалена книга не враховується в summary cards.
* Видалена книга не показується в улюблених, списках, черзі, серіях і пов’язаних розділах.
* Користувач може видаляти тільки власні книги.
* Якщо видалення не вдалося, користувач бачить error message.
