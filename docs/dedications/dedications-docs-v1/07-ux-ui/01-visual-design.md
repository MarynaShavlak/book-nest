# Visual Design

## Design goal

Сторінка має виглядати як тепла колекція книжкових записок.

Ключові слова:

```txt
cozy
paper-like
warm
bookish
minimal
soft
personal
```

---

## Color palette

Main accent:

```txt
#9A5D36
```

Additional colors:

```txt
cream background
warm beige cards
soft terracotta accents
muted gold sparkles
brown text
light peach active areas
```

---

## Decorative elements

Можна використовувати:

- тонкі гілочки;
- маленьку іконку відкритої книги;
- декоративні лапки;
- паперову текстуру;
- мʼякі тіні;
- легкі corner ornaments.

Не перевантажувати сторінку декором.

---

## Typography

Title:

- serif font;
- large size;
- warm dark brown color.

Body:

- readable sans-serif;
- normal line-height;
- text preview max 3–5 lines.

Dedication text:

- can use italic style in preview;
- full modal can use larger serif/italic style.

---

## Card visual

Card should look like:

```txt
book cover + small paper note
```

Recommended:

- border radius 18–22px;
- cream background;
- thin border;
- subtle shadow;
- small action icons at bottom.
