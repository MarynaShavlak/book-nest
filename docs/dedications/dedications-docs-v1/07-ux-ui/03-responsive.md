# Responsive Behavior

## Desktop

```txt
Sidebar fixed width: 260px
Main content: flexible
Right sidebar: 300–340px
Grid: 3 columns
```

---

## Tablet

```txt
Sidebar may be collapsed
Right sidebar moves below main content
Grid: 2 columns
```

---

## Mobile

```txt
No permanent sidebar
Header compact
Search full width
Filters horizontally scrollable
Grid: 1 column
Right sidebar blocks appear after cards
```

---

## Mobile card

Mobile card can become horizontal:

```txt
[small cover] [title + author + dedication preview]
[action row]
```

or remain vertical if covers are important.

Recommended mobile:

```txt
horizontal compact card
```

---

## Modal on mobile

Use full-screen drawer or bottom sheet.

Avoid small centered modal on mobile.
