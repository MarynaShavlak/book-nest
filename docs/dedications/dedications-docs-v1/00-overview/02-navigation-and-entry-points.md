# Navigation and Entry Points

## Sidebar entry

Сторінка має бути доступна з основного sidebar.

Рекомендована назва пункту:

```txt
Присвяти
```

Рекомендована іконка:

- перо;
- маленька листівка;
- відкрита книга з листочком;
- декоративні лапки;
- handwritten note icon.

---

## Recommended sidebar position

```txt
Головна
Усі книги
Моя бібліотека
Хочу прочитати
Прочитано
В дорозі
Присвяти
Цитати
Серії
Автори
Жанри
Статистика
```

Сторінка **“Присвяти”** має бути поруч із **“Цитати”**, бо обидві сторінки працюють із текстовими фрагментами, але мають різну природу.

---

## Routes

```txt
/dedications
/dedications/:dedicationId
```

Для MVP достатньо тільки:

```txt
/dedications
```

Детальну сторінку `/dedications/:dedicationId` можна замінити modal / drawer.

---

## Entry points from other features

### Book Details Page

Якщо книга має присвяту, на деталях книги можна показувати блок:

```txt
Присвята автора
```

Дії:

- показати більше;
- скопіювати;
- додати в улюблені;
- перейти до сторінки “Присвяти”.

### Create / Edit Book Form

У формі книги має бути поле:

```txt
Присвята автора
```

Це поле необовʼязкове.

### Global Search

Присвяти можуть потрапляти в глобальний пошук як окремий тип результату.
