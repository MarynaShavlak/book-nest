# Right Sidebar

Right sidebar робить сторінку більш інформативною та атмосферною.

## 1. Statistics card

Title:

```txt
Статистика
```

Fields:

```txt
Усього присвят        24
Улюблених             5
З прочитаних книг     18
З непрочитаних книг   6
Найчастіший жанр      Романтика
Найбільше присвят від автора  Сара Джіо
```

---

## 2. Quick filters card

Title:

```txt
Швидкі фільтри
```

Buttons:

```txt
Лише з прочитаних
Лише з непрочитаних
Улюблені присвяти
Без улюблених
```

Click on quick filter має синхронізуватися з основними фільтрами.

---

## 3. Decorative quote card

Це не контент користувача, а декоративний UI-блок.

Text:

```txt
Кожна присвята — це маленька історія про когось важливого.
```

Design:

- beige paper card;
- decorative quotes;
- маленька гілочка або відкрита книга;
- без кнопок.

---

## 4. Helper CTA card

Title:

```txt
Не знайшли свою присвяту?
```

Text:

```txt
Додайте її на сторінці редагування книги, і вона зʼявиться тут.
```

CTA:

```txt
Додати книгу
```

Alternative CTA:

```txt
Перейти до всіх книг
```

---

## Mobile behavior

На mobile right sidebar переміщується під основний список.

Порядок:

```txt
Header
Search
Filters
Cards
Statistics
Quick filters
Helper CTA
```
