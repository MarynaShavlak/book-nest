# Pagination and View Modes

## Default view

Для сторінки присвят найкраще підходить grid view.

Картки мають виглядати як маленькі книжкові notes з обкладинкою та текстом присвяти.

---

## Pagination

Full version може підтримувати pagination:

```txt
< 1 2 3 ... 8 >
```

Recommended page size:

```txt
12 items per page
```

---

## Load more alternative

Для MVP можна використати кнопку:

```txt
Показати ще
```

---

## Empty after filters

Якщо фільтр або пошук не має результатів:

```txt
За цими параметрами присвят не знайдено.
Спробуйте змінити пошук або очистити фільтри.
```

CTA:

```txt
Очистити фільтри
```
