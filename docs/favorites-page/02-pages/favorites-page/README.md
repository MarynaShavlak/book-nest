# Favorites Page

Сторінка `/favorites` показує тільки книги поточного користувача з `isFavorite = true`.

Рекомендований порядок реалізації:

1. route/access;
2. page header;
3. toolbar;
4. search;
5. filters;
6. sorting/view mode;
7. cards/rows;
8. remove from favorites;
9. states;
10. pagination/load more.
