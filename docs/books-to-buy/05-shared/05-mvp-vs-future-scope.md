# MVP vs Future Scope

## Included in MVP

- `want_to_buy` ownership status.
- Books to Buy Page.
- List of wishlist books.
- Store links.
- Add/Edit/Delete Store Link.
- Best offer calculation.
- Mark as Bought.
- Remove from Shopping List.
- Go to Book Details.
- Search.
- Filters.
- Sorting.
- Right sidebar statistics.
- Best offers block.
- Loading, empty and error states.
- Delivery integration if Delivery module is enabled.

## Not included in MVP

- Automatic price parsing.
- Automatic price updates.
- Price history.
- Discount notifications.
- Stock tracking.
- Public/shared wishlist.
- Bulk mark as bought.
- Drag-and-drop priority.
- Multiple books in one order.
- Receipt upload.
- Payment/refund logic.
- Currency conversion.

## Future improvements

- Price history.
- Discount alerts.
- Wishlist budget.
- Manual priority.
- Store recommendations.
- Purchase notes.
- Group by store/publisher/genre.
- Export wishlist.
- Shared wishlist.
- Bulk actions.
