# Responsive Rules

## Desktop

- Main list and right sidebar.
- Toolbar in one row.
- Store links visible in rows.
- Primary actions visible.
- Secondary actions in More menu.

## Tablet

- Sidebar can move below the list.
- Filters can collapse into popover/drawer.
- Store links can wrap.

## Mobile

- One-column layout.
- Search full width.
- Filters in bottom sheet/drawer.
- Book rows become cards.
- Store links stack vertically.
- Actions collapse into menu.
- Long URLs/tracking-like values must wrap or truncate.

## Accessibility

- Buttons have clear labels.
- External links indicate they open outside the app.
- Destructive/status-changing actions require confirmation.
- Keyboard navigation works for modals and menus.
