# Loading, Error and Empty States

## Page loading

Show skeletons for:

- toolbar;
- book rows;
- sidebar.

## Empty page

Title:

```text
Список покупок порожній
```

Text:

```text
Додайте книгу зі статусом “Хочу купити”, і вона з’явиться тут.
```

Actions:

```text
Додати книгу
Перейти до бібліотеки
```

## Empty search

Title:

```text
Нічого не знайдено
```

Action:

```text
Очистити фільтри
```

## Row no links

```text
Посилання на магазини ще не додані
```

Action:

```text
Додати посилання
```

## Error

```text
Не вдалося завантажити книги до покупки
```

Action:

```text
Спробувати ще раз
```

## Action error

Keep modal open, preserve entered values and show error.
