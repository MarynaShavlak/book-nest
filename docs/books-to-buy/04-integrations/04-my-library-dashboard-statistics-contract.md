# My Library, Dashboard and Statistics Contract

## My Library

My Library can filter books by ownership status:

```text
Хочу купити
```

A `want_to_buy` book appears in both:

- My Library;
- Books to Buy Page.

## Dashboard

Dashboard can show wishlist widget:

```text
14 книг у списку покупок
Найвигідніша пропозиція: 380 грн
```

Action:

```text
Перейти до книг до покупки
```

## Statistics

General app statistics can include:

- wishlist count;
- approximate wishlist value;
- most common stores;
- most common publishers;
- average best offer price.

Important:

```text
Wishlist value is estimated planned spending, not actual spending.
```

Actual spending belongs to Delivery Expense Statistics.
