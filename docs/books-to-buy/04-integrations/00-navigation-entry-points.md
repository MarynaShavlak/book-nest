# Navigation and Entry Points

## Sidebar

Sidebar should include:

```text
Книги до покупки
```

Recommended icon:

```text
shopping cart / tag / bookmark
```

## Entry points to Books to Buy

- Sidebar item.
- Dashboard wishlist widget.
- My Library ownership filter.
- Book Details purchase block.
- Empty state action after setting book to `want_to_buy`.

## Entry points from Books to Buy

- Book Details.
- Create Book Form.
- Books in Transit Page.
- My Library.
- Store external URL.

## Route

```text
/books-to-buy
```
