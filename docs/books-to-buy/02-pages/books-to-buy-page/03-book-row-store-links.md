# Book Row and Store Links

## Row structure

Recommended row:

```text
[Index] [Cover] [Book info] [Store links] [Actions] [More menu]
```

## Book info

Show:

- cover or placeholder;
- title;
- author;
- publisher;
- badge `Хочу купити`;
- genre/tags if space allows.

## Store links area

Show all saved links for the book or first 2–3 links with expand behavior.

Each link shows:

- store name;
- price and currency if available;
- external link icon;
- best offer highlight if this link has the lowest price.

Example:

```text
Yakaboo — 420 грн
Книгарня Є — 389 грн
+ Додати посилання
```

## No links state inside row

If no links exist:

```text
Посилання на магазини ще не додані
```

Action:

```text
Додати посилання
```

## Main row actions

Visible actions:

- Позначити як куплену;
- Перейти до книги.

Secondary actions:

- Додати посилання;
- Позначити як “В дорозі”;
- Прибрати зі списку покупок.

## External link action

Click on external link icon opens store URL in a new tab.

It does not change any data.
