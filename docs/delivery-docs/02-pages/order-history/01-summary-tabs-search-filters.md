# Order History: Summary, Tabs, Search, Filters

## Summary cards

Recommended cards:

| Card | Description |
| --- | --- |
| Усього замовлень | all delivery records count |
| Активні | `ordered` + `in_transit` |
| Отримані | `received` |
| Скасовані | `cancelled` |
| Загальна сума | total price by selected scope |

Cancelled orders should not be included in main amount by default unless selected.

## Tabs

```text
Усі
Активні
Отримані
Скасовані
```

Default tab:

```text
Усі
```

## Search

Search by:

- book title;
- author;
- store name;
- order number;
- tracking number;
- delivery service;
- note;
- cancel reason.

## Filters

Recommended filters:

```text
Status
Store
Delivery service
Date range
Price range
Currency
Has tracking number
Has tracking URL
```

## Sorting

Recommended:

```text
Newest orders
Oldest orders
Recently updated
By status
By store
By price
By book title
```
