# MVP vs Future Scope

## MVP

- Delivery record model.
- Stored delivery statuses.
- Calculated UI statuses.
- Mark Book as In Transit.
- Edit Delivery Info.
- Mark as Received.
- Bulk Mark as Received.
- Cancel Delivery Order.
- Books in Transit page.
- Delivery Order History page.
- Delivery Expense Statistics page.
- Books to Buy integration.
- Book Form delivery section.
- Book Details delivery block contract.

## Future improvements

- Automatic tracking by carrier API.
- Multiple books in one order.
- Multiple packages for one book.
- Refund tracking.
- Payment status.
- Store integrations.
- Currency conversion.
- Delivery notifications/reminders.
- Reorder cancelled order action.
- Export delivery history.
- Advanced analytics by store/service/month.
