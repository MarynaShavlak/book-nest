# Responsive Rules

## Desktop

Use:

```text
main content + right sidebar
```

Cards can be grid or list.

Filters can be inline.

## Tablet

Use:

```text
main content full width
sidebar below or collapsible
```

Cards can be two columns.

## Mobile

Use:

```text
single-column layout
filters in drawer/popover
summary cards horizontally scrollable or stacked
charts stacked below content
```

## Action placement

On mobile, move secondary actions into card menu:

```text
...
```

Primary action should remain visible:

```text
Позначити як отриману
```

## Modals

On mobile, delivery modals can become full-screen sheets.
