# Loading, Error, Empty States

## Loading

Use skeletons for:

- summary cards;
- delivery cards;
- charts;
- sidebars.

## Error

Every page should show:

```text
Не вдалося завантажити дані
```

Action:

```text
Спробувати ще раз
```

## Empty active deliveries

```text
У вас немає книг в дорозі
```

Action:

```text
Перейти до книг, які хочу купити
```

## Empty order history

```text
Історія замовлень порожня
```

## Empty expense statistics

```text
Поки немає даних про витрати на доставки
```

## No price data

```text
Додайте ціну до замовлень, щоб побачити статистику витрат
```

## Empty filtered result

```text
Нічого не знайдено за вибраними фільтрами
```

Action:

```text
Скинути фільтри
```
