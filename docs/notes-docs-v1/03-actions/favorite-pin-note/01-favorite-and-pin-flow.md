# Favorite and Pin Note Flow

## Favorite note

### Add to favorite

1. Користувач натискає heart / bookmark icon.
2. Нотатка стає улюбленою.
3. Іконка переходить в active state.
4. Нотатка з’являється у фільтрі `Улюблені`.

Toast:

```text
Нотатку додано в улюблені.
```

### Remove from favorite

1. Користувач повторно натискає active heart / bookmark icon.
2. Нотатка прибирається з улюблених.
3. Іконка стає inactive.

Toast:

```text
Нотатку прибрано з улюблених.
```

## Pin note

### Pin

1. Користувач натискає pin icon або action `Закріпити`.
2. Нотатка стає закріпленою.
3. Нотатка піднімається у верхню частину списку.

Toast:

```text
Нотатку закріплено.
```

### Unpin

1. Користувач натискає active pin icon або action `Відкріпити`.
2. Нотатка повертається у звичайне сортування.

Toast:

```text
Нотатку відкріплено.
```

## Independent state rule

Favorite і pinned — незалежні стани.

Нотатка може бути:

- тільки улюбленою;
- тільки закріпленою;
- одночасно улюбленою і закріпленою;
- жодною з них.
