# Delete Note Flow

## Entry points

Видалення доступне з:

- картки нотатки на сторінці книги;
- картки нотатки на сторінці серії;
- картки нотатки на сторінці `Нотатки`.

## Flow

1. Користувач відкриває menu actions нотатки.
2. Натискає `Видалити`.
3. Відкривається confirm modal.
4. Користувач підтверджує видалення.
5. Нотатка зникає зі списку.
6. Лічильники нотаток оновлюються.

## Confirm modal

Title:

```text
Видалити нотатку?
```

Description:

```text
Цю дію неможливо скасувати. Нотатка буде видалена з вашого архіву.
```

Buttons:

- Скасувати
- Видалити

## Success message

```text
Нотатку видалено.
```

## Error message

```text
Не вдалося видалити нотатку. Спробуйте ще раз.
```
