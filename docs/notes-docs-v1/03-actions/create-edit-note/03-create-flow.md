# Create Note Flow

## From Book Details

1. Користувач відкриває сторінку книги.
2. У блоці `Мої нотатки` натискає `Додати нотатку`.
3. Відкривається modal `Додати нотатку`.
4. У preview показується книга.
5. Користувач вводить текст нотатки.
6. За потреби обирає категорію.
7. За потреби вказує власну категорію.
8. За потреби вказує розділ.
9. За потреби вказує сторінку.
10. За потреби позначає спойлер / улюблену / закріплену.
11. Натискає `Зберегти нотатку`.
12. Нотатка з’являється в блоці книги.
13. Кількість нотаток оновлюється.

## From Series Details

1. Користувач відкриває сторінку серії.
2. У блоці `Нотатки до серії` натискає `Додати нотатку`.
3. Відкривається modal.
4. У preview показується серія.
5. Далі flow такий самий, як для книги.

## From All Notes Page

1. Користувач відкриває сторінку `Нотатки`.
2. Натискає `Додати нотатку`.
3. Спочатку обирає тип сутності: книга або серія.
4. Потім обирає конкретну книгу або серію.
5. Відкривається modal `Додати нотатку`.
6. У preview показується обрана сутність.
7. Після збереження нотатка з’являється в загальному списку.

## Success message

```text
Нотатку додано.
```

## Error message

```text
Не вдалося зберегти нотатку. Спробуйте ще раз.
```
