# Create / Edit Note Modal — Form Fields

## Text note

Label:

```text
Текст нотатки *
```

Placeholder:

```text
Запишіть свої думки, враження або важливі ідеї...
```

Limit:

```text
0 / 5000
```

Validation:

- required;
- max 5000 characters.

## Category

Label:

```text
Категорія
```

Placeholder:

```text
Оберіть категорію
```

Options:

- Загальне враження
- Персонажі
- Сюжет
- Атмосфера
- Світобудова
- Тема / ідея
- Стиль автора
- Для рецензії
- Питання
- Інше

Category is optional.

## Custom category

Показувати тільки якщо category = `Інше`.

Label:

```text
Власна категорія
```

Placeholder:

```text
Наприклад: любовна лінія, фінал, улюблений момент...
```

## Spoiler

Checkbox / switch:

```text
Це спойлер
```

Helper text:

```text
Позначте, якщо нотатка містить важливі сюжетні деталі.
```

## Favorite

Checkbox / switch:

```text
Додати нотатку в улюблені
```

Helper text:

```text
Улюблені нотатки можна швидко знайти через фільтр.
```

## Pinned

Checkbox / switch:

```text
Закріпити нотатку
```

Helper text:

```text
Закріплені нотатки показуються першими.
```
