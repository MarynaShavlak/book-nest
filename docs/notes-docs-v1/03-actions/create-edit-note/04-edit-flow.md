# Edit Note Flow

## Entry points

Користувач може редагувати нотатку з:

- блоку нотаток на сторінці книги;
- блоку нотаток на сторінці серії;
- загальної сторінки `Нотатки`.

## Flow

1. Користувач натискає `Редагувати` у меню нотатки.
2. Відкривається modal `Редагувати нотатку`.
3. Форма заповнюється поточними значеннями.
4. Користувач змінює потрібні поля.
5. Натискає `Зберегти зміни`.
6. Нотатка оновлюється у списку.

## Editable fields

- текст;
- категорія;
- власна категорія;
- розділ;
- сторінка;
- spoiler state;
- favorite state;
- pinned state.

## Success message

```text
Нотатку оновлено.
```

## Error message

```text
Не вдалося оновити нотатку. Спробуйте ще раз.
```

## Important behavior

Редагування нотатки не повинно змінювати пов’язану книгу або серію, якщо користувач явно не має окремої дії `Перенести нотатку`.

Для MVP перенесення нотатки між сутностями не потрібне.
