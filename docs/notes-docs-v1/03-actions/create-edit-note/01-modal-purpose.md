# Create / Edit Note Modal — Purpose

## Modal titles

Create:

```text
Додати нотатку
```

Edit:

```text
Редагувати нотатку
```

## Purpose

Модалка дозволяє створити або змінити нотатку до книги або серії.

## Preview area

У верхній частині модалки показується preview сутності, до якої створюється нотатка.

Для книги:

- обкладинка;
- назва книги;
- автор;
- короткий статус або жанр, якщо потрібно.

Для серії:

- series visual / placeholder;
- назва серії;
- автор / автори;
- кількість книг, якщо доступно.

## Important behavior

Якщо користувач створює нотатку з детальної сторінки книги, сутність уже відома.

Якщо користувач створює нотатку зі сторінки `Нотатки`, він спочатку має обрати:

- тип сутності;
- конкретну книгу або серію.
