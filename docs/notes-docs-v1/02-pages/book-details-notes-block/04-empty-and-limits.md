# Book Details Notes Block — Empty States and Limits

## No notes

```text
У вас ще немає нотаток до цієї книги.

Записуйте думки, питання, ідеї для рецензій або важливі деталі, до яких хочеться повернутися.

[Додати першу нотатку]
```

## Only spoiler notes

Якщо всі нотатки в блоці — спойлерні, показувати їх прихованими.

Не відкривати спойлери автоматично.

## Too many notes

Якщо нотаток багато, у блоці книги показувати обмежену кількість і кнопку:

```text
Переглянути всі нотатки книги (24)
```

## Long note text

У preview-картці довгий текст можна обрізати.

Рекомендовано:

- показати 3–5 рядків;
- додати `Показати більше`;
- повний текст доступний у modal / drawer або на сторінці всіх нотаток.

## Character counter

У формі створення ліміт 5000 символів.

У картці не потрібно показувати counter.
