# Book Details Notes Block — Note Card

## Card content

На картці нотатки в блоці книги показувати:

- category chip, якщо обрана категорія;
- custom category, якщо обрано `Інше`;
- pinned icon, якщо нотатка закріплена;
- favorite icon, якщо нотатка улюблена;
- spoiler badge, якщо нотатка зі спойлером;
- текст нотатки або spoiler placeholder;
- розділ / сторінку, якщо вказані;
- дату створення або оновлення;
- actions menu.

## Normal note example

```text
[Персонажі] [♡] [⋯]

Здається, тут героїня вперше чесно визнає, що боїться змін.

Розділ 8 · стор. 146
12 лип. 2026
```

## Spoiler note example

```text
[Сюжет] [Спойлер] [♡] [⋯]

Ця нотатка містить спойлер.
[Показати спойлер]

Розділ 24 · стор. 311
```

After click:

```text
[Сюжет] [Спойлер] [♡] [⋯]

Текст спойлерної нотатки...
[Приховати спойлер]
```

## Pinned note example

```text
[📌 Закріплено] [Для рецензії] [♥] [⋯]

Головна думка для майбутнього відгуку...
```

## Actions menu

Actions:

- Редагувати
- Закріпити / Відкріпити
- Додати нотатку в улюблені / Прибрати нотатку з улюблених
- Видалити

## Important UI copy

Не використовувати неоднозначні формулювання:

- `Додати в улюблені` — погано, бо неясно, що саме.
- `Додати нотатку в улюблені` — добре.
