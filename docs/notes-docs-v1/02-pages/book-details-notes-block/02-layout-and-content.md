# Book Details Notes Block — Layout and Content

## Default layout

Блок складається з:

1. Header.
2. Short helper text або subtitle.
3. Список нотаток.
4. Actions.

Example:

```text
Мої нотатки · 4
Думки, питання та враження, які ви зберегли під час читання.

[+ Додати нотатку]

[Note card]
[Note card]
[Note card]

[Переглянути всі нотатки книги]
```

## Notes preview limit

На детальній сторінці книги не треба показувати всі нотатки, якщо їх багато.

Рекомендовано показувати:

- закріплені нотатки;
- потім 2–3 останні нотатки.

Якщо нотаток більше:

```text
Переглянути всі нотатки книги (12)
```

## Sorting inside block

1. Закріплені нотатки зверху.
2. Далі за сторінкою, якщо є сторінки.
3. Далі нові спочатку.

## Empty state

Якщо нотаток немає:

```text
У вас ще немає нотаток до цієї книги.
Записуйте думки про персонажів, сюжетні повороти, атмосферу або ідеї для майбутньої рецензії.

[Додати першу нотатку]
```

## Visual style

- теплий card background;
- м’які border і shadow;
- category chip;
- spoiler badge;
- pinned icon;
- favorite icon;
- декоративна гілочка або маленька іконка пера / нотатки в header.
