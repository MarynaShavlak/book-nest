# Book Details Notes Block — Purpose

## Purpose

Блок `Мої нотатки` на детальній сторінці книги дозволяє користувачу швидко працювати з нотатками саме цієї книги.

Це основне місце створення нотаток до книги.

## User can

- побачити кількість нотаток до книги;
- переглянути останні / закріплені нотатки;
- додати нотатку;
- редагувати нотатку;
- видалити нотатку;
- позначити нотатку як улюблену;
- закріпити нотатку;
- позначити нотатку як спойлер;
- показати / приховати спойлер;
- перейти до повного списку нотаток книги.

## Placement

Рекомендовано розміщувати блок нижче основного опису книги або поруч із блоками `Цитати`, `Персонажі`, `Хронологія`, якщо такі є.

Для сторінки книги можна використовувати назву:

```text
Мої нотатки
```

або

```text
Нотатки до книги
```

## Header

Header блоку:

```text
Мої нотатки · 4
```

Actions:

- `+ Додати нотатку`
- `Переглянути всі`
