# All Notes Page — Sidebar

## Purpose

Right sidebar допомагає швидко оцінити стан нотаток і перейти до корисних фільтрів.

## Statistics block

Title:

```text
Статистика
```

Items:

- Усього нотаток
- До книг
- До серій
- Без спойлерів
- Зі спойлерами
- Улюблених
- Закріплених
- Книг з нотатками
- Серій з нотатками

## Quick filters block

Title:

```text
Швидкі фільтри
```

Buttons:

- Лише улюблені
- Лише закріплені
- Без спойлерів
- Зі спойлерами
- Для рецензії
- Питання

## Tip block

```text
Порада
Закріплюйте найважливіші нотатки, щоб швидко повернутися до головних думок перед рецензією або наступною книгою серії.
```

## Quick action block

```text
Не знайшли потрібну нотатку?
Скористайтесь пошуком або додайте нову нотатку до книги чи серії.

[+ Додати нотатку]
```
