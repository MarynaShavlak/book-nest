# All Notes Page — Note Card

## Card content

На загальній сторінці нотаток картка має показувати:

- тип сутності: книга або серія;
- обкладинку книги або series visual / placeholder;
- назву книги або серії;
- автора книги або автора/авторів серії, якщо є;
- category chip;
- pinned icon;
- favorite icon;
- spoiler badge;
- текст нотатки або spoiler placeholder;
- розділ;
- сторінку;
- дату створення / оновлення;
- action `До книги` або `До серії`;
- menu actions.

## Book note example

```text
[Book cover]
Один світанок влітку
Шарі Лоу

[Персонажі] [♡] [⋯]

Ця сцена добре показує, як героїня боїться змін.

Розділ 8 · стор. 146

До книги →
```

## Series note example

```text
[Series visual]
Легендарні лиходії
Серія

[Світобудова] [📌] [♥] [⋯]

Перед наступною частиною згадати, як працює магічний договір.

Книга 2, фінал

До серії →
```

## Spoiler state

Якщо нотатка спойлерна, текст приховувати.

```text
Ця нотатка містить спойлер.
[Показати спойлер]
```

## Card actions

- Редагувати
- Закріпити / Відкріпити
- Додати нотатку в улюблені / Прибрати нотатку з улюблених
- Видалити
- До книги / До серії
