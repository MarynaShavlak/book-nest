# All Notes Page — Purpose

## Route

Recommended route:

```text
/notes
```

## Title

```text
Нотатки
```

## Subtitle

```text
Усі ваші думки, враження, питання та ідеї до книг і серій.
```

## Purpose

Сторінка `Нотатки` — це загальний архів усіх нотаток користувача.

Вона потрібна для:

- перегляду всіх нотаток;
- пошуку;
- фільтрації;
- сортування;
- швидкого переходу до пов’язаної книги або серії;
- редагування;
- видалення;
- роботи з улюбленими та закріпленими нотатками.

## What to show

На сторінці показуються нотатки до:

- книг;
- серій.

У майбутньому сторінка має також підтримувати нотатки до інших сутностей.
