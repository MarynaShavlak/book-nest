# All Notes Page — Filters and Sorting

## Quick filters

Показати tabs/chips:

- Усі
- Без спойлерів
- Зі спойлерами
- Улюблені
- Закріплені

## Entity filters

- Усі сутності
- Книги
- Серії

У майбутньому:

- Персонажі
- Автори
- Цитати
- Хронологія

## Category filter

Select:

```text
Категорія
```

Options:

- Усі категорії
- Загальне враження
- Персонажі
- Сюжет
- Атмосфера
- Світобудова
- Тема / ідея
- Стиль автора
- Для рецензії
- Питання
- Інше
- Власні категорії, якщо є

## Additional filters

- Зі сторінкою
- Без сторінки
- З розділом
- Без розділу
- Нещодавно оновлені

## Sorting

Options:

- Нові спочатку
- Старі спочатку
- Нещодавно оновлені
- За назвою книги / серії
- За категорією
- За сторінкою
- Спочатку закріплені
- Спочатку улюблені
- Спочатку без спойлерів
- Спочатку зі спойлерами

## Default

Default sorting:

```text
Спочатку закріплені → нові спочатку
```
