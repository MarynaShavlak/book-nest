# Notes Implementation Order

## Stage 1 — Domain rules and shared contracts

1. Узгодити, що нотатка може бути прив’язана до книги або серії.
2. Закласти масштабовану логіку прив’язки до сутностей.
3. Узгодити список категорій нотаток.
4. Узгодити правила spoiler / favorite / pinned.
5. Узгодити validation rules.

## Stage 2 — Create / Edit Note Modal

1. Додати modal `Додати нотатку`.
2. Додати preview пов’язаної сутності.
3. Додати textarea тексту нотатки з лімітом 5000 символів.
4. Додати category select.
5. Додати поле власної категорії для `Інше`.
6. Додати опційне поле `Розділ`.
7. Додати опційне поле `Сторінка`.
8. Додати switches / checkboxes:
   - `Це спойлер`;
   - `Додати в улюблені`;
   - `Закріпити нотатку`.
9. Додати create flow.
10. Додати edit flow.

## Stage 3 — Book Details integration

1. Додати блок `Мої нотатки` на детальну сторінку книги.
2. Показувати кількість нотаток до книги.
3. Показувати останні або закріплені нотатки.
4. Додати кнопку `Додати нотатку`.
5. Додати show / hide spoiler.
6. Додати favorite / pin actions.
7. Додати edit / delete actions.
8. Додати кнопку `Переглянути всі нотатки книги`.

## Stage 4 — Series Details integration

1. Додати блок `Нотатки до серії` на сторінку деталей серії.
2. Використати той самий UI нотаток, що й для книги.
3. У preview модалки показувати серію, а не книгу.
4. Для нотаток серії не показувати поле сторінки як основне, але дозволити його заповнити опційно, якщо користувач хоче прив’язати думку до конкретної частини / сторінки.

## Stage 5 — All Notes Page

1. Додати сторінку `Нотатки`.
2. Показувати всі нотатки користувача.
3. Додати пошук.
4. Додати фільтри:
   - усі;
   - без спойлерів;
   - зі спойлерами;
   - улюблені;
   - закріплені;
   - за категорією;
   - книги;
   - серії.
5. Додати сортування.
6. Додати sidebar зі статистикою.

## Stage 6 — QA and polish

1. Перевірити, що кілька нотаток до однієї книги не перезаписують одна одну.
2. Перевірити spoiler behavior.
3. Перевірити favorite behavior.
4. Перевірити pinned sorting.
5. Перевірити пошук і фільтри.
6. Перевірити mobile layout.
7. Перевірити empty / loading / error states.
