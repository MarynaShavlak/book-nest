# Notes Page Visual Reference

Цей файл зарезервований для UI-референсів сторінки нотаток і модалки створення нотатки.

Рекомендований стиль:

- cozy BookNest style;
- кремовий фон;
- теракотові акценти `#9A5D36`;
- округлі картки;
- м’які тіні;
- serif headings;
- декоративні гілочки;
- маленькі іконки для category / spoiler / favorite / pinned.

## Suggested page sections

- Header: `Нотатки`.
- Subtitle: `Усі ваші думки, враження, питання та ідеї до книг і серій.`
- Search input.
- Quick filters.
- Category filter.
- Entity type filter.
- Notes grid.
- Right sidebar with statistics.
