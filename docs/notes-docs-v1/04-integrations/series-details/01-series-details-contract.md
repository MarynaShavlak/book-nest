# Series Details Integration Contract

## Purpose

Детальна сторінка серії має показувати нотатки, прив’язані до всієї серії.

Це корисно для довгих циклів, де потрібно пам’ятати загальні події, арки персонажів, правила світу або питання перед наступною книгою.

## UI block

Block title:

```text
Нотатки до серії
```

## Must show

- кількість нотаток до серії;
- preview нотаток;
- кнопку `Додати нотатку`;
- кнопку `Переглянути всі нотатки серії`, якщо нотаток більше ніж показано в preview;
- empty state.

## Create note behavior

Коли користувач створює нотатку зі сторінки серії:

- related entity = поточна серія;
- у preview модалки показується серія;
- користувач не обирає книгу;
- поля `Розділ` і `Сторінка` залишаються опційними.

## Recommended placeholders for series notes

Chapter placeholder can be adjusted:

```text
Наприклад: Книга 2, фінал або Арка Діани
```

Page placeholder can remain:

```text
Наприклад: 87
```

## Sorting

1. Закріплені зверху.
2. Далі нещодавно оновлені.
3. Далі нові спочатку.

## Empty state

```text
У вас ще немає нотаток до цієї серії.
Зберігайте важливі деталі, арки персонажів, питання та події, які варто згадати перед наступною книгою.

[Додати першу нотатку]
```
