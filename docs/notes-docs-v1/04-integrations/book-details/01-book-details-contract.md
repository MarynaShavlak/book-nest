# Book Details Integration Contract

## Purpose

Детальна сторінка книги має показувати нотатки, прив’язані до цієї книги.

## UI block

Block title:

```text
Мої нотатки
```

Alternative:

```text
Нотатки до книги
```

## Must show

- кількість нотаток до книги;
- список preview нотаток;
- кнопку `Додати нотатку`;
- кнопку `Переглянути всі нотатки книги`, якщо нотаток більше ніж показано в preview;
- empty state, якщо нотаток немає.

## Note preview sorting

1. Закріплені зверху.
2. Далі за сторінкою, якщо є сторінки.
3. Далі нові спочатку.

## Actions

Користувач може:

- додати нотатку;
- редагувати нотатку;
- видалити нотатку;
- показати / приховати спойлер;
- додати нотатку в улюблені;
- прибрати нотатку з улюблених;
- закріпити нотатку;
- відкріпити нотатку.

## Related entity

Коли нотатка створюється з Book Details, related entity має бути поточна книга.

Користувач не має додатково обирати книгу в модалці.

## Book update behavior

Додавання, редагування або видалення нотатки не повинно змінювати дані книги, окрім похідних лічильників у UI.

## Empty state

```text
У вас ще немає нотаток до цієї книги.
Записуйте думки про персонажів, сюжетні повороти, атмосферу або ідеї для майбутньої рецензії.

[Додати першу нотатку]
```
