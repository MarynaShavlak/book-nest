# Validation and Permissions

## Text validation

Поле `Текст нотатки` обов’язкове.

Rules:

- Мінімум: 1 символ після trim.
- Максимум: 5000 символів.
- Показувати counter: `0 / 5000`.
- Якщо перевищено ліміт — блокувати збереження або показувати помилку.

Error message:

```text
Нотатка не може бути довшою за 5000 символів.
```

Empty text error:

```text
Введіть текст нотатки.
```

## Category validation

Категорія необов’язкова.

Якщо обрано `Інше`, поле власної категорії може бути:

- необов’язковим у MVP;
- або рекомендованим через helper text.

Якщо команда хоче зробити його обов’язковим для `Інше`, error message:

```text
Вкажіть власну категорію або оберіть іншу категорію.
```

## Chapter validation

- Необов’язкове поле.
- Максимум рекомендовано 100 символів.

Error message:

```text
Назва розділу занадто довга.
```

## Page validation

- Необов’язкове поле.
- Якщо заповнене — має бути позитивним числом.
- Не дозволяти 0 або від’ємні значення.

Error message:

```text
Номер сторінки має бути більшим за 0.
```

## Permissions

Користувач може бачити, створювати, редагувати та видаляти тільки власні нотатки.

Користувач не може редагувати нотатки іншого користувача.

## Delete confirmation

Видалення нотатки має проходити через confirm modal.

Text:

```text
Видалити нотатку?
Цю дію неможливо скасувати.
```

Actions:

- Скасувати
- Видалити
