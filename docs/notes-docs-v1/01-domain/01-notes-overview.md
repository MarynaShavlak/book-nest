# Notes Overview

## Purpose

Фіча **Нотатки** дозволяє користувачу зберігати власні думки, враження, питання, спостереження, ідеї для рецензій та важливі деталі під час читання.

Нотатки не замінюють цитати. Цитата — це текст із книги. Нотатка — це думка користувача.

## Primary use cases

- Записати враження від сцени.
- Зафіксувати думку про персонажа.
- Записати питання до сюжету.
- Зберегти ідею для майбутньої рецензії.
- Позначити важливий момент зі спойлером.
- Повернутися до конкретної сторінки або розділу.
- Зберегти загальну думку про серію.
- Закріпити найважливішу нотатку зверху.
- Додати нотатку в улюблені.

## Important distinction from quotes

Нотатка може посилатися на конкретне місце книги через розділ або сторінку, але не є цитатою. Якщо користувач хоче зберегти дослівний уривок із книги — це фіча `Цитати`. Якщо користувач хоче зберегти власну думку — це фіча `Нотатки`.

## Multiple notes rule

Користувач може створювати багато нотаток до однієї книги або серії.

Приклад:

- нотатка про атмосферу;
- нотатка про персонажа;
- спойлерна нотатка про фінал;
- нотатка для рецензії;
- питання до сюжету.

Створення нової нотатки не повинно замінювати попередню.
