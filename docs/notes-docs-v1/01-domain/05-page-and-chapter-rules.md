# Page and Chapter Rules

## Decision

Нотатка може мати опційні поля:

- `Розділ`;
- `Сторінка`.

Обидва поля необов’язкові.

## Why chapter is useful

Поле `Розділ` корисне для:

- електронних книг, де сторінки можуть відрізнятися залежно від пристрою;
- аудіокниг;
- книг без стабільної пагінації;
- серійних нотаток, де користувач хоче вказати частину або розділ;
- збереження контексту без точного номера сторінки.

## Why page is useful

Поле `Сторінка` корисне для:

- паперових книг;
- повернення до конкретного місця;
- написання рецензії;
- аналізу сюжету;
- спойлерних нотаток;
- нотаток за ходом читання.

## Validation rules

### Chapter

- Необов’язкове поле.
- Може бути текстом.
- Максимальна довжина рекомендовано до 100 символів.
- Приклади: `Розділ III`, `Глава 12`, `Частина друга`, `Фінал`, `Книга 2`.

### Page

- Необов’язкове поле.
- Має бути числом, якщо заповнене.
- Значення має бути більше 0.
- Якщо відома кількість сторінок у книзі, UI може попереджати, якщо номер сторінки більший за кількість сторінок, але не обов’язково блокувати збереження.

## Display rules

Якщо вказані і розділ, і сторінка:

```text
Розділ 12 · стор. 146
```

Якщо вказаний тільки розділ:

```text
Розділ 12
```

Якщо вказана тільки сторінка:

```text
стор. 146
```

Якщо нічого не вказано, рядок не показується.

## Series notes nuance

Для нотаток до серії поле `Сторінка` менш важливе, але його можна залишити опційним, щоб не створювати окрему форму.

Для серії поле `Розділ` може використовуватись ширше:

- `Книга 1`;
- `Книга 2, фінал`;
- `Перед третьою частиною`;
- `Арка Діани`.
