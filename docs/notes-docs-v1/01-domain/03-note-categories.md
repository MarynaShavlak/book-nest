# Note Categories

## Decision

Для нотаток використовуються **категорії**, а не теги.

Теги книги вже існують у BookNest і описують книгу як сутність. Категорії нотаток описують зміст конкретної думки користувача.

## Critical rule

Категорії нотаток не є тегами книги.

- Вибір категорії нотатки не додає тег до книги.
- Додавання тегу до книги не змінює категорії нотаток.
- Категорія нотатки використовується тільки для організації нотаток.

## Category behavior

Користувач може обрати одну категорію для нотатки.

Категорія необов’язкова. Якщо користувач не хоче класифікувати нотатку, він може залишити поле порожнім.

## Predefined categories

Рекомендований список категорій:

1. Загальне враження
2. Персонажі
3. Сюжет
4. Атмосфера
5. Світобудова
6. Тема / ідея
7. Стиль автора
8. Для рецензії
9. Питання
10. Інше

## Category descriptions

### Загальне враження

Для загальних думок про книгу, сцену або серію.

### Персонажі

Для думок про героїв, мотивацію, розвиток, конфлікти, стосунки.

### Сюжет

Для думок про події, повороти, конфлікти, темп і структуру історії.

### Атмосфера

Для настрою, емоцій, вайбу, напруги, відчуття світу.

### Світобудова

Для магії, правил світу, політики, локацій, рас, богів, систем.

### Тема / ідея

Для сенсів, філософії, головних думок, моральних питань.

### Стиль автора

Для мови, темпу, структури, оповіді, авторського голосу.

### Для рецензії

Для нотаток, які користувач хоче використати у майбутньому відгуку.

### Питання

Для незрозумілих моментів або теорій, до яких хочеться повернутися.

### Інше

Для випадків, коли жодна категорія не підходить.

## Other category behavior

Якщо користувач обрав `Інше`, UI має показати додаткове поле:

```text
Власна категорія
```

Placeholder:

```text
Наприклад: любовна лінія, фінал, улюблений момент...
```

Власна категорія необов’язкова, але бажана, якщо обрано `Інше`.

## UI display

На картці нотатки категорія показується як маленький chip / badge.

Приклади:

- `Персонажі`
- `Для рецензії`
- `Питання`
- `Інше: любовна лінія`

## Filtering

На сторінці `Нотатки` має бути фільтр за категорією.

Для MVP достатньо:

- select `Категорія`;
- опція `Усі категорії`;
- список predefined категорій;
- додатково показувати власні категорії, якщо вони є.
