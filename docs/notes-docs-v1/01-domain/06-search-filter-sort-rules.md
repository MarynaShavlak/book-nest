# Search, Filter and Sort Rules

## Search scope

Пошук на сторінці `Нотатки` має працювати за:

- текстом нотатки;
- назвою пов’язаної книги;
- назвою пов’язаної серії;
- автором книги;
- категорією нотатки;
- власною категорією;
- розділом;
- номером сторінки.

## Quick filters

Рекомендовані швидкі фільтри:

- Усі
- Без спойлерів
- Зі спойлерами
- Улюблені
- Закріплені

## Advanced filters

Додаткові фільтри:

- Тип сутності: `Книги`, `Серії`, у майбутньому `Персонажі`, `Автори`.
- Категорія.
- Книга.
- Серія.
- Зі сторінкою.
- Без сторінки.
- З розділом.
- Без розділу.
- Нещодавно оновлені.

## Sorting options

Рекомендовані варіанти сортування:

- Нові спочатку.
- Старі спочатку.
- Нещодавно оновлені.
- За назвою книги / серії.
- За автором книги.
- За категорією.
- За сторінкою.
- Спочатку закріплені.
- Спочатку улюблені.
- Спочатку без спойлерів.
- Спочатку зі спойлерами.

## Default sorting

На сторінці `Нотатки` рекомендовано:

1. Закріплені зверху.
2. Далі нові спочатку.

На детальній сторінці книги рекомендовано:

1. Закріплені зверху.
2. Далі за сторінкою, якщо сторінки вказані.
3. Далі нові спочатку.

На детальній сторінці серії рекомендовано:

1. Закріплені зверху.
2. Далі нещодавно оновлені або нові спочатку.
