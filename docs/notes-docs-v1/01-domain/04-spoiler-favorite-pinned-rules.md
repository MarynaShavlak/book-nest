# Spoiler, Favorite and Pinned Rules

## Spoiler notes

Нотатка може бути позначена як спойлер.

Якщо нотатка є спойлером:

- текст нотатки прихований у списку;
- показується badge `Спойлер` або `Зі спойлером`;
- замість тексту показується кнопка `Показати спойлер`;
- після натискання текст відкривається;
- користувач може натиснути `Приховати спойлер`.

## Spoiler visibility is local UI state

Відкриття спойлера в UI не змінює саму нотатку. Це тимчасовий стан перегляду.

Якщо користувач оновив сторінку, спойлер знову може бути прихованим.

## Favorite notes

Користувач може позначити нотатку як улюблену.

Favorite behavior:

- на картці є heart / bookmark icon;
- якщо нотатка улюблена, іконка активна;
- повторний клік прибирає нотатку з улюблених;
- є фільтр `Улюблені`;
- у правому sidebar можна показати кількість улюблених нотаток.

## Critical rule: note favorite is independent

Улюблена нотатка не є улюбленою книгою або серією.

- Додавання нотатки в улюблені не змінює favorite status книги.
- Додавання нотатки в улюблені не змінює favorite status серії.
- Додавання книги в улюблені не робить її нотатки улюбленими.
- Додавання серії в улюблені не робить її нотатки улюбленими.

UI copy має бути точним:

- `Додати нотатку в улюблені`
- `Прибрати нотатку з улюблених`

Не використовувати неоднозначний текст `Додати в улюблені`, якщо поруч є дії для книги або серії.

## Pinned notes

Користувач може закріпити нотатку.

Pinned behavior:

- на картці є pin icon;
- якщо нотатка закріплена, вона показується вище за інші нотатки;
- закріплені нотатки сортуються між собою за поточним сортуванням або за датою оновлення;
- повторний клік знімає закріплення;
- є фільтр `Закріплені`;
- у блоці книги або серії закріплені нотатки показуються першими.

## Critical rule: pinned does not change created date

Закріплення нотатки не змінює дату створення нотатки.

Якщо потрібно оновити дату редагування при зміні pinned state — це рішення бекенду, але UI не повинен показувати закріплення як нову нотатку, якщо змінився тільки pin state.

## Combined states

Нотатка може одночасно бути:

- спойлером;
- улюбленою;
- закріпленою.

Ці стани незалежні.

Приклад:

```text
Закріплена · Улюблена · Спойлер
```

У такому випадку текст все одно має бути прихований, доки користувач не натисне `Показати спойлер`.
