# Acceptance Criteria

## Book Details

- На детальній сторінці книги є блок `Мої нотатки` або `Нотатки до книги`.
- Користувач бачить кількість нотаток до книги.
- Користувач може додати нотатку до книги.
- Користувач може створити кілька нотаток до однієї книги.
- Створення нової нотатки не перезаписує існуючі.
- Користувач може редагувати нотатку.
- Користувач може видалити нотатку.
- Користувач може позначити нотатку як спойлер.
- Спойлерна нотатка прихована до натискання `Показати спойлер`.
- Користувач може приховати відкритий спойлер.
- Користувач може додати нотатку в улюблені.
- Улюблена нотатка має активний visual state.
- Користувач може прибрати нотатку з улюблених.
- Користувач може закріпити нотатку.
- Закріплена нотатка показується вище інших нотаток.
- Користувач може відкріпити нотатку.

## Series Details

- На детальній сторінці серії є блок `Нотатки до серії`.
- Користувач може додати нотатку до серії.
- Користувач може створити кілька нотаток до однієї серії.
- Нотатка до серії не дублюється автоматично в книги серії.
- Нотатка до книги не стає автоматично нотаткою серії.

## Create / Edit Modal

- Modal показує preview пов’язаної книги або серії.
- Поле тексту нотатки обов’язкове.
- Максимальний обсяг тексту — 5000 символів.
- Є counter `0 / 5000`.
- Є поле `Категорія`.
- Категорія необов’язкова.
- Якщо обрано `Інше`, показується поле `Власна категорія`.
- Є опційне поле `Розділ`.
- Є опційне поле `Сторінка`.
- Сторінка має бути позитивним числом, якщо заповнена.
- Є checkbox / switch `Це спойлер`.
- Є checkbox / switch `Додати нотатку в улюблені`.
- Є checkbox / switch `Закріпити нотатку`.

## All Notes Page

- Користувач бачить всі свої нотатки.
- Користувач може шукати нотатки.
- Пошук працює за текстом нотатки, назвою книги/серії, категорією, розділом і сторінкою.
- Користувач може фільтрувати нотатки за spoiler state.
- Користувач може фільтрувати улюблені нотатки.
- Користувач може фільтрувати закріплені нотатки.
- Користувач може фільтрувати за категорією.
- Користувач може фільтрувати за типом сутності: книги / серії.
- Користувач може сортувати нотатки.
- Користувач може перейти з нотатки до пов’язаної книги або серії.

## Independence rules

- Улюблена нотатка не робить книгу улюбленою.
- Улюблена нотатка не робить серію улюбленою.
- Улюблена книга не робить нотатки улюбленими.
- Улюблена серія не робить нотатки улюбленими.
- Закріплення нотатки впливає тільки на порядок нотаток.
- Категорія нотатки не додає тег до книги.
