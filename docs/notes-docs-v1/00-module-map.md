# Notes Module Map

## Feature name

**Нотатки**

## Goal

Дати користувачу можливість зберігати власні думки, враження, спостереження, питання, ідеї для рецензій та важливі деталі, які виникають під час читання книги або серії.

## Main entities in UI

Документація не фіксує бекенд-модель. Бекенд сам визначає структуру даних. На рівні продукту важливо, щоб нотатка підтримувала такі бізнес-поля:

- текст нотатки;
- прив’язку до сутності: книга або серія у першій версії;
- можливість масштабування на інші сутності в майбутньому;
- категорію нотатки;
- власну категорію, якщо вибрано «Інше»;
- опційний розділ;
- опційний номер сторінки;
- spoiler state;
- favorite state;
- pinned state;
- дату створення;
- дату оновлення.

## MVP scope

У MVP входить:

1. Нотатки до книги.
2. Нотатки до серії.
3. Блок нотаток на детальній сторінці книги.
4. Блок нотаток на детальній сторінці серії.
5. Модалка додавання нотатки.
6. Модалка редагування нотатки.
7. Видалення нотатки.
8. Категорії нотаток без тегів.
9. Опція «Інше» для власної категорії.
10. Опційний розділ.
11. Опційна сторінка.
12. Позначка «Це спойлер».
13. Show / hide spoiler.
14. Улюблені нотатки.
15. Закріплені нотатки.
16. Сторінка «Нотатки» як загальний архів.
17. Пошук по нотатках.
18. Фільтри.
19. Сортування.
20. Перехід із нотатки до пов’язаної книги або серії.

## Out of scope for first version

- Нотатки до персонажів.
- Нотатки до авторів.
- Нотатки до цитат.
- Нотатки до локацій / карт світу.
- Нотатки до подій хронології.
- Markdown-редактор.
- Експорт нотаток.
- Спільний доступ до нотаток.
- Автоматична генерація нотаток.

## Key product rules

- Нотатка — окрема сутність, а не поле книги чи серії.
- Одна книга може мати багато нотаток.
- Одна серія може мати багато нотаток.
- Створення нової нотатки не перезаписує існуючі нотатки.
- Категорія нотатки не є тегом книги.
- Улюблена нотатка не змінює favorite status книги або серії.
- Закріплена нотатка піднімається вище в списку, але не змінює дату створення.
- Спойлерна нотатка приховує текст до ручного відкриття користувачем.
- Номер сторінки та розділ необов’язкові.
- Максимальний обсяг тексту нотатки — 5000 символів.
