1. Route / modal entry points.
2. Create mode / edit mode initialization.
3. Submit flow skeleton.
4. Shared validation and normalization.
5. Preview panel placeholders.

## Stage 2 — Core book data

1. Basic Information block.
2. Classification block.
3. Edition Details block.

## Stage 3 — Status logic

1. Reading status chips.
2. Reading conditional blocks.
3. Ownership status chips.
4. Ownership conditional blocks.
5. Format chips.
6. Conditional data cleanup confirmation in edit mode.

## Stage 4 — Cross-module integrations

1. Series relation.
2. Favorite toggle.
3. Reading queue.
4. Custom lists.
5. Purchase / delivery / loan integrations.

## Stage 5 — Polish

1. Cover upload / replace / remove.
2. Final states.
3. Accessibility.
4. Responsive layout.
5. Final acceptance criteria.
