# Spoiler-free description field

#### Коротко про книгу без спойлерів

| Параметр    | Значення                                           |
| ----------- | -------------------------------------------------- |
| Label       | Коротко про книгу без спойлерів                    |
| Placeholder | Опишіть сюжет, атмосферу або головну ідею книги... |
| Type        | Textarea                                           |
| Required    | Ні                                                 |
| Max length  | 500 символів                                       |
| Counter     | 0 / 500                                            |
| Line breaks | Дозволено                                          |
| HTML tags   | Заборонено                                         |

##### Logic

* поле необов’язкове;
* користувач може коротко описати сюжет, атмосферу, головну ідею або очікування від книги;
* це не повна рецензія і не нотатка;
* якщо поле порожнє, блок опису не показується на детальній сторінці;
* якщо текст доданий, він може показуватися на детальній сторінці книги;
* у compact preview опис можна не показувати або показувати тільки короткий fragment.

##### Error message

```text
Опис не може бути довшим за 500 символів
```
