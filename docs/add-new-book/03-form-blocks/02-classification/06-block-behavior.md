# Block behavior

### 7.5. Block-specific behavior

#### Create mode

У create mode:

* жанри відкриваються порожніми;
* теги відкриваються порожніми;
* вікова категорія має default `not_specified`;
* мова має default `ukrainian`;
* користувач може не заповнювати цей блок і все одно створити книгу;
* якщо користувач уже створював теги раніше, вони доступні в autocomplete;
* якщо користувач ще не створював теги, список тегів порожній;
* preview оновлюється після вибору жанрів і тегів.

#### Edit mode

У edit mode:

* усі поля заповнюються поточними значеннями книги;
* користувач може додати або прибрати жанри;
* користувач може додати або прибрати теги;
* користувач може змінити вікову категорію;
* користувач може змінити мову книги;
* якщо користувач видаляє всі жанри або теги, книга має зберегтися без них.
