# Age category field

#### Вікова категорія

| Параметр      | Значення                    |
| ------------- | --------------------------- |
| Label         | Вікова категорія            |
| Placeholder   | Оберіть вікову категорію    |
| Type          | Select                      |
| Required      | Ні                          |
| Default value | `not_specified`             |
| Unknown value | Заборонено                  |
| Empty value   | Замінити на `not_specified` |

##### Purpose

Вікова категорія — це не жанр і не тег.

Вона показує рекомендоване або обмежувальне маркування книги за віком.

##### Data source

Список завчасно визначених категорій:

```text
foundation/config/age-categories.json
```

##### Options

| Value             | Label        | Опис                                    |
| ----------------- | ------------ | --------------------------------------- |
| `not_specified`   | Не вказано   | Вікова категорія не вказана             |
| `no_restrictions` | Без обмежень | Книга без вікових обмежень              |
| `6_plus`          | 6+           | Книга рекомендована від 6 років         |
| `12_plus`         | 12+          | Книга рекомендована від 12 років        |
| `14_plus`         | 14+          | Книга рекомендована від 14 років        |
| `16_plus`         | 16+          | Книга рекомендована від 16 років        |
| `18_plus`         | 18+          | Книга рекомендована тільки для дорослих |

##### Logic

* поле необов’язкове;
* якщо користувач нічого не вибрав, використовується `not_specified`;
* вікова категорія показується на детальній сторінці книги;
* може показуватися як badge;
* може використовуватися у фільтрах бібліотеки.

##### Error message

```text
Обрана вікова категорія не знайдена
```
