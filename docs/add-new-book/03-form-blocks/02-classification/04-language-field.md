# Book language field

#### Мова книги

| Параметр      | Значення              |
| ------------- | --------------------- |
| Label         | Мова книги            |
| Placeholder   | Оберіть мову          |
| Type          | Select / Autocomplete |
| Required      | Ні                    |
| Default value | `ukrainian`           |
| Unknown value | Заборонено            |

##### Purpose

Поле показує мову книги або конкретного видання книги.

Це саме **мова книги**, а не мова інтерфейсу застосунку.

##### Data source

Список основних мов:

```text
foundation/config/languages.json
```

Для MVP можна використовувати local config. У майбутньому це можна замінити на готову API мов.

##### MVP options

| Value       | Label      |
| ----------- | ---------- |
| `ukrainian` | Українська |
| `english`   | Англійська |
| `polish`    | Польська   |
| `german`    | Німецька   |
| `french`    | Французька |
| `spanish`   | Іспанська  |
| `other`     | Інше       |

##### Logic

* поле необов’язкове;
* якщо користувач нічого не вибрав, можна використовувати `ukrainian` як default;
* мова показується на детальній сторінці книги;
* мова може використовуватися у фільтрах бібліотеки;
* мова може використовуватися у статистиці;
* якщо вибрано `other`, додаткове поле можна не показувати в MVP.

##### Error message

```text
Обрана мова не знайдена
```
