# Reading conditional: rereading

#### Якщо reading status = `rereading`

Показати блок:

```text
Повторне читання
```

##### Поля

| Поле                       | Type         | Required | Опис                                     |
| -------------------------- | ------------ | -------: | ---------------------------------------- |
| Поточна сторінка           | Number input |       Ні | Поточний прогрес повторного читання      |
| Дата початку перечитування | Date picker  |       Ні | Коли користувач почав перечитувати книгу |
| Нотатка                    | Textarea     |       Ні | Додаткова нотатка                        |

##### Logic

* блок показується тільки для `rereading`;
* логіка схожа на `reading`;
* для MVP цей статус можна приховати, якщо повторне читання ще не реалізоване.
