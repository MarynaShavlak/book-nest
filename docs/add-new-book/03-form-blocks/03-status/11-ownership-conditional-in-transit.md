# Ownership conditional: in transit

#### Якщо ownership status = `in_transit`

Показати блок:

```text
Інформація про доставку
```

##### Поля

| Поле                    | Type                              | Required | Опис                            |
| ----------------------- | --------------------------------- | -------: | ------------------------------- |
| Магазин                 | Text input / Autocomplete         |       Ні | Назва магазину                  |
| Номер замовлення        | Text input                        |       Ні | Номер замовлення або ТТН        |
| Дата замовлення         | Date picker                       |       Ні | Коли книга була замовлена       |
| Очікувана дата доставки | Date picker                       |       Ні | Коли очікується доставка        |
| Статус доставки         | Chip single-select group / Select |       Ні | Поточний ручний статус доставки |
| Нотатка                 | Textarea                          |       Ні | Додаткова інформація            |

##### Delivery status options in form

У формі потрібно показувати тільки ручні delivery statuses:

| Value              | Label            |     Показувати у create mode |
| ------------------ | ---------------- | ---------------------------: |
| `ordered`          | Замовлено        |                          Так |
| `in_transit`       | В дорозі         |                          Так |
| `ready_for_pickup` | Очікує отримання |                          Так |
| `cancelled`        | Скасовано        | Ні, краще тільки в edit mode |

> Канонічні значення, `tone` та іконки — у `foundation/config/statuses.json` (єдине джерело правди); тут не дублюються.

Default delivery status:

```text
ordered
```

##### Logic

* блок показується тільки для `in_transit`;
* книга після збереження має з’явитися у розділі **“Книги в дорозі”**;
* computed delivery badges рахуються автоматично від очікуваної дати доставки;
* кнопка **“Позначити як отриману”** має бути action, а не статус у select.

##### Received action

Коли користувач натискає:

```text
Позначити як отриману
```

система має змінити:

```text
ownershipStatus: in_transit → owned
```

Після цього книга зникає зі сторінки **“Книги в дорозі”** і залишається в бібліотеці.
