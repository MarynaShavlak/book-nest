# Validation summary

### 8.11. Validation

#### Статус читання

| Правило             | Значення                  |
| ------------------- | ------------------------- |
| Required            | Так                       |
| Allowed values only | Так                       |
| Default             | `not_started`             |
| Empty value         | Замінити на `not_started` |

Error message:

```text
Оберіть статус читання
```

---

#### Reading conditional fields

| Поле                 | Валідація                                                                   |
| -------------------- | --------------------------------------------------------------------------- |
| Поточна сторінка     | optional, integer, min 0, не більше `pagesCount`, якщо `pagesCount` вказано |
| Дата початку читання | optional, не може бути в майбутньому                                        |
| Дата прочитання      | optional, не може бути в майбутньому                                        |
| Дата паузи           | optional, не може бути в майбутньому                                        |
| Дата припинення      | optional, не може бути в майбутньому                                        |
| Оцінка               | optional, від 1 до 5, крок 0.5 або 1                                        |
| Причина / нотатка    | optional, max 300 символів                                                  |
| Коротке враження     | optional, max 500 символів                                                  |

---

#### Статус володіння

| Правило             | Значення           |
| ------------------- | ------------------ |
| Required            | Так                |
| Allowed values only | Так                |
| Default             | `none`             |
| Empty value         | Замінити на `none` |

Error message:

```text
Оберіть статус володіння
```

---

#### Формат книги

| Правило             | Значення   |
| ------------------- | ---------- |
| Required            | Ні         |
| Allowed values only | Так        |
| Duplicate values    | Заборонено |
| Empty value         | Дозволено  |

Error messages:

```text
Обраний формат не знайдено
Цей формат уже додано
```

#### Інформація про купівлю

| Поле                 | Валідація                      |
