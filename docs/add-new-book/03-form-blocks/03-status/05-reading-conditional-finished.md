# Reading conditional: finished

#### Якщо reading status = `finished`

Показати блок:

```text
Завершення
```

##### Поля

| Поле             | Type         | Required | Опис                                |
| ---------------- | ------------ | -------: | ----------------------------------- |
| Оцінка           | Rating stars |       Ні | Особиста оцінка книги               |
| Дата прочитання  | Date picker  |       Ні | Коли книга була прочитана           |
| Коротке враження | Textarea     |       Ні | Невеликий коментар після завершення |

##### Logic

* блок показується тільки для `finished`;
* дата прочитання може автоматично ставати поточною датою;
* користувач може змінити дату вручну;
* оцінка не є обов’язковою;
* якщо є `pagesCount`, прогрес можна вважати 100%;
* книга враховується у статистиці, reading goals і reading calendar.
