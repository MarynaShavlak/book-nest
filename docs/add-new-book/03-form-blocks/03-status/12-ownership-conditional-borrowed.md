# Ownership conditional: borrowed from someone

#### Якщо ownership status = `borrowed_from_someone`

Показати блок:

```text
Позичена у когось
```

##### Поля

| Поле                      | Type        | Required | Опис                                         |
| ------------------------- | ----------- | -------: | -------------------------------------------- |
| У кого позичена           | Text input  |      Так | Ім’я людини, у якої користувач позичив книгу |
| Дата позики               | Date picker |       Ні | Коли користувач позичив книгу                |
| Очікувана дата повернення | Date picker |       Ні | Коли потрібно повернути книгу                |
| Нотатка                   | Textarea    |       Ні | Додаткова інформація                         |

##### Logic

* блок показується тільки для `borrowed_from_someone`;
* поле **“У кого позичена”** є обов’язковим;
* після збереження книга з’являється у розділі **“Позичені книги”**;
* статус позики у create mode автоматично вважається активним;
* дедлайн-статуси не вибираються вручну, а рахуються автоматично.
