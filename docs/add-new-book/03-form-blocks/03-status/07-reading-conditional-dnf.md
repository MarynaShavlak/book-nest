# Reading conditional: dnf

#### Якщо reading status = `dnf`

Показати блок:

```text
Покинуто
```

##### Поля

| Поле                    | Type         | Required | Опис                                         |
| ----------------------- | ------------ | -------: | -------------------------------------------- |
| Сторінка, де зупинились | Number input |       Ні | На якій сторінці користувач припинив читання |
| Дата припинення         | Date picker  |       Ні | Коли користувач припинив читати              |
| Причина                 | Textarea     |       Ні | Чому користувач покинув книгу                |

##### Logic

* блок показується тільки для `dnf`;
* причина не є обов’язковою;
* книга не враховується як прочитана;
* книга може показуватися у фільтрі **“Покинуто”**.
