# Ownership conditional: want to buy

#### Якщо ownership status = `want_to_buy`

Показати блок:

```text
Інформація про купівлю
```

##### Поля

| Поле                 | Type                      | Required | Опис                 |
| -------------------- | ------------------------- | -------: | -------------------- |
| Магазин              | Text input / Autocomplete |       Ні | Назва магазину       |
| Посилання на магазин | URL input                 |       Ні | Посилання на книгу   |
| Очікувана ціна       | Number input              |       Ні | Орієнтовна ціна      |
| Валюта               | Select                    |       Ні | UAH / EUR / USD      |
| Нотатка              | Textarea                  |       Ні | Додаткова інформація |

##### Logic

* блок показується тільки для `want_to_buy`;
* книга після збереження має з’явитися у розділі **“Книги до покупки”**;
* якщо користувач змінює ownership status на інший, блок приховується;
* якщо дані блоку вже були введені, не очищати їх одразу без підтвердження.
