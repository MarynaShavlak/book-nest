# Reading conditional: paused

#### Якщо reading status = `paused`

Показати блок:

```text
Пауза в читанні
```

##### Поля

| Поле              | Type         | Required | Опис                                    |
| ----------------- | ------------ | -------: | --------------------------------------- |
| Поточна сторінка  | Number input |       Ні | Де користувач зупинився                 |
| Дата паузи        | Date picker  |       Ні | Коли користувач поставив книгу на паузу |
| Причина / нотатка | Textarea     |       Ні | Чому читання поставлено на паузу        |

##### Logic

* блок показується тільки для `paused`;
* поля optional;
* книга не зникає з бібліотеки;
* книга може показуватися у фільтрі **“На паузі”**;
* якщо користувач пізніше повертається до книги, статус можна змінити на `reading`.
