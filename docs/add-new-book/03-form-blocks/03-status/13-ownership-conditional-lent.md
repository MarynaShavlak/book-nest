# Ownership conditional: lent to someone

#### Якщо ownership status = `lent_to_someone`

Показати блок:

```text
Видана комусь
```

##### Поля

| Поле                      | Type        | Required | Опис                                   |
| ------------------------- | ----------- | -------: | -------------------------------------- |
| Кому видана               | Text input  |      Так | Ім’я людини, якій користувач дав книгу |
| Дата передачі             | Date picker |       Ні | Коли користувач передав книгу          |
| Очікувана дата повернення | Date picker |       Ні | Коли книгу мають повернути             |
| Нотатка                   | Textarea    |       Ні | Додаткова інформація                   |

##### Logic

* блок показується тільки для `lent_to_someone`;
* поле **“Кому видана”** є обов’язковим;
* після збереження книга з’являється у розділі **“Позичені книги”**;
* статус позики у create mode автоматично вважається активним;
* дедлайн-статуси не вибираються вручну, а рахуються автоматично.
