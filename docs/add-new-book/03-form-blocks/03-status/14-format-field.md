# Format field

### 8.9. Формат книги

| Параметр         | Значення                |
| ---------------- | ----------------------- |
| Label            | Формат книги            |
| Type             | Chip multi-select group |
| Required         | Ні                      |
| Default value    | Порожній список         |
| Unknown value    | Заборонено              |
| Duplicate values | Заборонено              |

#### Purpose

Формат книги показує, у якому вигляді користувач має або планує читати книгу.

Формат не є статусом володіння.

Книга може мати кілька форматів одночасно.

#### Options

| Value       | Label      | Tone    | Icon           | Де використовується |
| ----------- | ---------- | ------- | -------------- | ------------------- |
| `paper`     | Паперова   | neutral | `i-book`       | деталі, фільтри     |
| `ebook`     | Електронна | neutral | `i-tablet`     | деталі, фільтри     |
| `audiobook` | Аудіокнига | neutral | `i-headphones` | деталі, фільтри     |

#### Important

Не показувати `not_specified` як окремий варіант у multi-select.

Якщо користувач нічого не вибрав:

* формат просто не вказаний;
* у деталях можна показати fallback **“Формат не вказано”**;
* у формі не потрібно створювати chip **“Не вказано”**.

#### Logic

* поле необов’язкове;
* користувач може вибрати один або кілька форматів;
* вибрані формати показуються як active chips;
* при повторному натисканні на active chip формат знімається;
* формати використовуються у фільтрах бібліотеки;
* формати можуть показуватися на картці книги та детальній сторінці.
