# Preview logic

### 8.14. Preview logic

Права панель preview має реагувати на зміни в цьому блоці.

| Поле             | Як впливає на preview                      |
| ---------------- | ------------------------------------------ |
| Статус читання   | Показується як badge                       |
| Статус володіння | Показується як badge                       |
| Формати          | Показуються як chips / badges              |
| Rating           | Може показуватися, якщо статус `finished`  |
| Delivery status  | Можна показувати тільки в expanded preview |
| Loan info        | Можна не показувати в compact preview      |
