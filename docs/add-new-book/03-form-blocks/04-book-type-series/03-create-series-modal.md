# Create series modal

### 9.6. Modal “Створити серію”

Modal **“Створити серію”** потрібна для швидкого створення нової серії прямо під час створення книги.

Modal не має одразу створювати серію в базі.
Вона має створити тільки тимчасовий draft series у формі.

---

#### Поля modal

| Поле                    | Type                     | Required | Опис                                |
| ----------------------- | ------------------------ | -------: | ----------------------------------- |
| Назва серії             | Text input               |      Так | Назва нової серії                   |
| Статус серії            | Chip single-select group |       Ні | Завершена, ще виходить або невідомо |
| Загальна кількість книг | Number input             |       Ні | Скільки книг у серії                |
| Опис серії              | Textarea                 |       Ні | Короткий опис серії                 |
| Обкладинка серії        | Image upload             |       Ні | Зображення серії                    |

---

Деталі полів рівня серії (задаються в цій модалці):

#### Загальна кількість книг

| Параметр    | Значення                |
| ----------- | ----------------------- |
| Label       | Загальна кількість книг |
| Placeholder | Наприклад: 5            |
| Type        | Number input            |
| Required    | Ні                      |

##### Logic

* поле необов’язкове;
* якщо користувач не знає кількість книг, поле можна залишити порожнім;
* використовується для прогресу серії;
* якщо вказано загальну кількість книг, вона не може бути меншою за номер частини.

##### Error messages

```text
Загальна кількість книг має бути цілим числом
Загальна кількість книг не може бути меншою за номер частини
```

#### Статус серії

| Параметр      | Значення                 |
| ------------- | ------------------------ |
| Label         | Статус серії             |
| Type          | Chip single-select group |
| Required      | Ні                       |
| Default value | `unknown`                |

##### Options

| Value       | Label             |
| ----------- | ----------------- |
| `completed` | Серія завершена   |
| `ongoing`   | Серія ще виходить |
| `unknown`   | Невідомо          |

> Канонічні значення, `tone` та іконки — у `foundation/config/statuses.json` (єдине джерело правди); тут не дублюються.

##### Logic

* статус серії стосується всієї серії, а не конкретної книги;
* статус серії задається в modal **“Створити серію”** (а не як окреме поле в кожній книзі);
* статус серії не показується в основному блоці **Статус**;
* якщо користувач нічого не вибрав, використовується `unknown`;
* для MVP бажано показувати всі три варіанти:

    * Серія завершена;
    * Серія ще виходить;
    * Невідомо.

#### Опис серії

| Параметр    | Значення                 |
| ----------- | ------------------------ |
| Label       | Опис серії               |
| Placeholder | Коротко опишіть серію... |
| Type        | Textarea                 |
| Required    | Ні                       |
| Max length  | 300 символів             |

##### Logic

* поле доступне в modal **“Створити серію”**;
* поле необов’язкове;
* якщо опис не доданий, блок опису серії можна не показувати;
* опис можна пізніше відредагувати на сторінці деталей серії.

#### Обкладинка серії

| Параметр | Значення         |
| -------- | ---------------- |
| Label    | Обкладинка серії |
| Type     | Image upload     |
| Required | Ні               |

##### Logic

* поле доступне в modal **“Створити серію”**;
* поле необов’язкове;
* якщо обкладинка не додана, показується placeholder;
* обкладинку можна пізніше змінити на сторінці деталей серії.

##### Error messages

```text
Файл має бути у форматі JPG, PNG або WEBP
Розмір файлу не може перевищувати 2 MB
```

---

##### Кнопки modal

```text
Скасувати
Створити серію
```

---

##### Logic

* користувач натискає **Створити серію** в autocomplete;
* відкривається modal;
* користувач заповнює дані серії;
* після натискання **Створити серію** modal закривається;
* нова серія підставляється в поле **Назва серії**;
* фокус бажано перевести на поле **Номер частини**;
* серія ще не створюється в базі;
* серія буде створена тільки після submit всієї форми книги.
