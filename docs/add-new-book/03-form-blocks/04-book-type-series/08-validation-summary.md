# Validation summary

### 9.11. Validation summary

| Поле                    |                Required | Правила                                 |
| ----------------------- | ----------------------: | --------------------------------------- |
| Тип книги               |                     Так | тільки `solo` або `series_part`         |
| Назва серії             | Так, якщо `series_part` | 2–120 символів, без дублікатів          |
| Номер частини           | Так, якщо `series_part` | integer, 1–999; дубль номера в серії → warning |
| Загальна кількість книг |                      Ні | integer, 1–999, не менше номера частини |
| Статус серії            |                      Ні | allowed values only, default `unknown`  |
| Опис серії              |                      Ні | max 300 символів                        |
| Обкладинка серії        |                      Ні | JPG / PNG / WEBP, max 2 MB              |
