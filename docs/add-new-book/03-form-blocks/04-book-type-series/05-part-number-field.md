# Part number field

### 9.8. Номер частини

| Параметр    | Значення                         |
| ----------- | -------------------------------- |
| Label       | Номер частини                    |
| Placeholder | Наприклад: 1                     |
| Type        | Number input                     |
| Required    | Так, якщо книга є частиною серії |

#### Logic

* поле показується тільки якщо вибрано **Частина серії**;
* визначає порядок книги в серії;
* після збереження книга має відображатися на сторінці серії відповідно до номера частини;
* якщо дві книги мають однаковий номер частини, потрібно показати warning або validation error.

#### Error messages

```text
Вкажіть номер частини
Номер частини має бути цілим числом
Номер частини має бути від 1 до 999
Книга з таким номером частини вже є в цій серії
```
