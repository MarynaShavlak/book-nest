# Illustrator field

### 10.9. Ілюстратор

| Параметр    | Значення                  |
| ----------- | ------------------------- |
| Label       | Ілюстратор                |
| Placeholder | Введіть ім’я ілюстратора  |
| Type        | Text input / Autocomplete |
| Required    | Ні                        |

#### Purpose

Поле потрібне для книг, де важливі ілюстрації або художнє оформлення.

Наприклад:

* дитячі книги;
* графічні романи;
* артбуки;
* спеціальні ілюстровані видання.

#### Logic

* поле необов’язкове;
* для MVP можна зробити простий text input;
* якщо потрібно підтримувати кількох ілюстраторів, краще зробити multi-value input;
* якщо поле порожнє, ілюстратор не показується на сторінці деталей.

#### Error message

```text
Ім’я ілюстратора не може бути довшим за 100 символів
```
