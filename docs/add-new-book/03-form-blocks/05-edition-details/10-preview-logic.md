# Preview logic

### 10.12. Preview logic

Права панель preview може реагувати на зміни в цьому блоці.

| Поле               | Як впливає на preview                       |
| ------------------ | ------------------------------------------- |
| Кількість сторінок | Може показуватися в detail preview          |
| Рік видання        | Може показуватися в detail preview          |
| ISBN               | Не обов’язково показувати в compact preview |
| Оригінальна назва  | Не обов’язково показувати в compact preview |
| Перекладач         | Не обов’язково показувати в compact preview |
| Ілюстратор         | Не обов’язково показувати в compact preview |
| Присвята | Не обов’язково показувати в compact preview |

У компактному preview достатньо показувати тільки основну інформацію, статуси й обкладинку.
Деталі видання краще показувати на сторінці деталей книги.
