# Dedication field

### 10.7. Присвята

| Параметр    | Значення                                     |
| ----------- | -------------------------------------------- |
| Label       | Присвята                                     |
| Placeholder | Наприклад: Книга присвячена родині автора... |
| Type        | Textarea                                     |
| Required    | Ні                                           |
| Max length  | 300 символів                                 |

#### Purpose

Поле **“Присвята”** потрібне, щоб користувач міг зберегти короткий текст присвяти, якщо вона є у книзі.

Це може бути авторська присвята на початку книги або коротка інформація про те, кому присвячене видання.

#### Logic

* поле необов’язкове;
* якщо присвята не додана, блок не показується на сторінці деталей книги;
* якщо присвята додана, її можна показувати на сторінці деталей книги в секції **Деталі видання**;
* присвята не є нотаткою користувача;
* присвята не впливає на статус читання, жанри, теги або статистику;
* перед збереженням потрібно робити `trim`;
* HTML-теги не дозволені.

#### Error message

```text
Присвята не може бути довшою за 300 символів
```

#### Normalization before submit

```ts
dedication = dedication?.trim() || null;
```
