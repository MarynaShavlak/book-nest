# Block behavior

### 10.11. Block-specific behavior

#### Create mode

У create mode:

* усі поля блоку відкриваються порожніми;
* блок необов’язковий;
* користувач може створити книгу, не заповнюючи жодного поля цього блоку;
* якщо вказана кількість сторінок, вона використовується для validation прогресу читання;
* якщо вказаний ISBN, його можна використати для duplicate warning.
* користувач може додати присвяту;
* якщо присвята не додана, поле не впливає на створення книги.

#### Edit mode

У edit mode:

* поля відкриваються з поточними значеннями книги;
* користувач може змінити або очистити будь-яке поле;
* якщо користувач змінює кількість сторінок, потрібно перевірити, чи не стає поточний прогрес невалідним;
* якщо поточна сторінка більша за нову кількість сторінок, потрібно показати validation або warning.
* користувач може змінити або очистити присвяту.

#### Приклад warning

```text
Поточна сторінка більша за нову кількість сторінок. Оновіть прогрес читання.
```
