# Pages count field

### 10.3. Кількість сторінок

| Параметр    | Значення           |
| ----------- | ------------------ |
| Label       | Кількість сторінок |
| Placeholder | Наприклад: 528     |
| Type        | Number input       |
| Required    | Ні                 |

#### Purpose

Поле показує, скільки сторінок має конкретне видання книги.

Це важливо для:

* розрахунку прогресу читання;
* перевірки поля **Поточна сторінка**;
* статистики прочитаних сторінок;
* reading goals;
* reading calendar.

#### Logic

* поле необов’язкове;
* якщо кількість сторінок вказана, вона використовується для validation прогресу;
* якщо кількість сторінок не вказана, прогрес можна вести без обмеження по максимальній сторінці;
* якщо книга має статус `finished`, прогрес може вважатися 100%;
* якщо користувач вводить поточну сторінку в блоці **Статус**, вона не може бути більшою за кількість сторінок.

#### Error messages

```text
Кількість сторінок має бути цілим числом
Кількість сторінок має бути більшою за 0
Кількість сторінок не може бути більшою за 10000
```
