# Original title field

### 10.6. Оригінальна назва

| Параметр    | Значення               |
| ----------- | ---------------------- |
| Label       | Оригінальна назва      |
| Placeholder | Наприклад: Fourth Wing |
| Type        | Text input             |
| Required    | Ні                     |

#### Purpose

Поле потрібне для книг, які перекладені з іншої мови.

Наприклад:

* назва українського видання: **Четверте крило**;
* оригінальна назва: **Fourth Wing**.

#### Logic

* поле необов’язкове;
* якщо книга не є перекладом, поле можна залишити порожнім;
* якщо поле заповнене, оригінальна назва показується на сторінці деталей книги;
* не впливає на основну назву книги.

#### Error message

```text
Оригінальна назва не може бути довшою за 200 символів
```
