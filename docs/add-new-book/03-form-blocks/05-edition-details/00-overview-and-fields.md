# Overview and fields

### 10.1. Purpose

Блок **“Деталі видання”** потрібен, щоб користувач міг додати технічну інформацію саме про конкретне видання книги.

Цей блок не описує читацький статус, прогрес, серію або нотатки.
Він зберігає інформацію про саме видання:

* оригінальну назву;
* присвяту
* кількість сторінок;
* рік видання;
* ISBN;
* перекладача;
* ілюстратора.

Ці дані допомагають:

* точніше описати книгу;
* відрізняти різні видання однієї книги;
* правильно рахувати прогрес читання;
* показувати повнішу інформацію на сторінці деталей книги;
* покращити фільтрацію та пошук у бібліотеці.

### 10.2. Fields overview

| Поле               | Type                      | Required | Validation                         | Де використовується         |
| ------------------ | ------------------------- | -------: | ---------------------------------- | --------------------------- |
| Присвята           | Textarea                  | Ні       | max 300 символів                   | деталі книги                |
| Кількість сторінок | Number input              |       Ні | integer, min 1, max 10000          | прогрес читання, статистика |
| Рік видання        | Number input              |       Ні | 4 digits, не більше поточного року | деталі книги, фільтри       |
| ISBN               | Text input                |       Ні | ISBN-10 або ISBN-13                | пошук, дублікати, деталі    |
| Оригінальна назва  | Text input                |       Ні | max 200 символів                   | деталі книги                |
| Перекладач         | Text input / Autocomplete |       Ні | max 100 символів                   | деталі книги                |
| Ілюстратор         | Text input / Autocomplete |       Ні | max 100 символів                   | деталі книги                |
