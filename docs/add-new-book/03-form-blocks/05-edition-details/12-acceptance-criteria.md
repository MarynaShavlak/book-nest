# Acceptance Criteria

### 10.14. Acceptance Criteria

* Користувач бачить блок **Деталі видання** у формі створення / редагування книги.
* Блок **Деталі видання** не є обов’язковим.
* Користувач може вказати кількість сторінок.
* Користувач може залишити кількість сторінок порожньою.
* Якщо кількість сторінок вказана, вона має бути цілим числом більше 0.
* Користувач може вказати рік видання.
* Якщо рік видання вказаний, він має бути валідним роком.
* Користувач може вказати ISBN.
* Якщо ISBN вказаний, він має бути валідним ISBN-10 або ISBN-13.
* Користувач може вказати оригінальну назву.
* Користувач може вказати перекладача.
* Користувач може вказати ілюстратора.
* Користувач може створити книгу, не заповнюючи цей блок.
* У create mode поля відкриваються порожніми.
* У edit mode поля відкриваються з поточними значеннями книги.
* Якщо введені невалідні значення, користувач бачить validation errors.
* Якщо кількість сторінок змінена так, що поточний прогрес стає невалідним, користувач бачить warning або validation error.
* Поля блоку **Деталі видання** показуються на сторінці деталей книги, якщо вони заповнені.
