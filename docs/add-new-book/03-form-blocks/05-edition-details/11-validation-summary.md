# Validation summary

### 10.13. Validation summary

| Поле               | Required | Правила                         |
| ------------------ | -------: | ------------------------------- |
| Кількість сторінок | Ні | ціле число, 1–10000 (без дробових і від’ємних) |
| Рік видання        | Ні | 4 цифри, 1000 – поточний рік + 1 |
| ISBN               | Ні | ISBN-10 або ISBN-13; цифри, дефіси, пробіли, `X`; без HTML |
| Оригінальна назва  | Ні | max 200 символів; trim; без HTML |
| Перекладач         | Ні | max 100 символів; trim; без HTML |
| Ілюстратор         | Ні | max 100 символів; trim; без HTML |
| Присвята           | Ні | max 300 символів; trim; без HTML |
