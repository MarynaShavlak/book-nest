# Publication year field

### 10.4. Рік видання

| Параметр    | Значення        |
| ----------- | --------------- |
| Label       | Рік видання     |
| Placeholder | Наприклад: 2024 |
| Type        | Number input    |
| Required    | Ні              |

#### Purpose

Поле показує, у якому році було видано конкретне видання книги.

Це корисно, якщо користувач хоче відрізняти старі й нові видання однієї книги.

#### Logic

* поле необов’язкове;
* якщо рік вказаний, він показується на сторінці деталей книги;
* може використовуватися у фільтрах або сортуванні;
* не має впливати на статус читання або володіння.

#### Error messages

```text
Рік видання має бути у форматі YYYY
Введіть коректний рік видання
```
