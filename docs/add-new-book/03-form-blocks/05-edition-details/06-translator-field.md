# Translator field

### 10.8. Перекладач

| Параметр    | Значення                  |
| ----------- | ------------------------- |
| Label       | Перекладач                |
| Placeholder | Введіть ім’я перекладача  |
| Type        | Text input / Autocomplete |
| Required    | Ні                        |

#### Purpose

Поле потрібне для перекладених видань, щоб зберігати інформацію про перекладача.

#### Logic

* поле необов’язкове;
* можна дозволити вводити одного або кількох перекладачів;
* для MVP можна зробити простий text input;
* якщо потрібно підтримувати кількох перекладачів, краще зробити multi-value input;
* якщо поле порожнє, перекладач не показується на сторінці деталей.

#### Error message

```text
Ім’я перекладача не може бути довшим за 100 символів
```
