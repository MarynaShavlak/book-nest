# ISBN field

### 10.5. ISBN

| Параметр    | Значення                     |
| ----------- | ---------------------------- |
| Label       | ISBN                         |
| Placeholder | Наприклад: 978-617-548-123-4 |
| Type        | Text input                   |
| Required    | Ні                           |

#### Purpose

ISBN допомагає ідентифікувати конкретне видання книги.

Поле корисне для:

* пошуку книги;
* імпорту / експорту;
* перевірки дублікатів;
* відрізнення різних видань однієї книги.

#### Logic

* поле необов’язкове;
* користувач може вводити ISBN з дефісами або без дефісів;
* перед збереженням ISBN потрібно нормалізувати;
* дефіси й пробіли можна прибрати для внутрішньої перевірки;
* у UI можна показувати ISBN у тому форматі, який ввів користувач, або у нормалізованому форматі.

#### Error messages

```text
Введіть коректний ISBN
ISBN має бути у форматі ISBN-10 або ISBN-13
```
