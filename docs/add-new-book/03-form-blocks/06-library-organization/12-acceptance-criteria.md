# Acceptance Criteria

### 11.15. Acceptance Criteria

* Користувач бачить блок **Організація в бібліотеці** у формі створення / редагування книги.
* Блок є необов’язковим.
* Користувач може створити книгу, не заповнюючи цей блок.
* Користувач може позначити книгу як улюблену.
* Якщо книга позначена як улюблена, вона з’являється у розділі **Улюблені книги**.
* Користувач може додати книгу в чергу читання.
* Якщо книга додана в чергу, вона з’являється на сторінці **Черга читання**.
* `want_to_read` не додає книгу в чергу автоматично.
* Якщо увімкнено **Додати в чергу читання**, користувач може вибрати пріоритет.
* Якщо пріоритет не вибраний, використовується `normal`.
* Якщо **Додати в чергу читання** вимкнено, `queuePriority` не відправляється при submit.
* Користувач може додати книгу до одного або кількох власних списків.
* Користувач не може додати книгу в один список двічі.
* Користувач може створити новий список через modal.
* Новий список з modal не створюється в базі одразу.
* Новий список створюється тільки після submit книги.
* Якщо користувач скасував створення книги, draft list не зберігається.
* У create mode поля відкриваються з default значеннями.
* У edit mode поля відкриваються з поточними значеннями книги.
* Якщо книга вже є в черзі, checkbox **Додати в чергу читання** відкривається увімкненим.
* Якщо книга вже належить до списків, ці списки вибрані в multi-select.
* Якщо користувач прибирає книгу з черги в edit mode, показується confirmation modal.
* Якщо введені невалідні значення, користувач бачить validation errors.
