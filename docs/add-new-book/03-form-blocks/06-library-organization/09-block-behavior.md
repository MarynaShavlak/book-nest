# Block behavior

### 11.12. Block-specific behavior

#### Create mode

У create mode:

* `isFavorite` має default `false`;
* `addToReadingQueue` має default `false`;
* `queuePriority` прихований, поки не ввімкнено **“Додати в чергу читання”**;
* список власних списків завантажується для поточного користувача;
* користувач може вибрати існуючі списки;
* користувач може створити новий draft list через modal;
* новий draft list не створюється в базі до submit книги;
* якщо користувач скасував створення книги, draft list не зберігається.

#### Edit mode

У edit mode:

* `isFavorite` відкривається з поточним значенням книги;
* якщо книга вже є в черзі, checkbox **“Додати в чергу читання”** має бути увімкнений;
* якщо книга вже має пріоритет у черзі, він має бути вибраний;
* якщо книга вже належить до списків, ці списки мають бути вибрані в multi-select;
* користувач може прибрати книгу з улюблених;
* користувач може прибрати книгу з черги;
* користувач може додати або прибрати книгу зі списків;
* після зміни списків сторінки відповідних списків мають оновитися.
