# Preview logic

### 11.13. Preview logic

Права preview-панель може реагувати на зміни в цьому блоці.

| Поле                   | Як впливає на preview                       |
| ---------------------- | ------------------------------------------- |
| Додати в улюблені      | Може показувати heart icon                  |
| Додати в чергу читання | Може показувати badge “У черзі”             |
| Пріоритет у черзі      | Може показувати маленький priority badge    |
| Додати до списків      | Не обов’язково показувати в compact preview |

Для compact preview достатньо показувати:

* heart icon, якщо книга улюблена;
* badge **“У черзі”**, якщо книга додана в reading queue.
