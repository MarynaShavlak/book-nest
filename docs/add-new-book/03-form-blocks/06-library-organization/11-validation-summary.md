# Validation summary

### 11.14. Validation summary

| Поле                   |                           Required | Правила                                                                    |
| ---------------------- | ---------------------------------: | -------------------------------------------------------------------------- |
| Додати в улюблені      |                                 Ні | boolean                                                                    |
| Додати в чергу читання |                                 Ні | boolean                                                                    |
| Пріоритет у черзі      |                                 Ні | allowed values only, default `normal`, тільки якщо книга додається в чергу |
| Додати до списків      |                                 Ні | тільки списки поточного користувача, без дублікатів                        |
| Назва нового списку    | Так, якщо створюється новий список | 2–80 символів, без HTML                                                    |
| Опис нового списку     |                                 Ні | max 300 символів                                                           |
