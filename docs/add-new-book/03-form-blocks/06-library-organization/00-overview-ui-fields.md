# Overview, UI and fields

### 11.1. Purpose

Блок **“Організація в бібліотеці”** потрібен, щоб користувач міг одразу визначити, як книга має бути розміщена всередині його особистої бібліотеки.

Цей блок не описує саму книгу і не змінює її статус читання або володіння.
Він відповідає за організаційні дії:

* додати книгу в улюблені;
* додати книгу в чергу читання;
* вибрати пріоритет у черзі;
* додати книгу до одного або кількох власних списків;
* створити новий список прямо під час створення книги.

---

### 11.2. UI behavior

Блок має бути необов’язковим.

Користувач може створити книгу, не заповнюючи жодного поля цього блоку.

Рекомендований порядок елементів:

```text id="k1les6"
Організація в бібліотеці

[ ] Додати в улюблені

[ ] Додати в чергу читання
    → Пріоритет у черзі

Додати до списків
[ multi-select списків ]

+ Створити новий список
```

---

### 11.3. Fields overview

| Поле / дія             | Type                              | Required | Коли показувати                 | Опис                                             |
| ---------------------- | --------------------------------- | -------: | ------------------------------- | ------------------------------------------------ |
| Додати в улюблені      | Checkbox / Switch                 |       Ні | Завжди                          | Позначає книгу як улюблену                       |
| Додати в чергу читання | Checkbox / Switch                 |       Ні | Завжди                          | Додає книгу в reading queue                      |
| Пріоритет у черзі      | Chip single-select group / Select |       Ні | Якщо увімкнено “Додати в чергу” | Визначає важливість книги в черзі                |
| Додати до списків      | Multi-select                      |       Ні | Завжди                          | Додає книгу до власних списків                   |
| Створити новий список  | Button / Modal action             |       Ні | Якщо потрібного списку немає    | Дозволяє створити список під час створення книги |
