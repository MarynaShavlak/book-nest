# Add to custom lists

### 11.7. Додати до списків

| Параметр    | Значення          |
| ----------- | ----------------- |
| Label       | Додати до списків |
| Placeholder | Оберіть списки    |
| Type        | Multi-select      |
| Required    | Ні                |

#### Purpose

Поле **“Додати до списків”** дозволяє користувачу одразу додати книгу до одного або кількох власних списків.

Приклади списків:

* “Книги для осені”;
* “Фентезі, яке хочу прочитати”;
* “Подарунки”;
* “Улюблені світи”;
* “Книги від блогерів”.

#### Data source

Поле має показувати тільки списки поточного користувача.

Джерела:

* уже створені власні списки користувача;
* нові draft lists, створені через modal у цій формі.

#### Logic

* поле необов’язкове;
* користувач може вибрати один або кілька списків;
* книга не може бути додана в один і той самий список двічі;
* якщо список порожній, показати empty state;
* якщо потрібного списку немає, користувач може створити новий список через modal;
* після submit книга додається до вибраних списків;
* якщо користувач скасував створення книги, нові draft lists не зберігаються.

#### Empty state

