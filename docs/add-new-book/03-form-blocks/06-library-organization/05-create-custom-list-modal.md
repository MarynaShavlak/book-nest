# Create custom list modal

### 11.8. Modal “Створити новий список”

Modal **“Створити новий список”** потрібна, щоб користувач міг створити власний список прямо під час створення книги.

Modal не має одразу створювати список у базі.
Вона має створити тільки тимчасовий draft list у формі.

Реальний список створюється тільки після submit книги.

---

#### Поля modal

| Поле         | Type       | Required | Опис                 |
| ------------ | ---------- | -------: | -------------------- |
| Назва списку | Text input |      Так | Назва нового списку  |
| Опис списку  | Textarea   |       Ні | Короткий опис списку |

---

#### Кнопки modal

```text id="864ubi"
Скасувати
Створити список
```

---

#### Logic

* користувач натискає **Створити новий список**;
* відкривається modal;
* користувач вводить назву списку;
* після натискання **Створити список** modal закривається;
* новий список тимчасово додається у multi-select;
* новий список одразу вибирається для цієї книги;
* реальний список створюється тільки після submit книги;
* якщо користувач скасував створення книги, draft list не зберігається.
