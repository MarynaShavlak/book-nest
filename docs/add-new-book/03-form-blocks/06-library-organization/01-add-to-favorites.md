# Add to favorites

### 11.4. Додати в улюблені

| Параметр      | Значення          |
| ------------- | ----------------- |
| Label         | Додати в улюблені |
| Type          | Checkbox / Switch |
| Required      | Ні                |
| Default value | `false`           |

#### Purpose

Поле **“Додати в улюблені”** дозволяє користувачу одразу позначити книгу як улюблену під час створення або редагування.

Це окрема дія, яка не належить до статусів книги.

#### Logic

* за замовчуванням вимкнено;
* якщо користувач увімкнув це поле, книга після збереження з’являється у розділі **“Улюблені книги”**;
* якщо поле вимкнено, книга не потрапляє в улюблені;
* це поле не змінює `readingStatus`;
* це поле не змінює `ownershipStatus`;
* це поле не залежить від статусу читання.

#### Data

```ts id="n4uq6a"
isFavorite: boolean
```

#### Acceptance Criteria

* Користувач може позначити книгу як улюблену під час створення.
* Користувач може не позначати книгу як улюблену.
* Якщо книга позначена як улюблена, вона з’являється у розділі **Улюблені книги**.
* Якщо користувач вимикає це поле в edit mode, книга зникає з розділу **Улюблені книги**.
