# File size rules

### 12.7. File size

Максимальний розмір файлу:

```text id="np371a"
5 MB
```

#### Logic

* якщо файл більший за 5 MB, показати error;
* файл не має додаватися у preview;
* користувач має вибрати інший файл.

#### Error message

```text id="h56993"
Розмір файлу не може перевищувати 5 MB
```
