# Upload area

### 12.5. Upload area

#### Empty state

Якщо обкладинка ще не додана, показати upload area.

Приклад тексту:

```text id="xo56ii"
Завантажити обкладинку

PNG, JPG або WEBP до 5 MB
Рекомендований формат: 2:3
```

#### Дії

Користувач може:

* натиснути на upload area;
* вибрати файл з комп’ютера;
* перетягнути файл у drag-and-drop зону;
* побачити preview перед збереженням книги.
