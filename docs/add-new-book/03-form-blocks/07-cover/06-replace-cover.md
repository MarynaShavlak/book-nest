# Replace cover

### 12.10. Replace cover

Якщо обкладинка вже вибрана, показати дію:

```text id="aeu2vk"
Замінити обкладинку
```

#### Logic

* користувач натискає **Замінити обкладинку**;
* відкривається file picker;
* після вибору нового файлу preview оновлюється;
* старий draft-файл у create mode не зберігається;
* у edit mode стара обкладинка замінюється тільки після submit.
