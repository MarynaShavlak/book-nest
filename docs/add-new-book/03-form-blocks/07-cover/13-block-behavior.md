# Block behavior

### 12.17. Block-specific behavior

#### Create mode

У create mode:

* обкладинка необов’язкова;
* upload area відкривається порожньою;
* користувач може вибрати файл;
* після вибору показується preview;
* файл не завантажується в storage одразу;
* якщо користувач видаляє файл до submit, книга створюється без обкладинки;
* якщо користувач скасовує створення книги, файл не зберігається.

#### Edit mode

У edit mode:

* якщо книга має обкладинку, вона показується у preview;
* користувач може замінити обкладинку;
* користувач може видалити обкладинку;
* реальні зміни зберігаються тільки після submit;
* якщо submit неуспішний, стара обкладинка не має втрачатися.
