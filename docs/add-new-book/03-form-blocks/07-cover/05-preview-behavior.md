# Preview behavior

### 12.9. Preview behavior

Після вибору файлу користувач має одразу бачити preview.

Preview має показувати:

* зображення обкладинки;
* назву книги, якщо вона вже введена;
* автора, якщо він уже введений;
* статуси книги, якщо вони вибрані.

#### Image display

Для картки книги використовувати:

```css id="9p8kex"
object-fit: cover;
aspect-ratio: 2 / 3;
```

Це дозволить красиво обрізати зображення, якщо воно не ідеального розміру.
