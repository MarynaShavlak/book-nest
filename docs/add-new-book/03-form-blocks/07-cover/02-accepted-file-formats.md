# Accepted file formats

### 12.6. Accepted file formats

Дозволені формати:

| Формат     | Дозволено |
| ---------- | --------: |
| JPG / JPEG |       Так |
| PNG        |       Так |
| WEBP       |       Так |
| GIF        |        Ні |
| SVG        |        Ні |
| PDF        |        Ні |

#### Чому не SVG

SVG краще не дозволяти для обкладинок у MVP, бо він може містити небезпечний або зайвий код.
Для простого MVP достатньо JPG, PNG і WEBP.
