# Remove cover

### 12.11. Remove cover

Якщо обкладинка вже вибрана, показати дію:

```text id="zyakzs"
Видалити обкладинку
```

#### Create mode

У create mode:

* обкладинка просто прибирається з форми;
* файл не завантажується;
* книга створюється без обкладинки.

#### Edit mode

У edit mode:

* якщо книга вже мала обкладинку, після натискання **Видалити обкладинку** потрібно показати confirmation modal або позначити обкладинку як “буде видалена після збереження”.

#### Confirmation modal

```text id="b5r9zr"
Title: Видалити обкладинку?

Description:
Обкладинка буде видалена після збереження змін. Ви зможете додати нову обкладинку пізніше.

Actions:
- Скасувати
- Видалити
```
