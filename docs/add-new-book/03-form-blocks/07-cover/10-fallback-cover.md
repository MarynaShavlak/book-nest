# Fallback cover

### 12.14. Fallback cover

Якщо користувач не додав обкладинку, потрібно показувати fallback placeholder.

#### Placeholder має містити

* іконку книги;
* назву книги, якщо вона введена;
* автора, якщо він введений;
* нейтральний фон у стилі застосунку.

Приклад:

```text id="1mawdp"
Без обкладинки
```

#### Logic

* fallback не зберігається як реальна обкладинка;
* fallback генерується тільки в UI;
* якщо користувач пізніше додасть обкладинку, placeholder замінюється реальним зображенням.
