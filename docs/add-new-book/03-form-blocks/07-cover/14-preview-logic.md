# Preview logic

### 12.18. Preview logic

Права preview-панель має оновлюватися одразу після вибору файлу.

| Дія                         | Результат у preview                |
| --------------------------- | ---------------------------------- |
| Користувач вибрав файл      | Показується нова обкладинка        |
| Користувач замінив файл     | Preview оновлюється                |
| Користувач видалив файл     | Показується fallback placeholder   |
| Користувач ввів назву книги | Назва може показуватися у fallback |
| Користувач ввів автора      | Автор може показуватися у fallback |
