# Acceptance Criteria

### 12.19. Acceptance Criteria

* Користувач бачить можливість завантажити обкладинку книги.
* Обкладинка книги не є обов’язковою.
* Користувач може створити книгу без обкладинки.
* Користувач може завантажити JPG, JPEG, PNG або WEBP файл.
* Користувач не може завантажити файл більш ніж 5 MB.
* Користувач бачить preview обкладинки перед submit.
* Якщо зображення не вертикальне, користувач бачить warning.
* Якщо файл має неправильний формат, користувач бачить validation error.
* Якщо файл пошкоджений, користувач бачить validation error.
* У create mode файл не завантажується в storage до submit книги.
* Якщо користувач скасував створення книги, файл не зберігається.
* У edit mode стара обкладинка не замінюється до submit.
* Користувач може замінити обкладинку.
* Користувач може видалити обкладинку.
* Якщо обкладинка видалена, показується fallback placeholder.
* Якщо обкладинка не додана, у бібліотеці показується fallback placeholder.
* Alt text для обкладинки генерується автоматично.
