# Accessibility

### 12.15. Accessibility

Для обкладинки потрібно мати alt text.

#### Recommended alt text

```text id="faeth7"
Обкладинка книги “{bookTitle}”
```

Якщо назва книги ще не введена:

```text id="wrs1nr"
Обкладинка книги
```

#### Logic

* alt text не потрібно вводити вручну;
* він може генеруватися автоматично з назви книги;
* якщо назва змінюється, alt text оновлюється.
