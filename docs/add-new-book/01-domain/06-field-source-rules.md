# Field source rules

- Predefined authors, publishers, genres, age categories, languages and statuses come from config files.
- Custom authors, publishers, tags, series and lists are user-scoped.
- Custom values are drafts until the full book form is submitted.
- A hidden inactive conditional block should not be submitted in create mode.
