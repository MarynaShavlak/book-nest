# Layout and section order

## 2. Структура форми

Форма складається із семи змістових блоків (розділи 6–12 цього документа):

| Розділ | Блок                     | Required | Призначення                                          |
| -----: | ------------------------ | -------: | ---------------------------------------------------- |
|      6 | Основна інформація       | Частково | Формує основну ідентичність книги                    |
|      7 | Класифікація             |       Ні | Допомагає фільтрувати, групувати й аналізувати книги |
|      8 | Статус                   |      Так | Статуси читання, володіння та формат книги           |
|      9 | Тип книги / Серія        | Частково | Зв’язок книги із серією та номер частини             |
|     10 | Деталі видання           |       Ні | Технічні дані конкретного видання                    |
|     11 | Організація в бібліотеці |       Ні | Улюблені, черга читання та власні списки             |
|     12 | Обкладинка книги         |       Ні | Зображення обкладинки книги                          |
