# Search, Filters and Sorting

## Search

Placeholder:

```text
Пошук жанру або тегу...
```

Search works by:

- genre label;
- tag name;
- tag description;
- books that use this genre/tag.

Search behavior:

- trim spaces;
- ignore case;
- search inside current tab by default;
- empty search shows all items for current tab.

## Genre filters

Recommended filters:

```text
Усі жанри
Найпопулярніші
Художня література
Нон-фікшн

Жанри з книгами “Хочу купити”
Жанри з книгами в черзі
Жанри з прочитаними книгами
```

## Tag filters

Recommended filters:

```text

Тропи

Теми
Персонажі

Власні теги
Нещодавно використані
```

Important:

```text
Filters apply only to tags created by current user.
```

## Sorting

Options:

```text
За назвою
За кількістю книг
За кількістю прочитаних книг
За датою останнього використання
Спочатку найпопулярніші
```

Tags-specific option:

```text
За типом тегу
```

Default sorting:

```text
За назвою
```
