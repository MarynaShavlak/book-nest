# Add Tag: Success Updates and Acceptance

## Success message

```text
Тег додано
```

## Updates

After success:

- new tag appears in Tags tab;
- new tag appears in Book Form autocomplete;
- if action was started from Book Form, tag can be automatically selected for current book;
- summary tags count updates.

## Acceptance Criteria

- User can create tag.
- Tag belongs to current user.
- Tag is not visible to other users.
- Duplicate tag names are blocked by normalized name.
- Tags tab updates after creation.
- Book Form autocomplete updates after creation.
