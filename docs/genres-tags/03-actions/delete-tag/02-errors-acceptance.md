# Delete Tag: Errors and Acceptance

## Errors

```text
Тег не знайдено
Не вдалося видалити тег
```

## Acceptance Criteria

- User can delete own tag.
- User cannot delete another user's tag.
- If tag is used, confirmation explains that tag will be removed from books.
- Books are not deleted.
- Tag disappears from Tags tab.
- Tag disappears from Book Form autocomplete.
- Tag is removed from related books.
- My Library filter results update.
