# Delete Tag: Entry and Confirmation

## Entry point

Tags tab → tag card/chip → Delete.

## If tag is unused

Confirmation can be light:

```text
Видалити тег?
```

## If tag is used by books

Show stronger confirmation:

Title:

```text
Видалити тег?
```

Description:

```text
Цей тег буде прибраний з усіх книг, де він використовується. Книги не будуть видалені.
```

Buttons:

```text
Скасувати
Видалити тег
```
