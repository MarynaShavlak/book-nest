# Navigation and Entry Points

## Sidebar

```text
Жанри / Теги
```

Recommended placement near library-related pages:

```text
Бібліотека

```

## Entry points

User can open Genres / Tags from:

- sidebar;
- Dashboard library widget;
- Book Details genre/tag block;
- My Library filters;
- Statistics section.
