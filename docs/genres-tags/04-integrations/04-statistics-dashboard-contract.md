# Statistics and Dashboard Contract

## Dashboard

Dashboard can show compact widgets:

```text
Найпопулярніший жанр: Фентезі · 128 книг
Найчастіший тег: slow burn · 24 книги
```

If user has no tags:

```text
Створіть власні теги, щоб швидше знаходити книги за настроєм.
```

## Statistics

Future statistics can use:

- books count by genre;
- books count by tag;
- read count by genre;
- average rating by genre;
- most used user tags.

MVP rule:

```text
Full genre/tag analytics can stay in future Statistics module.
Genres / Tags Page only shows navigation-level counts.
```
