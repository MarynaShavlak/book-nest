# Responsive Rules

## Desktop

- sidebar visible;
- genre cards in 3–4 columns;
- tags as chips/cards;
- toolbar horizontal;
- header quote/helper can be shown.

## Tablet

- genre cards in 2 columns;
- filters can collapse;
- tag chips wrap.

## Mobile

- one-column layout;
- tabs horizontally scrollable;
- search full width;
- filters in bottom sheet;
- cards stack vertically;
- tag chips wrap safely;
- long tag names truncate or wrap without breaking layout.
