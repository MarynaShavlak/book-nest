# Purpose and Scope

## Purpose

Feature **Genres / Tags** додає окрему сторінку для керування жанрами й тегами в особистій бібліотеці BookNest.

Сторінка потрібна, щоб користувач міг:

- бачити жанри, які використовуються в бібліотеці;
- бачити власні теги, які він створив;
- бачити кількість книг у кожному жанрі або тегу;
- переходити до книг конкретного жанру або тегу;
- створювати власні теги;
- редагувати власні теги;
- видаляти власні теги;
- краще розуміти свої читацькі вподобання.

## MVP scope

У MVP входить:

- сторінка **Жанри / Теги**;
- вкладки **Жанри** і **Теги**;
- predefined genres;
- user-created tags only;
- genre cards;
- tag chips / small cards;
- search;
- filters;
- sorting;
- Add Tag modal;
- Edit Tag modal;
- Delete Tag flow;
- Book Form integration;
- Book Details integration;
- My Library filters;
- empty / loading / error states.

## Not included in MVP

Не входить у MVP:

- predefined tags;
- detailed genre page;
- detailed tag page;
- merge duplicate tags;
- automatic tag suggestions;
- automatic genre detection;
- mood recommendations;
- charts by genres in Statistics;
- custom genres;
- tag color system as required feature;
- tag icons.
