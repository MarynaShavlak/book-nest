# Domain

Domain-документи описують різницю між жанрами і тегами, data model, типи тегів, нормалізацію, validation, permissions, data safety rules та predefined BookNest palette для кольорів тегів.

## Files

- `00-purpose-and-scope.md` — module goal, MVP scope and out-of-scope decisions.
- `01-genre-vs-tag-rules.md` — difference between genres and tags.
- `02-genre-model.md` — predefined genre model and genre stats.
- `03-user-tag-model.md` — user-created tag model.
- `04-tag-types.md` — optional tag type classification.
- `05-normalization-and-duplicates.md` — tag name normalization and duplicate prevention.
- `06-validation-rules.md` — validation rules for genres and tags.
- `07-data-safety-and-permissions.md` — permissions and safety rules.
- `08-tag-color-palette.md` — predefined BookNest palette for user-created tag colors.
