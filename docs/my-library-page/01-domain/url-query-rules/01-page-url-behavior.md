### 2.6. URL behavior

Сторінка має підтримувати query params для фільтрів, пошуку, сортування та pagination.


Це потрібно, щоб:

* користувач міг оновити сторінку і не втратити фільтри;
* можна було повертатися назад через browser history;
* посилання на відфільтровану бібліотеку було стабільним;
* frontend і backend мали передбачувану логіку запитів.
