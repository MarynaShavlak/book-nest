# Delete safety rules

> Джерело: розділ `11.5, 12.11` зі старого `my-library-page.md`.

### 11.5. Delete behavior

Дія **Видалити** не має одразу видаляти книгу.

При натисканні потрібно показати confirmation modal.

```text id="jssuz6"
Видалити книгу?

Цю дію не можна буде скасувати.
```

Actions:

```text id="y3bcc1"
Скасувати
Видалити
```

Recommended logic:

* delete action має бути внизу menu;
* delete action має бути візуально відділена від інших дій;
* після підтвердження книга прибирається з бібліотеки;
* якщо використовується soft delete, книга отримує `deletedAt`.

---

### 12.11. Delete books

Action:

```text
Видалити книги
```

Це destructive action, тому перед видаленням потрібно показати confirmation modal.

Modal text:

```text
Видалити вибрані книги?

Цю дію не можна буде скасувати.
```

Actions:

```text
Скасувати
Видалити
```

Logic:

* книги не видаляються без підтвердження;
* після підтвердження вибрані книги видаляються або отримують `deletedAt`;
* після видалення книги зникають зі списку;
* selection очищається;
* summary cards оновлюються.
