# Bulk selection and action rules

> Джерело: розділ `12.2–12.4, 12.12–12.13` зі старого `my-library-page.md`.

### 12.2. Selection behavior

Користувач може вибирати книги через checkbox на картці або в рядку списку.

Logic:

* checkbox показується для кожної книги;
* після вибору першої книги з’являється Bulk actions bar;
* користувач може вибрати кілька книг;
* користувач може зняти вибір з окремої книги;
* користувач може очистити весь selection;
* selected books мають бути візуально виділені.

---

### 12.3. Bulk actions bar

Bulk actions bar показується тільки тоді, коли вибрана хоча б одна книга.

Recommended content:

```text
Обрано: 3 книги    [Додати до списку] [Додати в чергу] [Змінити статус] [Ще...]
```

Bar має містити:

| Element         | Description              |
| --------------- | ------------------------ |
| Selected count  | Кількість вибраних книг  |
| Primary actions | Найчастіші bulk actions  |
| More actions    | Меню з додатковими діями |
| Clear selection | Скидання вибору          |

---

### 12.4. Recommended minimal bulk actions

| Action                   | Logic                                                |
| ------------------------ | ---------------------------------------------------- |
| Додати до списку         | додає вибрані книги до custom list                   |
| Додати в чергу читання   | додає вибрані книги в reading queue                  |
| Змінити статус читання   | оновлює `readingStatus` для вибраних книг            |
| Змінити статус володіння | оновлює `ownershipStatus` для вибраних книг          |
| Додати теги              | додає один або кілька тегів до вибраних книг         |
| Додати в улюблені        | встановлює `isFavorite = true`                       |
| Прибрати з улюблених     | встановлює `isFavorite = false`                      |
| Видалити книги           | відкриває confirmation modal і видаляє вибрані книги |

---

### 12.12. What not to include in bulk actions

Не потрібно додавати bulk actions для даних, які потребують індивідуального заповнення.

Не додавати:

* додати нотатку;
* додати цитату;
* змінити прогрес читання;
* змінити рейтинг;
* змінити дату прочитання;
* змінити дані позики;
* змінити дані доставки;
* змінити номер частини в серії.

Ці дії краще виконувати для однієї книги.

---

### 12.13. Behavior after bulk action

Після виконання bulk action:

* список книг оновлюється;
* selected books очищаються;
* summary cards оновлюються, якщо дія впливає на статистику;
* search залишається активним;
* filters залишаються активними;
* sorting залишається активним;
* view mode не змінюється;
* pagination може залишитися на поточній сторінці, якщо на ній ще є книги.
