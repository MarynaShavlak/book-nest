### 7.8. Book type filter

Фільтр за типом книги.

Options:

| Value         | Label         | Logic                |
| ------------- | ------------- | -------------------- |
| `all`         | Усі           | Показати всі книги   |
| `solo`        | Соло книги    | Книги без `seriesId` |
| `series_part` | Частина серії | Книги з `seriesId`   |

Important:

* конкретну серію не потрібно додавати як основний advanced filter;
* для цього є окрема сторінка **Серії** та сторінка деталей серії;
* у бібліотеці достатньо фільтра **Соло / Частина серії**.
