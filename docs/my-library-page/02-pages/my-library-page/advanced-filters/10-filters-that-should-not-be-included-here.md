### 7.10. Filters that should not be included here

Ці фільтри не потрібно додавати в Advanced filters сторінки **“Моя бібліотека”**, бо для них є окремі сторінки або окремі фічі.

| Filter             | Чому не додавати                                |
| ------------------ | ----------------------------------------------- |
| Улюблені           | Є окрема сторінка **Улюблені книги**            |
| У черзі читання    | Є окрема сторінка **Черга читання**             |
| Власні списки      | Є окрема сторінка **Власні списки**             |
| Конкретна серія    | Є сторінка **Серії** та details page серії      |
| Статус серії       | Це фільтр для сторінки серій                    |
| Прострочені позики | Це логіка сторінки **Позичені книги**           |
| Повернути скоро    | Це логіка сторінки **Позичені книги**           |
| Статус доставки    | Це краще винести на сторінку **Книги в дорозі** |
| Нотатки            | Окрема Notes feature                            |
| Цитати             | Окрема Quotes feature                           |
| Персонажі          | Окрема Characters feature                       |
