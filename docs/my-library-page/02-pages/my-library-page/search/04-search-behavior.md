### 5.4. Search behavior

* пошук не чутливий до регістру;
* зайві пробіли на початку і в кінці ігноруються;
* кілька пробілів всередині запиту мають сприйматися як один;
* пошук має працювати по частковому збігу;
* пошук має працювати українською та англійською мовами;
* для ISBN потрібно ігнорувати дефіси та пробіли;
* search query має комбінуватися з активними фільтрами.

Приклад:

```text
Запит: "wing"
Може знайти: "Fourth Wing"
```

```text
Запит: "яррос"
Може знайти: книги авторки Ребекки Яррос
```

```text
Запит: "978 617"
Може знайти книгу з ISBN "978-617-..."
```
