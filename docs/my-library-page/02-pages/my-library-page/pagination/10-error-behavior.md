### 15.10. Error behavior

Якщо наступну порцію книг не вдалося завантажити:

* вже завантажені книги залишаються на сторінці;
* користувач бачить error message або toast;
* кнопка **Показати ще** залишається доступною для повторної спроби.

Message:

```text
Не вдалося завантажити ще книги
```

Action:

```text
Спробувати ще раз
```
