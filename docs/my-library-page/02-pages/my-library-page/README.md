# My Library Page documentation

Ця папка описує UI та поведінку сторінки **Моя бібліотека**.

Для Claude Code не відкривай всю папку одразу. Бери тільки потрібну секцію:

- `page-entry/` — route, sidebar, access, URL behavior;
- `header/` — title, subtitle, primary action, summary cards;
- `toolbar/` — toolbar layout and base behavior;
- `search/` — search input and behavior;
- `quick-filters/` — top-level filter chips;
- `advanced-filters/` — drawer/popover with detailed filters;
- `active-filters-bar/` — chips for selected filters;
- `sorting/` — sort options and empty values;
- `view-modes/` — grid/list modes;
- `summary-sidebar/` — right sidebar blocks;
- `pagination/` — load more / cursor behavior;
- `states/` — loading, empty, no results and error states.
