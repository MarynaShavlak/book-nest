### 4.2. Toolbar elements

| Element       | Type          | Description                   |
| ------------- | ------------- | ----------------------------- |
| Search        | Input         | Пошук книги                   |
| Filters       | Button        | Відкриває панель фільтрів     |
| Sort          | Dropdown      | Змінює порядок книг           |
| View mode     | Toggle        | Перемикає `grid` / `list`     |
| Results count | Text          | Показує кількість результатів |
| Clear all     | Button / Link | Очищає пошук і фільтри        |
