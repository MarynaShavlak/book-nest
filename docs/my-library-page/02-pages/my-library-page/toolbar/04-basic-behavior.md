### 4.4. Basic behavior

* search input шукає книги за назвою, автором або серією;
* кнопка **Фільтри** відкриває розширені фільтри;
* якщо є активні фільтри, біля кнопки показується count;
* sort dropdown змінює порядок книг;
* view mode перемикає вигляд між grid і list;
* results count оновлюється після пошуку або фільтрації;
* **Очистити все** показується тільки якщо є активний пошук або фільтри.
