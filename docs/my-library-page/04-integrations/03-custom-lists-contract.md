# Custom Lists contract

## Purpose

My Library може додавати одну або кілька книг до кастомного списку.

## Contract

- Single-book action може відкривати `Add to custom list`.
- Bulk action може додавати вибрані книги до одного списку.
- Duplicate prevention має виконуватися на стороні custom lists logic.
- My Library після дії показує success/error state, але не керує деталями списку.

## Related source sections

### 12.5. Add to custom list

Action:

```text
Додати до списку
```

Logic:

* відкриває modal вибору custom list;
* користувач вибирає один список;
* вибрані книги додаються до цього списку;
* якщо книга вже є в списку, вона не дублюється;
* після успішної дії selection можна очистити.

### 11.3. More actions menu

Усі додаткові дії мають бути в меню `...`.

| Action                   | Logic                                                      |
| ------------------------ | ---------------------------------------------------------- |
| Редагувати               | відкриває сторінку редагування книги                       |
| Оновити прогрес          | відкриває modal оновлення прогресу                         |
| Почати читати            | змінює статус на `reading` або відкриває progress modal    |
| Позначити як прочитану   | змінює статус на `finished` або відкриває completion modal |
| Додати в чергу читання   | додає книгу в reading queue                                |
| Додати до списку         | відкриває modal додавання книги до власного списку         |
| Додати нотатку           | відкриває modal створення нотатки                          |
| Додати цитату            | відкриває modal створення цитати                           |
| Змінити статус володіння | відкриває modal або форму зміни ownership status           |
| Видалити                 | відкриває confirm delete modal                             |
