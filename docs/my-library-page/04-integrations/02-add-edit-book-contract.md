# Add / Edit Book contract

## Purpose

My Library є основним місцем, звідки користувач додає нову книгу.

## Contract

- Primary action у header відкриває сценарій створення книги.
- Після створення книга зʼявляється в бібліотеці.
- Після редагування книга оновлюється в поточному списку без stale state.
- Якщо активні filters/search не включають нову або оновлену книгу, сторінка має поводитися передбачувано: або не показувати її в поточному результаті, або показати toast з поясненням.

## Related source sections

### 3.4. Primary action

У header має бути кнопка:

```text
+ Додати книгу
```

### Logic

* кнопка веде на сторінку створення книги;
* рекомендований route:

```text
/books/create
```

---

### 11.6. Behavior after action

Після виконання action:

* список книг має оновитися;
* summary cards мають оновитися, якщо дія впливає на статистику;
* active filters мають залишитися без змін;
* sorting має залишитися без змін;
* view mode має залишитися без змін;
* користувач має бачити success або error state.
