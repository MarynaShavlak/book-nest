# Navigation entry points

> Джерело: розділ `2.1, 2.5` зі старого `my-library-page.md`.

### 2.1. Sidebar navigation

У sidebar має бути пункт меню:

```text
Моя бібліотека
```

Рекомендована позиція в sidebar:

```text
Головна
Моя бібліотека
Серії
Черга читання
Списки
Книги до покупки
Улюблені
Нотатки
Цитати
Статистика
Налаштування
```

Пункт **“Моя бібліотека”** має бути одним із верхніх пунктів меню, бо це основний робочий розділ застосунку.

---

### 2.5. Header action entry point

На сторінці **“Моя бібліотека”** у header має бути основна дія:

```text
+ Додати книгу
```

Після натискання користувач переходить на сторінку створення книги:

```text
/books/create
```

або відкриває форму створення книги, якщо в застосунку використовується modal / drawer flow.

Рекомендований варіант для повної версії:

```text
/books/create
```

Причина: форма створення книги велика, має багато блоків і краще працює як окрема сторінка, а не як маленька modal.
