> Джерело: розділ `5.2, 5.3` зі старого `my-library-page.md`.

### 5.2. Search fields

Пошук має працювати за такими полями:

| Поле              | Приклад                | Пріоритет |
| ----------------- | ---------------------- | --------: |
| Назва книги       | `Четверте крило`       |      High |
| Оригінальна назва | `Fourth Wing`          |      High |
| Автор             | `Ребекка Яррос`        |      High |
| Назва серії       | `Емпіреї`              |      High |
| Видавництво       | `КСД`                  |    Medium |
| Жанри             | `Fantasy`              |    Medium |
| Теги              | `дракони`, `романтика` |    Medium |
| ISBN              | `9786175481234`        |    Medium |
| Перекладач        | `Олена Оксенич`        |       Low |
| Ілюстратор        | `Ім’я ілюстратора`     |       Low |

---

### 5.3. What search should not include

Search у **“Моїй бібліотеці”** не має шукати по:

| Поле / дані   | Причина                                       |
| ------------- | --------------------------------------------- |
| Нотатки       | Це окрема фіча Notes                          |
| Цитати        | Це окрема фіча Quotes                         |
| Персонажі     | Це окрема фіча Characters                     |
| Присвята      | Це деталь видання, не основне поле для пошуку |
| Опис серії    | Це належить до Series details                 |
| Службові поля | `id`, `createdAt`, `updatedAt`, `userId`      |
