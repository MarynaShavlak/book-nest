### 7.5. Format filter

Фільтр за форматом книги.

Options:

| Value       | Label      |
| ----------- | ---------- |
| `paper`     | Паперова   |
| `ebook`     | Електронна |
| `audiobook` | Аудіокнига |

Logic:

* книга може мати один або кілька форматів;
* кілька вибраних форматів працюють як `OR`;
* книги без формату показуються тільки тоді, коли format filter не активний.
