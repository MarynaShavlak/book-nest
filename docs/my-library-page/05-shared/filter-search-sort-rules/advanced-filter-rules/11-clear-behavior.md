### 7.12. Clear behavior

У панелі фільтрів має бути дія:

```text
Очистити фільтри
```

Logic:

* очищає тільки advanced filters;
* не очищає search input;
* не змінює quick filter;
* не змінює sort;
* не змінює view mode.

Дія **Очистити все** має бути глобальною і може очищати:

* search;
* quick filter;
* advanced filters;
* active filter chips.
