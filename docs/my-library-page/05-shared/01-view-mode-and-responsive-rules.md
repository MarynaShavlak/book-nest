# View mode and responsive rules

> Джерело: розділ `10.1–10.7, 13.7` зі старого `my-library-page.md`.

### 10.1. Available view modes

| View mode | Description                            |
| --------- | -------------------------------------- |
| `grid`    | Книги показуються як картки            |
| `list`    | Книги показуються як компактний список |

---

### 10.2. Default view mode

Default view mode:

```text
grid
```

Grid view краще підходить як основний вигляд, бо бібліотека візуально сприймається як книжкова полиця.

---

### 10.3. Grid view

Grid view показує книги у вигляді карток.

Картка книги може містити:

* обкладинку;
* назву книги;
* автора;
* статус читання;
* статус володіння;
* формат;
* рейтинг;
* короткі chips жанрів або тегів;
* quick actions.

Grid view краще підходить для візуального перегляду бібліотеки.

---

### 10.4. List view

List view показує книги у вигляді компактних рядків.

Рядок книги може містити:

* маленьку обкладинку;
* назву книги;
* автора;
* статус читання;
* формат;
* рейтинг;
* рік видання;
* кількість сторінок;
* quick actions.

List view краще підходить для швидкого перегляду великої кількості книг.

---

### 10.5. View mode behavior

* користувач може перемикатися між `grid` і `list`;
* перемикач знаходиться в Library toolbar;
* зміна view mode не очищає search;
* зміна view mode не очищає quick filter;
* зміна view mode не очищає advanced filters;
* зміна view mode не змінює sorting;
* зміна view mode не скидає pagination;
* вибраний view mode має зберігатися як user preference.

---

### 10.7. Responsive behavior

На desktop доступні обидва режими:

```text
grid / list
```

На mobile:

* grid view може показувати 1–2 картки в ряд;
* list view має залишатися компактним;
* перемикач view mode не має ламати toolbar;
* останній вибраний view mode має зберігатися між відкриттями сторінки.

---

### 13.7. Responsive behavior

* на desktop sidebar може показуватися праворуч від списку книг;
* на tablet sidebar може переходити під основний контент;
* на mobile sidebar можна показувати після списку книг або приховувати в collapsible block;
* sidebar не має заважати основному перегляду бібліотеки.
