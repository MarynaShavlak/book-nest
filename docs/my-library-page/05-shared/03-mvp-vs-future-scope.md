# MVP vs future scope

## MVP scope

У MVP для сторінки **Моя бібліотека** достатньо реалізувати:

- список усіх книг користувача;
- route `/library`;
- header + primary action `Додати книгу`;
- summary cards;
- search;
- quick filters;
- advanced filters;
- active filters bar;
- sorting;
- grid/list view;
- book card actions;
- базові bulk actions;
- loading / empty / no results / error states;
- pagination або load more.

## Future scope

Можна відкласти:

- складні saved views;
- AI-рекомендації;
- складні статистичні графіки;
- групування книг по полицях;
- масове редагування всіх можливих полів;
- advanced keyboard shortcuts;
- drag-and-drop для всієї бібліотеки.
