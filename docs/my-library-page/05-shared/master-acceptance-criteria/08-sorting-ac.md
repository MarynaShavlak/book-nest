### 9.8. Acceptance Criteria

* Користувач бачить sorting control у Library toolbar.
* За замовчуванням книги сортуються як **Нещодавно додані**.
* Користувач може змінити sorting option.
* Sorting змінює тільки порядок книг, але не змінює набір результатів.
* Sorting працює разом із search.
* Sorting працює разом із quick filters.
* Sorting працює разом із advanced filters.
* Після зміни sorting pagination скидається на першу сторінку.
* Sorting зберігається в URL query params.
* Після reload сторінки вибране sorting значення відновлюється.
* Книги без значення для вибраного sorting field показуються після книг із заповненим значенням.
