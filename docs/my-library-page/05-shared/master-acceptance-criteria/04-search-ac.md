### 5.10. Acceptance Criteria

* Користувач бачить search input у Library toolbar.
* Користувач може шукати книги за назвою.
* Користувач може шукати книги за оригінальною назвою.
* Користувач може шукати книги за автором.
* Користувач може шукати книги за назвою серії.
* Користувач може шукати книги за видавництвом.
* Користувач може шукати книги за жанрами.
* Користувач може шукати книги за тегами.
* Користувач може шукати книги за ISBN.
* Search не чутливий до регістру.
* Search працює разом з активними фільтрами.
* Search query зберігається в URL.
* Після очищення search input список книг оновлюється.
* Якщо результатів немає, користувач бачить no results state.
* Видалені книги не потрапляють у результати пошуку.
