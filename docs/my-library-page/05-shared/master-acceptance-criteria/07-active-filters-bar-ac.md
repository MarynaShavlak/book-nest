### 8.8. Acceptance Criteria

* Active filters bar показується тільки коли є активний search, quick filter або advanced filter.
* Кожен активний параметр показується як окремий chip.
* Користувач може прибрати окремий filter chip.
* При видаленні chip список книг оновлюється.
* Інші активні фільтри не очищаються.
* Користувач може натиснути **Очистити все**.
* **Очистити все** прибирає search, quick filter і advanced filters.
* Sort і view mode не скидаються після **Очистити все**.
* Active filters bar синхронізується з URL query params.
* Якщо активних параметрів немає, Active filters bar не показується.
