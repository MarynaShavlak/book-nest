### 15.11. Acceptance Criteria

* При відкритті сторінки завантажуються перші 24 книги.
* Якщо книг більше ніж 24, показується кнопка **Показати ще**.
* Кнопка підвантажує наступні 24 книги.
* Нові книги додаються в кінець списку.
* Користувач бачить counter типу **Показано X з Y книг**.
* Під час завантаження кнопка disabled.
* Коли всі книги завантажені, кнопка зникає.
* При зміні search список скидається до першої порції.
* При зміні filters список скидається до першої порції.
* При зміні sorting список скидається до першої порції.
* View mode не скидає завантажені книги.
* Load more state не зберігається в URL.
* Якщо завантаження не вдалося, користувач може повторити спробу.
