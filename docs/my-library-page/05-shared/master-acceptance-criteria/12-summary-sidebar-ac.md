### 13.8. Acceptance Criteria

* Sidebar показує блок Top genres.
* Sidebar показує блок Top tags.
* Sidebar показує 3 останні додані книги.
* Sidebar показує quick links.
* Top genres рахуються тільки по книгах поточного користувача.
* Top tags рахуються тільки по книгах поточного користувача.
* Recently added books показують останні 3 активні книги.
* Клік по recently added book відкриває book details page.
* Quick links ведуть на окремі сторінки.
* Sidebar не дублює summary cards із page header.
* Sidebar не містить повну статистику бібліотеки.
