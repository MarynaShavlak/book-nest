### 10.8. Acceptance Criteria

* Користувач бачить перемикач `grid / list` у Library toolbar.
* За замовчуванням використовується `grid` view.
* Користувач може перемкнути бібліотеку в `list` view.
* Користувач може повернутися назад у `grid` view.
* View mode змінює тільки вигляд списку книг.
* View mode не очищає search.
* View mode не очищає filters.
* View mode не змінює sorting.
* View mode зберігається як user preference.
* Після reload сторінки останній вибраний view mode відновлюється.
* Grid і list view коректно працюють на desktop і mobile.
