### 4.5. Acceptance Criteria

* Toolbar показується під page header.
* Toolbar містить search input.
* Toolbar містить кнопку **Фільтри**.
* Toolbar містить sort dropdown.
* Toolbar містить перемикач grid / list.
* Toolbar показує кількість книг або знайдених результатів.
* Якщо активні фільтри, кнопка **Фільтри** показує count.
* Якщо активний пошук або фільтри, користувач бачить дію **Очистити все**.
* Після очищення пошуку і фільтрів показується повний список книг.
