### 12.2. Selection behavior

Користувач може вибирати книги через checkbox на картці або в рядку списку.

Logic:

* checkbox показується для кожної книги;
* після вибору першої книги з’являється Bulk actions bar;
* користувач може вибрати кілька книг;
* користувач може зняти вибір з окремої книги;
* користувач може очистити весь selection;
* selected books мають бути візуально виділені.
