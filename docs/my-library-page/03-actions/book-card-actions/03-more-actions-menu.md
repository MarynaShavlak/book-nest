### 11.3. More actions menu

Усі додаткові дії мають бути в меню `...`.

| Action                   | Logic                                                      |
| ------------------------ | ---------------------------------------------------------- |
| Редагувати               | відкриває сторінку редагування книги                       |
| Оновити прогрес          | відкриває modal оновлення прогресу                         |
| Почати читати            | змінює статус на `reading` або відкриває progress modal    |
| Позначити як прочитану   | змінює статус на `finished` або відкриває completion modal |
| Додати в чергу читання   | додає книгу в reading queue                                |
| Додати до списку         | відкриває modal додавання книги до власного списку         |
| Додати нотатку           | відкриває modal створення нотатки                          |
| Додати цитату            | відкриває modal створення цитати                           |
| Змінити статус володіння | відкриває modal або форму зміни ownership status           |
| Видалити                 | відкриває confirm delete modal                             |
