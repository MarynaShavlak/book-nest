# Purpose and Scope

## Purpose

Reading Queue — це впорядкований список книг, які користувач планує читати далі.

Модуль потрібен, щоб користувач міг:

- бачити книги в запланованому порядку;
- додавати книгу в чергу зі сторінки деталей книги або зі сторінки черги;
- змінювати порядок книг у черзі;
- швидко починати читання;
- прибирати книгу з черги без видалення її з бібліотеки.

## In scope

- Reading Queue Page.
- Add to Reading Queue.
- Remove from Reading Queue.
- Reorder via drag-and-drop.
- Start Reading from queue.
- Queue position recalculation.
- Queue states: empty, loading, error, no search results.
- Cross-feature updates for Book Details, My Library and Dashboard.

## Out of scope for MVP

- Grid view.
- Complex filters.
- Advanced sorting.
- Load more.
- Queue progress.
- Automatic add next books from series.
- Recommendations.
- Deadlines.
- Priorities.
- Grouping by genres or series.
- Bulk actions.
