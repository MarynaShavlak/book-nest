# Domain Rules

Ця папка описує стабільні правила модуля Reading Queue.

Ці файли потрібно підключати майже до кожної задачі, бо вони визначають:

- які книги входять у чергу;
- як працюють позиції;
- що можна змінювати;
- що не можна змінювати;
- як уникати дублікатів;
- які оновлення мають бути атомарними.
