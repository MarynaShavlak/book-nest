# What Should Not Change

## Add to queue should not change

- reading status;
- ownership status;
- format;
- favorite state;
- custom lists;
- delivery state;
- loan state;
- series relation;
- rating;
- notes;
- quotes.

## Remove from queue should not change

- book existence in library;
- reading status;
- ownership status;
- format;
- favorite state;
- custom lists;
- delivery state;
- loan state;
- series relation.

## Reorder should not change

- book data;
- statuses;
- queue membership;
- total queue count.

Reorder changes only positions.
