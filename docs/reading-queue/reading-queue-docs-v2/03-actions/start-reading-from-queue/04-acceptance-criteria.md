# Start Reading Acceptance Criteria

- Each queue item has **Почати читати** action.
- Clicking action opens confirmation modal.
- Modal explains that status will change to **Читаю**.
- Modal has checkbox **Прибрати книгу з черги після початку читання**.
- Checkbox is checked by default.
- Confirm changes reading status to `reading`.
- If checkbox is checked, book is removed from queue.
- If checkbox is unchecked, book remains in queue.
- If book remains in queue, item shows **Читаю зараз** badge.
- Dashboard **Читаю зараз** block updates.
