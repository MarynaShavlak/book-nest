# Start Reading Action UI

На кожній книзі в черзі має бути кнопка:

```text
Почати читати
```

Action відкриває confirmation modal.

### Modal title

```text
Почати читати?
```

### Modal text

```text
Статус книги зміниться на “Читаю”.
```

### Checkbox

```text
Прибрати книгу з черги після початку читання
```

Default:

```text
checked = true
```

### Actions

```text
Скасувати
Почати читати
```
