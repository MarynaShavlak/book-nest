# UI Updates After Start Reading

After confirm:

- book `readingStatus` changes to `reading`;
- Dashboard block **Читаю зараз** updates;
- Reading Queue Page updates;
- if checkbox was checked, queue positions are recalculated;
- if checkbox was unchecked, item stays in queue and shows **Читаю зараз** badge;
- My Library card updates;
- Book Details updates if open elsewhere.
