# Book Selection Contract

## Selectable books

Modal should allow selecting books from user's library.

Do not show:

- deleted books;
- books from other users;
- books already in queue, unless shown as disabled;
- unavailable/invalid book records.

## Search inside modal

Recommended searchable fields:

- title;
- original title;
- author;
- series;
- genres;
- tags.

## After select

Show selected book preview and position selection.
