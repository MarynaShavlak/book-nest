# Submit Behavior

Після натискання:

```text
Додати в чергу
```

система має:

1. перевірити, чи книга вже є в черзі;
2. якщо книга не в черзі — додати її;
3. призначити позицію згідно з вибором користувача;
4. якщо потрібно — змістити інші книги нижче;
5. оновити Book Details UI;
6. оновити сторінку Reading Queue, якщо вона вже відкрита в іншому місці застосунку;
7. показати success message.

Success message:

```text
Книгу додано в чергу читання
```

Після успішного submit modal закривається.
