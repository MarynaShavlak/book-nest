# Book Preview in Modal

У верхній частині modal потрібно показати коротке preview книги.

| Element          | Description               |
| ---------------- | ------------------------- |
| Cover            | Обкладинка книги          |
| Title            | Назва книги               |
| Author           | Автор                     |
| Reading status   | Поточний статус читання   |
| Ownership status | Поточний статус володіння |

Example:

```text
Четверте крило
Ребекка Яррос

Статус читання: Хочу прочитати
Статус володіння: Маю
```
