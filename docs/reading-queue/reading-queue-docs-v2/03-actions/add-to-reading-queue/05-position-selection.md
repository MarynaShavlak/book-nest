# Queue Position Selection

Користувач має вибрати, куди саме додати книгу в черзі.

Available options:

```text
На початок черги
У кінець черги
На конкретну позицію
```

Default option:

```text
У кінець черги
```

Recommended UI:

```text
Куди додати книгу?

( ) На початок черги
(•) У кінець черги
( ) На конкретну позицію
```

Якщо користувач обирає **На конкретну позицію**, потрібно показати додаткове поле:

```text
Позиція в черзі
```

Example:

```text
Позиція: 3
```

Helper text:

```text
Якщо на цій позиції вже є книга, вона та всі наступні книги змістяться нижче.
```
