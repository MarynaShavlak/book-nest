# Entry Point

Дія доступна на сторінці **Book Details**.

Recommended location:

```text
Book Details → Right sidebar → Quick actions
```

Action label, якщо книги ще немає в черзі:

```text
Додати в чергу читання
```

Якщо книга вже є в черзі, замість цієї дії потрібно показувати статус:

```text
У черзі · позиція N
```

і окрему дію:

```text
Прибрати з черги
```

Example:

```text
У черзі · позиція 4
Прибрати з черги
```

---

# When Action Is Available

Action **Додати в чергу читання** доступна, якщо:

* книга належить поточному користувачу;
* книга не видалена;
* книги ще немає в черзі.

Action не потрібно блокувати через reading status або ownership status.

Користувач може додати в чергу книгу зі статусом:

* Не почато;
* Хочу прочитати;
* Читаю;
* На паузі;
* Прочитано;
* Покинуто;
* Немає;
* Хочу купити;
* В дорозі;
* Маю;
* Позичена у когось;
* Видана комусь.

Reason:

```text
Черга читання — це план користувача, а не автоматична залежність від статусів.
```

Наприклад, користувач може додати прочитану книгу в чергу, якщо хоче перечитати її пізніше.
