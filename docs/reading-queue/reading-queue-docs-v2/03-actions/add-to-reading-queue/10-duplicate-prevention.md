# Duplicate Prevention

Одна книга не може бути додана в чергу кілька разів.

Якщо користувач намагається додати книгу, яка вже є в черзі:

* новий запис у черзі не створюється;
* позиція книги не дублюється;
* користувач бачить повідомлення.

Message:

```text
Книга вже є в черзі читання
```

На Book Details у цьому випадку має показуватися:

```text
У черзі · позиція N
```
