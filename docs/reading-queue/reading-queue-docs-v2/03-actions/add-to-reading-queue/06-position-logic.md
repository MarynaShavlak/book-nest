# Position Logic

### 9.1. Add to the beginning

Якщо користувач обрав:

```text
На початок черги
```

книга стає першою в черзі.

Усі інші книги зміщуються нижче.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Додаємо Книгу D на початок

Стало:
1. Книга D
2. Книга A
3. Книга B
4. Книга C
```

---

### 9.2. Add to the end

Якщо користувач обрав:

```text
У кінець черги
```

книга додається після всіх книг у черзі.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Додаємо Книгу D у кінець

Стало:
1. Книга A
2. Книга B
3. Книга C
4. Книга D
```

---

### 9.3. Add to specific position

Якщо користувач обрав:

```text
На конкретну позицію
```

він має вказати номер позиції.

Example:

```text
Позиція: 2
```

Якщо на цій позиції вже є книга, нова книга вставляється на вказане місце, а книга, яка була на цій позиції, разом з усіма наступними зміщується нижче.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Додаємо Книгу D на позицію 2

Стало:
1. Книга A
2. Книга D
3. Книга B
4. Книга C
```
