# Empty Queue Behavior

Якщо черга порожня, будь-який варіант позиції додає книгу на позицію 1.

Result:

```text
position = 1
```

Recommended behavior:

* залишити всі options доступними;
* але якщо користувач обрав **На конкретну позицію**, дозволити тільки позицію `1`;
* helper text може пояснити, що це буде перша книга в черзі.

Example:

```text
Черга поки порожня. Книга буде додана на позицію 1.
```
