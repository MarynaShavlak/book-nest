# Drag-and-drop Reorder

Користувач може змінювати порядок книг у черзі через drag-and-drop.

Drag-and-drop доступний, якщо:

* немає активного search;
* список відсортований за позицією;
* сторінка не перебуває в loading state.

Після перетягування:

1. книга переміщується на нову позицію;
2. інші книги зміщуються відповідно;
3. позиції перераховуються;
4. новий порядок зберігається;
5. UI одразу показує оновлений порядок.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Користувач перемістив Книгу C на перше місце

Стало:
1. Книга C
2. Книга A
3. Книга B
```
