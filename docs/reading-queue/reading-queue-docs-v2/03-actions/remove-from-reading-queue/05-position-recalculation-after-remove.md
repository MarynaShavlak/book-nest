# Position Recalculation After Remove

Після прибирання книги з черги позиції інших книг мають оновитися.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C
4. Книга D

Користувач прибрав Книгу B

Стало:
1. Книга A
2. Книга C
3. Книга D
```

Important:

* у черзі не має бути пропусків у позиціях;
* позиції мають залишатися послідовними;
* Book Details має показувати актуальну позицію, якщо книга залишилась у черзі.
