# Undo Remove Logic

Якщо користувач натискає **Скасувати** в toast:

* книга повертається в чергу;
* бажано повернути її на попередню позицію;
* якщо попередня позиція вже недоступна, книга додається максимально близько до попереднього місця;
* Book Details знову показує статус **У черзі · позиція N**.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Користувач прибрав Книгу B

Стало:
1. Книга A
2. Книга C

Користувач натиснув Undo

Стало:
1. Книга A
2. Книга B
3. Книга C
```

# Remove from Queue Toast

Після прибирання книги з черги показати toast:

```text
Книгу прибрано з черги
```

Toast action:

```text
Скасувати
```

Якщо користувач натискає **Скасувати**:

* книга повертається в чергу;
* бажано повернути її на попередню позицію;
* список оновлюється;
* позиції знову перераховуються.
