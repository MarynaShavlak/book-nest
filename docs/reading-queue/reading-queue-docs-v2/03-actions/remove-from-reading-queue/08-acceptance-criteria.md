# Remove from Queue Acceptance Criteria

- User can remove a book from queue on Book Details when the book is already in queue.
- User can remove a book from Reading Queue Page item menu.
- Book is removed only from Reading Queue.
- Book remains in library.
- Reading status does not change.
- Ownership status does not change.
- Queue positions are recalculated.
- UI shows updated queue count.
- Book Details no longer shows `У черзі · позиція N`.
- User sees toast after removal.
- Undo restores the book to queue.
- If possible, undo restores previous position.
- Failed remove rolls UI back to previous state.
