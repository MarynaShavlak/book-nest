# Remove from Queue Overview and Entry Points

## Entry points

Remove from queue exists in two places:

1. Book Details quick actions.
2. Reading Queue Page item more actions.

## Labels

On Book Details:

```text
Прибрати з черги
```

On Reading Queue Page:

```text
Прибрати з черги
```

## Core behavior

- remove only queue item;
- keep book in library;
- do not change reading status;
- do not change ownership status;
- recalculate positions.
