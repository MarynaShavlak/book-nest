# Sorting

Для MVP основне сортування:

```text
Позиція в черзі
```

Logic:

```text
position ASC
```

Це default sorting і головний порядок сторінки.

У MVP не потрібно додавати сортування за назвою, автором, рейтингом або датою додавання.

Important:

```text
Drag-and-drop доступний тільки при сортуванні “Позиція в черзі”.
```

Якщо в майбутньому будуть додані інші варіанти сортування, під час їх використання drag-and-drop потрібно вимикати.
