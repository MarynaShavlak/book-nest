# Queue List

Основний блок сторінки — це вертикальний список книг у черзі.

Для MVP використовується тільки list view.

Grid view не входить у MVP, бо для черги головне — порядок, а list view краще показує послідовність книг.

Кожен елемент списку має показувати:

| Element          | Required | Description                 |
| ---------------- | -------: | --------------------------- |
| Drag handle      |      Так | Елемент для перетягування   |
| Position         |      Так | Номер книги в черзі         |
| Cover            |      Так | Обкладинка або placeholder  |
| Title            |      Так | Назва книги                 |
| Author           |      Так | Автор                       |
| Reading status   |      Так | Поточний статус читання     |
| Ownership status |      Так | Поточний статус володіння   |
| Series info      |       Ні | Якщо книга є частиною серії |
| Pages count      |       Ні | Кількість сторінок, якщо є  |
| Start reading    |      Так | Основна дія                 |
| View book        |      Так | Перехід до деталей книги    |
| More actions     |      Так | Додаткові дії               |
