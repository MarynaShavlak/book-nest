# Next to Read Sidebar Block

На desktop можна показувати правий sidebar.

Для MVP достатньо одного головного блоку:

```text
Наступна до читання
```

Цей блок показує першу книгу в черзі.

Logic:

```text
position = 1
```

У блоці показати:

* cover;
* title;
* author;
* reading status badge;
* pages count, якщо є;
* кнопку **Почати читати**.

Якщо черга порожня, блок не показується або показує empty text:

```text
Додайте книгу в чергу, щоб побачити наступну до читання.
```
