# Page Header

Page header має показувати назву сторінки, короткий опис, кількість книг у черзі та основну дію.

### Title

```text
Черга читання
```

### Subtitle

```text
Ваш упорядкований список того, що читати далі
```

### Count badge

Показує кількість книг у черзі.

Example:

```text
9 книг
```

### Primary action

```text
+ Додати книгу в чергу
```

Behavior:

* відкриває modal додавання книги в чергу;
* користувач може вибрати книгу зі своєї бібліотеки;
* після додавання книга з’являється у списку черги.
