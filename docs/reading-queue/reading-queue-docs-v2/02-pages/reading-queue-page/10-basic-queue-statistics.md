# Basic Queue Statistics

У MVP можна показати коротку статистику в sidebar.

Recommended statistics:

| Metric          | Logic                                                       |
| --------------- | ----------------------------------------------------------- |
| Книг у черзі    | Загальна кількість книг у черзі                             |
| Загальний обсяг | Сума сторінок усіх книг у черзі, якщо pages count доступний |

Optional, not required for MVP:

* середня довжина книги;
* додано із серій;
* прогрес черги.

Important:

```text
Прогрес черги не входить у MVP.
```

Його краще додати пізніше, коли буде зрозуміло, як саме рахувати прогрес: за прочитаними книгами, прибраними з черги або поточним reading status.
