# Page Overview

Сторінка **“Черга читання”** дозволяє користувачу бачити впорядкований список книг, які він планує читати далі.

Ця сторінка відповідає на головне питання:

```text
Що я буду читати наступним?
```

Фіча потрібна, щоб користувач міг:

* бачити книги в запланованому порядку;
* змінювати порядок книг у черзі;
* швидко почати читати першу або будь-яку іншу книгу;
* перейти до деталей книги;
* прибрати книгу з черги без видалення її з бібліотеки.

---

# Page Entry Point

Сторінка має бути доступна з основної навігації застосунку.

Sidebar item:

```text
Черга читання
```

Recommended route:

```text
/reading-queue
```

Пункт **“Черга читання”** має бути активним, коли користувач перебуває на сторінці `/reading-queue`.

---

# Page Access Rules

Сторінка доступна тільки авторизованому користувачу.

Користувач має бачити тільки свої книги в черзі.

На сторінці не мають відображатися:

* книги інших користувачів;
* видалені книги;
* книги, які не додані в чергу;
* чужі queue items.

Якщо користувач не авторизований, його потрібно перенаправити на login page.

---

# Displayed Books Rules

На сторінці **“Черга читання”** відображаються тільки книги, які користувач додав у reading queue.

Основна умова:

```text
book is in reading queue
```

Default order:

```text
position ASC
```

Тобто першою показується книга з позицією `1`, потім `2`, `3` і так далі.

Important:

* черга має бути впорядкованою;
* кожна книга має мати позицію;
* позиції мають бути послідовними без пропусків;
* одна книга не може бути в черзі двічі.
