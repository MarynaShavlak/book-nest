# Drag Disabled by Search or Sort

## Drag disabled by search

If search is active:

```text
drag-and-drop disabled
```

Reason:

Користувач бачить тільки частину черги, тому зміна порядку в search results може бути незрозумілою.

## Drag disabled by sort

If sorting is not `position ASC`:

```text
drag-and-drop disabled
```

Reason:

Manual order only makes sense when visible list equals actual queue order.
