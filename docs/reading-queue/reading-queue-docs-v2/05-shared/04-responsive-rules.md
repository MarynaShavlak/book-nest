# Responsive Rules

## Desktop

Desktop can show:

- page header;
- toolbar;
- vertical queue list;
- right sidebar with **Наступна до читання**;
- basic queue statistics.

## Tablet

Tablet can keep list layout and hide or move sidebar below the list.

## Mobile

Mobile should prioritize:

- search;
- list items;
- primary item actions;
- position display;
- more actions menu.

Recommended mobile behavior:

- hide right sidebar or move it below list;
- keep drag handle accessible but not visually dominant;
- avoid dense metadata;
- keep **Почати читати** visible.
