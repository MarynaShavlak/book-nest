# Drag-and-drop Acceptance Criteria
### Drag-and-drop

* Користувач може змінити порядок книг через drag-and-drop.
* Після reorder позиції книг оновлюються.
* Новий порядок зберігається.
* Drag-and-drop disabled, якщо search активний.
* Drag-and-drop disabled під час loading.
* Позиції книг залишаються послідовними без пропусків.
