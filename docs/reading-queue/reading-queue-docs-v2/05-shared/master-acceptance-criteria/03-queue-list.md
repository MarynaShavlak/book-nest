# Queue list Acceptance Criteria
### Queue list

* На сторінці показується список книг у черзі.
* Книги відсортовані за позицією в черзі.
* Кожна книга має позицію.
* Кожна книга має drag handle.
* Кожна книга показує обкладинку або placeholder.
* Кожна книга показує назву.
* Кожна книга показує автора.
* Кожна книга показує reading status.
* Кожна книга показує ownership status.
* Якщо книга є частиною серії, показується series info.
* Користувач може перейти до деталей книги.
