# States Acceptance Criteria
### States

* Якщо черга порожня, показується empty state.
* Empty state має action **Додати книгу в чергу**.
* Empty state має action **Перейти до бібліотеки**.
* Під час завантаження показується loading state.
* Якщо чергу не вдалося завантажити, показується error state.
* Error state має action **Спробувати ще раз**.
