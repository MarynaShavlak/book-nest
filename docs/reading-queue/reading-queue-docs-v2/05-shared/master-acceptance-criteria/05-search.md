# Search Acceptance Criteria
### Search

* Користувач може шукати книги в черзі.
* Search працює за назвою.
* Search працює за автором.
* Search працює за серією.
* Search працює за жанрами й тегами.
* Якщо search нічого не знайшов, показується no search results state.
* Користувач може очистити search.
