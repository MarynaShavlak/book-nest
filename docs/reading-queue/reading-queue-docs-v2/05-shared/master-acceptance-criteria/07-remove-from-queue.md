# Remove from queue Acceptance Criteria
### Remove from queue

* Користувач може прибрати книгу з черги.
* Прибирання з черги не видаляє книгу з бібліотеки.
* Прибирання з черги не змінює reading status.
* Прибирання з черги не змінює ownership status.
* Після прибирання позиції інших книг перераховуються.
* Після прибирання показується toast **Книгу прибрано з черги**.
* Toast має action **Скасувати**.
* При натисканні **Скасувати** книга повертається в чергу.
