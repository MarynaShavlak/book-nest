# MVP vs Future Scope

## MVP

- Reading Queue Page.
- Add to queue from Book Details.
- Add to queue from Reading Queue Page.
- Remove from queue.
- Undo remove.
- Drag-and-drop reorder.
- Search in queue.
- Sort by position.
- Start reading.
- View book.
- Empty/loading/error/no search results states.
- Next to read sidebar.
- Basic statistics.

## Future

- Grid view.
- Advanced filters.
- Advanced sorting.
- Load more.
- Focus week block.
- Queue progress.
- Estimated reading time.
- Automatic add next books from series.
- Recommendations.
- Deadlines.
- Priorities.
- Grouping by genres.
- Grouping by series.
- Bulk actions.
