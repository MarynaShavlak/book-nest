# Statistics Contract

## Basic queue statistics

Reading Queue may provide:

- total books in queue;
- total pages in queue.

## Update after actions

Statistics update after:

- add to queue;
- remove from queue;
- start reading with remove checked;
- book pages count change, if supported elsewhere.

## Not MVP

Queue progress is not part of MVP.

Possible future definitions:

- progress by removed books;
- progress by finished books;
- progress by current reading status.
