# Navigation Entry Points

## Sidebar

Main sidebar item:

```text
Черга читання
```

Route:

```text
/reading-queue
```

The sidebar item should be active when user is on `/reading-queue`.

## Book Details

Recommended quick action location:

```text
Book Details → Right sidebar → Quick actions
```

Action labels:

```text
Додати в чергу читання
У черзі · позиція N
Прибрати з черги
```

## Reading Queue Page

Primary action:

```text
+ Додати книгу в чергу
```

Queue item actions:

```text
Почати читати
Переглянути книгу
Прибрати з черги
```
