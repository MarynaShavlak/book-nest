# Feature: Reading Queue Page

## 1. Purpose

Сторінка **“Черга читання”** дозволяє користувачу бачити впорядкований список книг, які він планує читати далі.

Ця сторінка відповідає на головне питання:

```text
Що я буду читати наступним?
```

Фіча потрібна, щоб користувач міг:

* бачити книги в запланованому порядку;
* змінювати порядок книг у черзі;
* швидко почати читати першу або будь-яку іншу книгу;
* перейти до деталей книги;
* прибрати книгу з черги без видалення її з бібліотеки.

---

## 2. Page entry point

Сторінка має бути доступна з основної навігації застосунку.

Sidebar item:

```text
Черга читання
```

Recommended route:

```text
/reading-queue
```

Пункт **“Черга читання”** має бути активним, коли користувач перебуває на сторінці `/reading-queue`.

---

## 3. Page access rules

Сторінка доступна тільки авторизованому користувачу.

Користувач має бачити тільки свої книги в черзі.

На сторінці не мають відображатися:

* книги інших користувачів;
* видалені книги;
* книги, які не додані в чергу;
* чужі queue items.

Якщо користувач не авторизований, його потрібно перенаправити на login page.

---

## 4. What books are displayed

На сторінці **“Черга читання”** відображаються тільки книги, які користувач додав у reading queue.

Основна умова:

```text
book is in reading queue
```

Default order:

```text
position ASC
```

Тобто першою показується книга з позицією `1`, потім `2`, `3` і так далі.

Important:

* черга має бути впорядкованою;
* кожна книга має мати позицію;
* позиції мають бути послідовними без пропусків;
* одна книга не може бути в черзі двічі.


## 7. Search in queue

Search потрібен, щоб користувач міг швидко знайти книгу в черзі.

Placeholder:

```text
Пошук у черзі...
```

Search має працювати тільки серед книг, які вже є в черзі.

Search fields:

* назва книги;
* оригінальна назва;
* автор;
* серія;
* жанри;
* теги.

Search behavior:

* search не чутливий до регістру;
* зайві пробіли ігноруються;
* пошук працює по частковому збігу;
* якщо search input порожній, показується вся черга.

Important:

```text
Якщо search активний, drag-and-drop має бути disabled.
```

Reason:

Користувач бачить тільки частину черги, тому зміна порядку в search results може бути незрозумілою.

## 8. Sorting



У MVP не потрібно додавати сортування за назвою, автором, рейтингом або датою додавання.

## 11. Position display

Кожна книга в черзі має показувати свою позицію.

Example:

```text
1
2
3
4
```

Position behavior:

* позиції починаються з `1`;
* позиції мають бути послідовними;
* після drag-and-drop позиції оновлюються;
* після remove from queue позиції перераховуються;
* після додавання нової книги позиції оновлюються відповідно до місця вставки.

---

## 12. Drag-and-drop reorder

Користувач може змінювати порядок книг у черзі через drag-and-drop.

Drag-and-drop доступний, якщо:

* немає активного search;
* список відсортований за позицією;
* сторінка не перебуває в loading state.

Після перетягування:

1. книга переміщується на нову позицію;
2. інші книги зміщуються відповідно;
3. позиції перераховуються;
4. новий порядок зберігається;
5. UI одразу показує оновлений порядок.

Example:

```text
Було:
1. Книга A
2. Книга B
3. Книга C

Користувач перемістив Книгу C на перше місце

Стало:
1. Книга C
2. Книга A
3. Книга B
```

---

## 13. Drag-and-drop disabled states

Drag-and-drop має бути disabled, якщо:

* search активний;
* список не відсортований за позицією;
* дані завантажуються;
* попередній reorder ще зберігається;
* сталася помилка завантаження списку.

Якщо drag-and-drop disabled через search, можна показати hint:

```text
Очистіть пошук, щоб змінити порядок книг у черзі.
```



## 15. Start reading logic

Після підтвердження:

1. reading status книги змінюється на `reading`;
2. книга з’являється на Dashboard у блоці **Читаю зараз**;
3. якщо checkbox увімкнений, книга прибирається з черги;
4. якщо checkbox вимкнений, книга залишається в черзі з badge **Читаю зараз**;
5. UI сторінки оновлюється.

### If checkbox is checked

```text
readingStatus → reading
book removed from queue
positions recalculated
```

### If checkbox is unchecked

```text
readingStatus → reading
book stays in queue
item shows badge “Читаю зараз”
```

Recommended default:

```text
Прибрати книгу з черги після початку читання = checked
```

Reason:

Черга — це план того, що читати далі. Якщо книга вже почата, найчастіше її потрібно прибрати з плану наступних книг.

## 16. View book action

На кожній книзі має бути кнопка:

```text
Переглянути книгу
```

Behavior:

* відкриває Book Details page;
* route:

```text
/books/:bookId
```

* повернення назад має повертати користувача до Reading Queue page.

---

## 17. Remove from queue

Користувач може прибрати книгу з черги через More actions menu.

Action label:

```text
Прибрати з черги
```

Behavior:

* книга видаляється тільки з черги;
* книга залишається в бібліотеці;
* reading status не змінюється;
* ownership status не змінюється;
* format не змінюється;
* позиції інших книг перераховуються.

Confirmation modal для MVP не потрібна.

Reason:

```text
Це не destructive action, бо книга не видаляється з бібліотеки.
```

---

## 18. Remove from queue toast

Після прибирання книги з черги показати toast:

```text
Книгу прибрано з черги
```

Toast action:

```text
Скасувати
```

Якщо користувач натискає **Скасувати**:

* книга повертається в чергу;
* бажано повернути її на попередню позицію;
* список оновлюється;
* позиції знову перераховуються.

## 21. Empty state

Empty state показується, якщо в користувача немає жодної книги в черзі.

When to show:

```text
queueCount = 0
search is empty
```

Title:

```text
Черга читання порожня
```

Description:

```text
Додайте книги, які хочете прочитати наступними, щоб завжди мати план читання.
```

Primary action:

```text
Додати книгу в чергу
```

Secondary action:

```text
Перейти до бібліотеки
```

Behavior:

* **Додати книгу в чергу** відкриває modal додавання книги;
* **Перейти до бібліотеки** веде на `/library`.

---

## 22. No search results state

No search results state показується, якщо черга не порожня, але search нічого не знайшов.

When to show:

```text
queueCount > 0
search is active
resultsCount = 0
```

Title:

```text
Нічого не знайдено
```

Description:

```text
Спробуйте змінити пошуковий запит або очистити пошук.
```

Action:

```text
Очистити пошук
```

Behavior:

* очищає search input;
* показує повний список черги;
* не змінює порядок книг.

---

## 23. Loading state

Loading state показується, коли сторінка очікує дані.

UI:

* skeleton для header count;
* skeleton для toolbar;
* skeleton для queue items;
* skeleton для sidebar, якщо він показується.

Behavior:

* не показувати empty state під час loading;
* не дозволяти drag-and-drop під час loading;
* actions мають бути disabled до завершення завантаження.

---

## 24. Error state

Error state показується, якщо чергу не вдалося завантажити.

Title:

```text
Не вдалося завантажити чергу читання
```

Description:

```text
Спробуйте оновити сторінку або повторити запит трохи пізніше.
```

Action:

```text
Спробувати ще раз
```

Якщо помилка сталася після action, наприклад reorder або remove, показати toast:

```text
Не вдалося оновити чергу читання
```

---

## 25. State priority

Якщо одночасно можливі кілька states, застосовується такий порядок:

```text
1. Loading
2. Error
3. Empty queue
4. No search results
5. Default queue list
```

Important:

* loading має найвищий пріоритет;
* empty queue показується тільки коли в черзі немає жодної книги;
* no search results показується тільки тоді, коли черга не порожня.

---

## 26. UI updates after actions

Після будь-якої дії на сторінці мають оновитися:

* список черги;
* позиції книг;
* count badge у header;
* sidebar block **Наступна до читання**;
* queue statistics;
* Book Details, якщо ця книга відкрита в іншому місці застосунку;
* My Library card, якщо там показується badge **У черзі**;
* Dashboard, якщо там показується блок черги.

---

## 27. What is not included in MVP

У MVP не входить:

* grid view;
* складні фільтри;
* advanced sorting за назвою, автором, рейтингом;
* load more;
* focus week block;
* progress queue;
* estimated reading time, якщо ця логіка ще не готова;
* automatic add next books from series;
* recommendations;
* deadlines;
* priorities;
* grouping by genres;
* grouping by series;
* bulk actions;
* full delivery / purchase / loan logic.

Ці можливості можна додати пізніше як окремі features.

## 28. Acceptance Criteria

### General

* Користувач може відкрити сторінку **Черга читання**.
* Сторінка доступна тільки авторизованому користувачу.
* Користувач бачить тільки свої книги в черзі.
* Видалені книги не відображаються.
* У sidebar є пункт **Черга читання**.
* Route сторінки — `/reading-queue`.

### Page header

* На сторінці є title **Черга читання**.
* На сторінці є subtitle.
* На сторінці показується кількість книг у черзі.
* На сторінці є primary action **+ Додати книгу в чергу**.

### Queue list

* На сторінці показується список книг у черзі.
* Книги відсортовані за позицією в черзі.
* Кожна книга має позицію.
* Кожна книга має drag handle.
* Кожна книга показує обкладинку або placeholder.
* Кожна книга показує назву.
* Кожна книга показує автора.
* Кожна книга показує reading status.
* Кожна книга показує ownership status.
* Якщо книга є частиною серії, показується series info.
* Користувач може перейти до деталей книги.

### Drag-and-drop

* Користувач може змінити порядок книг через drag-and-drop.
* Після reorder позиції книг оновлюються.
* Новий порядок зберігається.
* Drag-and-drop disabled, якщо search активний.
* Drag-and-drop disabled під час loading.
* Позиції книг залишаються послідовними без пропусків.

### Search

* Користувач може шукати книги в черзі.
* Search працює за назвою.
* Search працює за автором.
* Search працює за серією.
* Search працює за жанрами й тегами.
* Якщо search нічого не знайшов, показується no search results state.
* Користувач може очистити search.

### Start reading

* Користувач бачить кнопку **Почати читати** на кожній книзі.
* При натисканні **Почати читати** відкривається confirmation modal.
* Modal пояснює, що статус зміниться на **Читаю**.
* Modal має checkbox **Прибрати книгу з черги після початку читання**.
* Checkbox увімкнений за замовчуванням.
* Після підтвердження reading status змінюється на `reading`.
* Якщо checkbox увімкнений, книга прибирається з черги.
* Якщо checkbox вимкнений, книга залишається в черзі з badge **Читаю зараз**.

### Remove from queue

* Користувач може прибрати книгу з черги.
* Прибирання з черги не видаляє книгу з бібліотеки.
* Прибирання з черги не змінює reading status.
* Прибирання з черги не змінює ownership status.
* Після прибирання позиції інших книг перераховуються.
* Після прибирання показується toast **Книгу прибрано з черги**.
* Toast має action **Скасувати**.
* При натисканні **Скасувати** книга повертається в чергу.

### Sidebar

* Sidebar показує блок **Наступна до читання**, якщо черга не порожня.
* Блок **Наступна до читання** показує книгу з позицією `1`.
* У sidebar показується кількість книг у черзі.
* У sidebar може показуватися загальний обсяг сторінок.

### States

* Якщо черга порожня, показується empty state.
* Empty state має action **Додати книгу в чергу**.
* Empty state має action **Перейти до бібліотеки**.
* Під час завантаження показується loading state.
* Якщо чергу не вдалося завантажити, показується error state.
* Error state має action **Спробувати ще раз**.
