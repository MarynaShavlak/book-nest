# Quotes Page Layout

## Layout structure

```text
Sidebar | Main content | Right sidebar
```

## Main content

```text
Header
Search
Quick filters
Advanced filters + sort + add button
Quote cards grid
Pagination
```

## Right sidebar

```text
Statistics card
Quick filters card
Decorative quote card
Add first quote / CTA card
```

## Header section

Header contains:

- title `Цитати`;
- subtitle;
- decorative branch in BookNest style.

Example:

```text
Цитати
Ваш особистий архів улюблених книжкових фраз
```

## Grid

Recommended desktop grid:

```text
2 columns
```

For wider layout:

```text
2–3 columns
```

Mobile:

```text
1 column
```

## Card density

Quote cards should not be too tall. Long quotes should be truncated with a “Показати більше” action.

Recommended quote preview length:

```text
240–320 characters
```

## Pagination

Recommended MVP:

```text
pagination
```

Alternative:

```text
infinite scroll
```

Pagination is easier for predictable UX.
