# Quotes Page Overview

## Route

```text
/quotes
```

## Page title

```text
Цитати
```

## Subtitle

Recommended atmospheric subtitle:

```text
Ваш особистий архів улюблених книжкових фраз
```

Alternative:

```text
Усі ваші цитати з книг
```

## Purpose

The Quotes page is a personal archive of all quotes saved by the user from all books.

For MVP, this page can be delayed. Initial MVP can use only Book Details quotes section.

## Page should include

- sidebar navigation;
- page header;
- search input;
- quick filters;
- advanced filters;
- sorting control;
- `+ Додати цитату` button;
- quote cards grid;
- right sidebar with statistics and quick filters;
- pagination or infinite scroll;
- empty state.

## Main user actions

- search quote;
- filter quotes;
- sort quotes;
- open full quote;
- show/hide spoiler;
- favorite/unfavorite quote;
- edit quote;
- delete quote;
- go to book;
- add new quote.
