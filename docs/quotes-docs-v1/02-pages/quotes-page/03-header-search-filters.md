# Quotes Page Header, Search and Filters

## Header actions

Header actions:

```text
+ Додати цитату
```

If user adds quote from standalone Quotes page, book selection is required first.

## Search input

Placeholder:

```text
Пошук цитат...
```

Search should be placed under the page subtitle.

## Quick filters

Recommended quick filters:

```text
Усі
Без спойлерів
Зі спойлерами
Улюблені
З коментарем
```

Active filter should use BookNest accent color.

## Advanced filters

Dropdowns:

```text
Книга
Автор
Жанр
```

Optional:

```text
Дата додавання
Коментар
```

## Sorting dropdown

Default:

```text
Нові спочатку
```

Options:

```text
Нові спочатку
Старі спочатку
За назвою книги
За автором
За сторінкою
Спочатку улюблені
Спочатку без спойлерів
Спочатку зі спойлерами
```

## Empty search result

If filters produce no results:

```text
Нічого не знайдено
Спробуйте змінити запит або очистити фільтри.
```

Action:

```text
Скинути фільтри
```
