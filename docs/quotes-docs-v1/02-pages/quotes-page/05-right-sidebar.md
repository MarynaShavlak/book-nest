# Quotes Page Right Sidebar

## Purpose

Right sidebar gives quick overview and shortcuts.

## Statistics card

Title:

```text
Статистика
```

Rows:

```text
Усього цитат: 128
Улюблених: 36
Зі спойлерами: 18
Без спойлерів: 110
```

Optional rows:

```text
З коментарями: 42
Найцитованіша книга: ...
Найцитованіший автор: ...
```

## Quick filters card

Title:

```text
Швидкі фільтри
```

Buttons:

```text
Цитати з коментарями
Лише улюблені
Нещодавно додані
Довгі цитати
Скинути фільтри
```

## Decorative quote card

Example:

```text
Кожна цитата — це думка, до якої хочеться повернутися.
```

This block is decorative and should not be required for MVP.

## CTA card

If user has no quotes or as a permanent helper block:

```text
Додайте свою першу цитату
Зберігайте важливі фрази, які надихають, зворушують і залишають слід у серці.
[+ Додати цитату]
```

## Decorative style

Use small botanical ornaments in top-right corners of cards.

Use warm terracotta and beige BookNest palette.
