# Quotes UI Style Guide

## General style

Quotes should follow BookNest cozy visual language:

- warm cream background;
- rounded cards;
- terracotta accents;
- soft shadows;
- serif headings;
- small botanical ornaments;
- subtle paper-like texture.

## Palette

Main accent:

```text
#9A5D36
```

Use it for:

- primary buttons;
- active filters;
- favorite active state;
- decorative branches;
- important accents.

## Quote text

Quote text should feel bookish.

Recommended:

- serif font;
- larger than metadata;
- line-height 1.5–1.7;
- quotation marks optional.

## Badges

### Без спойлерів

Use green/soft positive badge.

### Зі спойлерами

Use warm peach/red badge, but not aggressive.

### Улюблена

Use heart icon or filled bookmark icon.

## Buttons

Primary button:

```text
+ Додати цитату
```

Use terracotta fill.

Secondary buttons use outline or soft beige background.

## Decorative elements

Recommended decorations:

- small branch near title;
- corner branch on right sidebar cards;
- quote mark illustration;
- open book icon.

Do not overload quote cards with too many decorations.

## Modal style

Add Quote modal should use:

- large serif title;
- book preview at top;
- subtle branch decoration;
- rounded input fields;
- warm info note for spoiler explanation.
