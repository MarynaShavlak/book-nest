# Responsive Rules

## Desktop

Use three-column layout:

```text
Sidebar | Main quotes grid | Right sidebar
```

Quote grid:

```text
2 columns
```

## Tablet

Hide or move right sidebar below main content.

Quote grid:

```text
1–2 columns
```

## Mobile

Use single-column layout.

Order:

```text
Header
Search
Filters horizontal scroll
Sort + add button
Quote cards
Statistics / quick filters
```

## Filters on mobile

Quick filters should be horizontally scrollable chips.

Advanced filters can be moved into a bottom sheet:

```text
Фільтри
```

## Modal on mobile

Add Quote modal should become full-screen or near full-screen bottom sheet.

Footer buttons should be sticky at bottom.

## Spoiler card on mobile

Spoiler placeholder should have large enough button:

```text
Показати спойлер
```

Minimum tap target:

```text
44px
```
