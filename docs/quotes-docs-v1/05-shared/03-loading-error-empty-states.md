# Shared Loading, Error and Empty States

## Loading

Use skeletons.

For global Quotes page:

- quote card skeletons;
- right sidebar skeleton.

For Book Details:

- 2–3 compact quote skeletons.

## Error

Message:

```text
Не вдалося завантажити цитати
```

Action:

```text
Повторити
```

## Empty global quotes

```text
У вас ще немає цитат
Додавайте улюблені фрази з книг, власні думки й важливі уривки — вони з’являться тут.
```

Actions:

```text
+ Додати цитату
Перейти до книг
```

## Empty book quotes

```text
У цій книзі ще немає цитат
Збережіть красивий уривок, важливу думку або фразу, до якої захочеться повернутися.
```

Action:

```text
+ Додати цитату
```

## Empty filter state

```text
Нічого не знайдено
Спробуйте змінити запит або очистити фільтри.
```

Action:

```text
Скинути фільтри
```
