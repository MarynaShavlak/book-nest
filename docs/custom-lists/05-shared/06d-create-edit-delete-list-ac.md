## 24. Acceptance Criteria

### Create list

* Користувач може відкрити modal **Створити список**.
* Користувач може ввести назву списку.
* Назва списку є обов’язковою.
* Назва списку має містити щонайменше 2 символи.
* Назва списку не може бути довшою за 80 символів.
* Користувач може optional додати опис.
* Опис не може бути довшим за 300 символів.
* Користувач може optional вибрати іконку.
* Користувач може optional вибрати колір.
* Якщо список із такою назвою вже існує, користувач бачить validation error.
* Після створення список з’являється на сторінці **Власні списки**.
* Після створення count badge оновлюється.
* Після створення користувач бачить success message.

### Edit list

* Користувач може відкрити modal **Редагувати список**.
* Modal відкривається з поточними даними списку.
* Користувач може змінити назву списку.
* Користувач може змінити опис списку.
* Користувач може змінити іконку, якщо ця опція доступна.
* Користувач може змінити колір, якщо ця опція доступна.
* Кнопка **Зберегти** disabled, якщо немає змін.
* Якщо нова назва дублює інший список користувача, показується validation error.
* Після збереження картка списку оновлюється.
* Після збереження користувач бачить success message.

### Delete list

* Користувач може натиснути **Видалити список**.
* Перед видаленням відкривається confirmation modal.
* Confirmation modal пояснює, що книги залишаться в бібліотеці.
* Користувач може скасувати видалення.
* Користувач може підтвердити видалення.
* Після підтвердження список зникає зі сторінки **Власні списки**.
* Після видалення книги зі списку залишаються в бібліотеці.
* Після видалення count badge оновлюється.
* Якщо видалено останній список, показується empty state.
* Якщо сталася помилка, список не зникає і користувач бачить error message.

### Permissions

* Користувач може створювати списки тільки для себе.
* Користувач може редагувати тільки свої списки.
* Користувач може видаляти тільки свої списки.
* Користувач не може редагувати або видаляти чужі списки.
