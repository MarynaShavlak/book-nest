# MVP vs Future Scope

## Role

Collects what is not included in MVP and future improvements.

## Source coverage

`custom-lists-page.md` section 36; `custom-list-details-page.md` sections 43-44; `add-to-custom-lists.md` section 24; `create-edit-delete-custom-list.md` section 23

## Content

## 36. What is not included in MVP

У MVP не входить:

* public lists;
* share list;
* favorite lists;
* filters;
* add books modal;
* full Custom List Details Page logic;
* список книг усередині списку;
* прибирання книги зі списку на цій сторінці;
* drag-and-drop книг у списку;
* ручний порядок списків;
* автоматичні списки;
* дублювання списку;
* статистика конкретного списку;
* спільні списки з іншими користувачами;
* API;
* data model.

Ці сценарії потрібно описувати окремими features.
