# Responsive Rules

## General

The module should work comfortably on desktop, tablet, and mobile.

## Custom Lists Page

Recommended behavior:

- desktop: header + toolbar + grid/list view + optional sidebar;
- tablet: sidebar can move below content;
- mobile: one-column layout, compact toolbar, cards stacked vertically.

## Custom List Details Page

Recommended behavior:

- desktop: full header, toolbar, book grid/list;
- mobile: primary action remains visible, filters/search should not hide content;
- book cards should keep important actions accessible.

## Modals

For add/create/edit/delete modals:

- use full-width modal or bottom sheet style on small screens;
- keep submit/cancel actions visible;
- avoid horizontal overflow;
- preserve keyboard accessibility.
