Acceptance criteria for one-list details page.

## Source coverage

## Content

## 45. Acceptance Criteria

### General

* Користувач може відкрити детальну сторінку конкретного списку.
* Сторінка доступна тільки авторизованому користувачу.
* Користувач бачить тільки свій список.
* Користувач не може відкрити чужий список.
* Видалений список не відкривається.
* Route сторінки має формат `/lists/:listId`.

### Header

* На сторінці показується назва списку.
* На сторінці показується опис списку, якщо він є.
* На сторінці показується кількість книг у списку.
* На сторінці показується дата створення або оновлення.
* Користувач може повернутися до сторінки всіх списків.
* Користувач може натиснути **Додати книги**.
* Користувач може відкрити actions menu списку.
* Користувач може редагувати список.
* Користувач може видалити список.

### Books list

* На сторінці показуються книги, додані до цього списку.
* Кожна книга показує позицію в списку.
* Кожна книга показує обкладинку або placeholder.
* Кожна книга показує назву.
* Кожна книга показує автора.
* Кожна книга показує reading status.
* Кожна книга показує ownership status.
* Кожна книга може показувати genres / tags.
* Кожна книга може показувати series info.
* Користувач може перейти до Book Details.
* Користувач може прибрати книгу зі списку.

### Search and sorting

* Користувач може шукати книги всередині списку.
* Search працює за назвою книги.
* Search працює за оригінальною назвою.
* Search працює за автором.
* Search працює за серією.
* Search працює за жанрами.
* Search працює за тегами.
* Search працює за видавництвом.
* Якщо search нічого не знайшов, показується no search results state.
* Користувач може очистити search.
* Користувач може сортувати книги у списку.
* Default sorting — **Позиція в списку**.

### Book position and reorder

* Кожна книга в списку має позицію.
* Одна й та сама книга може мати різну позицію в різних списках.
* Користувач може перемістити книгу вище.
* Користувач може перемістити книгу нижче.
* Якщо книга перша, action **Перемістити вище** disabled.
* Якщо книга остання, action **Перемістити нижче** disabled.
* Після зміни порядку позиції книг оновлюються.
* Новий порядок зберігається.
* Reorder доступний тільки при sorting = **Позиція в списку**.
* Reorder disabled, якщо активний search.

### Add books

* Користувач може відкрити modal **Додати книги до списку**.
* Modal має блок **Ваша бібліотека**.
* Modal має блок **Вибрано книг: N**.
* Користувач може шукати книги у своїй бібліотеці.
* Користувач може вибрати одну книгу.
* Користувач може вибрати кілька книг.
* Книги, які вже є у списку, показуються як **Уже в списку**.
* Книги, які вже є у списку, не можна додати повторно.
* Після додавання books count оновлюється.
* Після додавання список книг оновлюється.
* Нові книги додаються в кінець списку.
* Користувач бачить success message.

### Remove books

* Користувач може прибрати книгу зі списку.
* Прибирання книги зі списку не видаляє книгу з бібліотеки.
* Прибирання книги зі списку не змінює reading status.
* Прибирання книги зі списку не змінює ownership status.
* Прибирання книги зі списку не змінює favorite status.
* Після прибирання books count оновлюється.
* Після прибирання позиції книг оновлюються без пропусків.
* Після прибирання показується toast.
* Toast має action **Скасувати**.
* Після Undo книга повертається у список.

### Add to Reading Queue

* Користувач може додати книгу зі списку в Reading Queue.
* Якщо книга вже є в черзі, повторно вона не додається.
* Якщо книга вже є в черзі, на картці показується badge **У черзі**.
* Якщо книга вже є в черзі, можна показати action **Перейти до черги**.
* Після додавання книга з’являється на сторінці **Черга читання**.
* Після додавання користувач бачить success message.

### Related Book Details UI

* Якщо книга є в custom lists, Book Details може показувати блок **Мої списки**.
* Блок **Мої списки** показує назви списків, де є книга.
* Клік по назві списку відкриває відповідний Custom List Details Page.
* Якщо книга не додана до жодного списку, блок можна приховати.

### Empty and error states

* Якщо список порожній, показується empty list state.
* Empty state має action **Додати книги**.
* Empty state має action **Повернутися до списків**.
* Якщо список не вдалося завантажити, показується error state.
* Якщо список не знайдено або недоступний, показується not found / access state.
* Error state має action **Спробувати ще раз**.
