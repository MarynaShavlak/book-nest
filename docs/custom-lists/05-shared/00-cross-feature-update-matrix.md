# Cross-Feature Update Matrix

| Action | Update custom list | Update book | Update other custom lists | Delete book? |
| --- | --- | --- | --- | --- |
| Create list | Yes | No | No | No |
| Edit list | Yes | No | No | No |
| Delete list | Yes, remove list and memberships | No | No | No |
| Add book to list | Yes, add membership | No | No | No |
| Remove book from list | Yes, remove membership | No | No | No |
| Reorder books in list | Yes, update positions | No | No | No |
| Add book to reading queue from list | No | Reading queue changes | No | No |

## Core safety rule

Custom Lists organize books.  
They do not own books and must not delete books from the library.
