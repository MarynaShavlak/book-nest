# Navigation Entry Points

## Main navigation

Custom Lists Page is opened from the main sidebar:

```text
Sidebar → Списки → /lists
```

## Open one list

```text
Custom Lists Page → List card → /lists/:listId
```

## From Book Details

```text
Book Details → Right sidebar → Quick actions → Додати до списку
```

## From Custom List Details

```text
Custom List Details Page → Header → Додати книги
Custom List Details Page → Book card → View book
Custom List Details Page → Book card → Add to Reading Queue
```
