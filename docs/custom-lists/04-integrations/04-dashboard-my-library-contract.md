# Dashboard and My Library Contract

## MVP rule

Custom Lists should not change how books appear in My Library.

A book remains in My Library regardless of:

- which custom lists it belongs to;
- whether it is removed from a custom list;
- whether one of its custom lists is deleted.

## Optional future surfaces

Dashboard or My Library may later show:

- “Recently updated lists”;
- “Books in custom lists” count;
- list chips on book cards;
- shortcut to open a list.

These are not required for MVP unless explicitly added to the page documentation.
