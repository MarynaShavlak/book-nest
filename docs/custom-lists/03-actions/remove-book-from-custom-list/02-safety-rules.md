# Safety Rules

## Required behavior

- Removing a book from a list removes only the list membership.
- The book remains in the library.
- The book keeps its reading status, ownership status, favorite status, format, notes, quotes, series data, and delivery data.
- If the same book is present in other custom lists, those memberships remain unchanged.
