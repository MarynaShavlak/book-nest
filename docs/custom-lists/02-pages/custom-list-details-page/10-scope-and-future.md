# Scope and Future Improvements

## Role

Defines what is outside MVP and future improvements for the details page.

## Source coverage

`custom-list-details-page.md` sections 43-44

## Content

## 43. What is not included in MVP

У MVP не входить:

* public / shared list;
* share by link;
* drag-and-drop порядок книг у списку;
* advanced filters inside list;
* statistics for specific list;
* grouping by genre / series;
* comments for why book is in list;
* notes for specific list;
* duplicate list;
* export list;
* recommendations for list;
* API;
* data model.

Ці сценарії можна додати пізніше як окремі features.

* дублювати список;
* обкладинка списку;
* статистика списку;
* фільтри всередині списку;
* рекомендації книг для списку;
* автоматичні списки;
* коментарі до списку;
* notes для конкретного списку;
