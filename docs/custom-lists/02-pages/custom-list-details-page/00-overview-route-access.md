# Overview, Route, Access

## Role

Defines page purpose, route, access rules, and which books are displayed.

## Source coverage

`custom-list-details-page.md` sections 1-5

## Content

## 1. Purpose

Сторінка **Custom List Details Page** дозволяє користувачу переглядати один конкретний власний список і керувати книгами всередині нього.

Фіча потрібна, щоб власні списки були не просто назвами добірок, а повноцінними персональними книжковими полицями.

Користувач може:

* бачити всі книги, додані до конкретного списку;
* додавати нові книги до списку;
* прибирати книги зі списку;
* змінювати порядок книг у списку;
* переходити до детальної сторінки книги;
* додавати книгу зі списку в чергу читання;
* редагувати інформацію про список;
* видалити список, якщо він більше не потрібен.

## 2. Main idea

**Custom Lists Page** показує всі власні списки користувача.

**Custom List Details Page** показує один конкретний список і книги всередині нього.

```text
Custom Lists Page = усі списки
Custom List Details Page = один список + книги цього списку
```

Important rules:

* одна книга може бути в кількох різних списках;
* одна книга не може дублюватися в одному й тому самому списку;
* прибирання книги зі списку не видаляє книгу з бібліотеки;
* видалення списку не видаляє книги з бібліотеки;
* власний список не змінює reading status, ownership status, format або favorite status книги.

## 3. Page entry point

Сторінка відкривається після натискання на конкретний список на сторінці **Власні списки**.

Entry point:

```text
Custom Lists Page → List card → Відкрити список
```

Recommended route:

```text
/lists/:listId
```

Example:

```text
/lists/dark-fantasy
```

## 4. Page access rules

Сторінка доступна тільки авторизованому користувачу.

Користувач може відкрити тільки свої власні списки.

На сторінці не мають відображатися:

* чужі списки;
* видалені списки;
* книги інших користувачів;
* видалені книги;
* книги, які не належать до цього списку.

Якщо список не існує або недоступний, користувач має побачити not found / access error state.

---

## 5. What books are displayed

На сторінці показуються тільки книги, які додані до цього конкретного списку.

Книга має показуватися, якщо:

```text
book belongs to current user
book is active
book is added to current custom list
```

Книга не має показуватися, якщо:

* книга видалена;
* книга належить іншому користувачу;
* книга не додана до цього списку;
* список видалений.
