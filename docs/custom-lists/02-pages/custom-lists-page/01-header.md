# Page Header

## Role

Defines header title, subtitle, count badge, and primary action.

## Source coverage

`custom-lists-page.md` section 7

## Content

## 7. Page header

Page header має показувати назву сторінки, короткий опис, кількість списків і основну дію.

### Title

```text
Власні списки
```

### Subtitle

```text
Організуйте книги у власні тематичні добірки
```

### Count badge

Показує кількість активних списків користувача.

Example:

```text
7 списків
```

### Primary action

```text
+ Створити список
```

Behavior:

* відкриває modal створення нового списку;
* після створення новий список з’являється на сторінці.
