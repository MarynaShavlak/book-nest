## 7. Existing lists selection

Основний блок modal — це список власних списків користувача.

Кожен список показується як checkbox item.

Для кожного списку потрібно показати:

| Element     | Required | Description                  |
| ----------- | -------: | ---------------------------- |
| Checkbox    |      Так | Вибір списку                 |
| List name   |      Так | Назва списку                 |
| Books count |       Ні | Скільки книг у списку        |
| Description |       Ні | Короткий опис списку, якщо є |

Example:

```text
[ ] Осіннє читання · 12 книг
[x] Улюблене фентезі · 8 книг
[ ] Книги від блогерів · 5 книг
```

## 8. Selection behavior

Списки працюють як multi-select.

Behavior:

* користувач може вибрати один список;
* користувач може вибрати кілька списків;
* користувач може прибрати вибір зі списку;
* списки, у яких книга вже є, мають бути checked при відкритті modal;
* якщо користувач знімає checked зі списку, після збереження книга прибирається з цього списку;
* якщо користувач не змінює вибір, submit не має створювати дублікати.

Important:

```text
Modal працює не тільки як “додати”, а як “оновити списки цієї книги”.
```

Тобто користувач бачить поточний стан і може одразу додати або прибрати книгу з кількох списків.
