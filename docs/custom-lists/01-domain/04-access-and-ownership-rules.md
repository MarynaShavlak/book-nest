# Access and Ownership Rules

## Role

Defines which lists and books can be displayed or changed by the current user.

## Source coverage

`custom-lists-page.md` section 5, `custom-list-details-page.md` sections 4-5, `create-edit-delete-custom-list.md` section 4, `add-to-custom-lists.md` section 4

## Content

## 5. Page access rules

Сторінка доступна тільки авторизованому користувачу.

Користувач має бачити тільки свої списки.

На сторінці не мають відображатися:

* списки інших користувачів;
* видалені списки;
* чужі книги;
* чужі custom data.

Якщо користувач не авторизований, його потрібно перенаправити на login page.

## 4. Page access rules

Сторінка доступна тільки авторизованому користувачу.

Користувач може відкрити тільки свої власні списки.

На сторінці не мають відображатися:

* чужі списки;
* видалені списки;
* книги інших користувачів;
* видалені книги;
* книги, які не належать до цього списку.

Якщо список не існує або недоступний, користувач має побачити not found / access error state.

## 5. What books are displayed

На сторінці показуються тільки книги, які додані до цього конкретного списку.

Книга має показуватися, якщо:

```text
book belongs to current user
book is active
book is added to current custom list
```

Книга не має показуватися, якщо:

* книга видалена;
* книга належить іншому користувачу;
* книга не додана до цього списку;
* список видалений.

## 4. Access rules

Користувач може створювати, редагувати та видаляти тільки свої списки.

Система має перевіряти:

* користувач авторизований;
* список належить поточному користувачу;
* список не видалений;
* користувач не може редагувати або видаляти чужі списки.

Якщо список недоступний, дія не має виконуватися.

---

---

## 4. When action is available

Action **Додати до списку** доступна, якщо:

* книга належить поточному користувачу;
* книга не видалена;
* користувач авторизований.

Action не потрібно блокувати через:

* reading status;
* ownership status;
* format;
* favorite status;
* наявність книги в черзі читання.

Користувач може додати до списку будь-яку свою активну книгу.
