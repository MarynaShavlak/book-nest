# Purpose and Scope

## Role

Defines what the Custom Lists module is responsible for and what it must not own.

## Source coverage

`custom-lists-page.md` sections 1-2, `custom-list-details-page.md` sections 1-2, `create-edit-delete-custom-list.md` sections 1-2, `add-to-custom-lists.md` sections 1-2

## Content

## 1. Purpose

Сторінка **“Власні списки”** дозволяє користувачу переглядати, створювати, редагувати та видаляти власні книжкові добірки.

Фіча потрібна, щоб користувач міг організовувати книги не тільки за системними статусами, жанрами або серіями, а й за власною логікою.

Examples:

```text
Осіннє читання
Темне фентезі
Книги для настрою
Книги з драконами
Українські видавництва
Хочу перечитати
```

---

---

## 2. Main idea

**Власні списки** — це ручні тематичні добірки, які створює сам користувач.

Один список може містити багато книг.

Одна книга може бути в кількох списках одночасно.

Important:

```text
Видалення списку не видаляє книги з бібліотеки.
```

Після видалення списку видаляється тільки сам список і зв’язок книг із цим списком. Книги залишаються в **Моїй бібліотеці**.

## 1. Purpose

Сторінка **Custom List Details Page** дозволяє користувачу переглядати один конкретний власний список і керувати книгами всередині нього.

Фіча потрібна, щоб власні списки були не просто назвами добірок, а повноцінними персональними книжковими полицями.

Користувач може:

* бачити всі книги, додані до конкретного списку;
* додавати нові книги до списку;
* прибирати книги зі списку;
* змінювати порядок книг у списку;
* переходити до детальної сторінки книги;
* додавати книгу зі списку в чергу читання;
* редагувати інформацію про список;
* видалити список, якщо він більше не потрібен.

---

---

## 2. Main idea

**Custom Lists Page** показує всі власні списки користувача.

**Custom List Details Page** показує один конкретний список і книги всередині нього.

```text
Custom Lists Page = усі списки
Custom List Details Page = один список + книги цього списку
```

Important rules:

* одна книга може бути в кількох різних списках;
* одна книга не може дублюватися в одному й тому самому списку;
* прибирання книги зі списку не видаляє книгу з бібліотеки;
* видалення списку не видаляє книги з бібліотеки;
* власний список не змінює reading status, ownership status, format або favorite status книги.

## 1. Purpose

Feature **Create / Edit / Delete Custom List** дозволяє користувачу керувати власними книжковими списками в BookNest.

Фіча покриває три основні дії:

* створити новий власний список;
* редагувати існуючий список;
* видалити список.

Ця фіча працює зі списками як окремими добірками книг, але не відповідає за детальне керування книгами всередині списку.

---

---

## 2. Main idea

Власний список — це ручна тематична добірка книг, яку створює користувач.

Examples:

```text id="d6vprk"
Осіннє читання
Темне фентезі
Книги для настрою
Хочу перечитати
Книги з драконами
```

Important:

```text id="md606w"
Видалення списку не видаляє книги з бібліотеки.
```

Після видалення списку:

* список зникає;
* зв’язки книг із цим списком видаляються;
* самі книги залишаються в бібліотеці користувача.

## 1. Purpose

Feature **Add Book to Custom List from Book Details** дозволяє користувачу додати конкретну книгу до одного або кількох власних списків прямо зі сторінки деталей книги.

Фіча потрібна, щоб користувач міг швидко організовувати книги у персональні добірки без переходу на окрему сторінку списків.

Examples of custom lists:

```text
Осіннє читання
Улюблене фентезі
Книги для настрою
Хочу перечитати
Подарунки
Книги від блогерів
```

---

---

## 2. Main idea

Книга може бути додана до одного або кількох власних списків.

Example:

```text
Книга “Четверте крило” може бути одночасно у списках:
- Улюблене фентезі
- Книги з драконами
- Хочу перечитати
```

Important:

* власний список — це не reading status;
* власний список — це не ownership status;
* власний список — це не favorite;
* додавання книги до списку не змінює дані книги;
* книга залишається в бібліотеці незалежно від того, у яких списках вона є;
* одна книга не може дублюватися в одному й тому самому списку.
