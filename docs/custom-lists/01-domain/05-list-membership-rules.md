# List Membership Rules

## Core rules

- One custom list can contain many books.
- One book can be in multiple custom lists.
- One book cannot be duplicated inside the same custom list.
- Adding a book to a custom list does not change the book itself.
- Removing a book from a custom list does not delete the book.
