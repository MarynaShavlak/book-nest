## 3. Difference between system pages and custom lists

Власні списки не мають дублювати системні сторінки BookNest.

System pages:

```text
Улюблені
Черга читання
Книги до покупки
Книги в дорозі
Позичені книги
Серії
```

Custom lists:

```text
Осіннє читання
Книги для настрою
Темне фентезі
Хочу перечитати
Книги від блогерів
```

Important:

* `Улюблені` працюють через `isFavorite`;
* `Книги до покупки` працюють через ownership status;
* `Черга читання` працює через reading queue;
* custom lists — це окрема ручна організація книг.
