# Edit Profile Acceptance Criteria

- User can open edit profile form.
- Existing profile values are prefilled.
- User can update name and lastName.
- User can update avatar.
- User can update nickname.
- User can add/remove dateOfBirth.
- User can update bio.
- User can update favoriteBookQuote.
- User can select favoriteGenres.
- Email is not editable in this form.
- Invalid fields show validation errors.
- Successful save updates profile page.
- Failed save shows error and keeps entered values.
