# Edit Profile Form Overview

## Purpose

The form lets current user update personal profile fields.

## Fields

- avatar;
- name;
- lastName;
- nickname;
- dateOfBirth;
- bio;
- favoriteBookQuote;
- favoriteGenres.

## Not included

- email;
- authProvider;
- createdAt;
- profile stats;
- password;
- settings;
- socialLinks list management if implemented as separate block.

## Success message

```text
Профіль оновлено
```
