# Submit Flow

## Steps

1. User edits fields.
2. Frontend validates input.
3. Values are normalized.
4. Update request is sent.
5. UI shows loading state.
6. On success, profile page receives fresh data.
7. User sees success notification.

## Success notification

```text
Профіль оновлено
```

## Error

If save fails, keep form values and show error message.
