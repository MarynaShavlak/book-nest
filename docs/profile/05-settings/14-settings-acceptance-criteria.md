# Settings Acceptance Criteria

- User sees settings section in profile.
- User can choose theme mode.
- User can choose accent color.
- User can choose interface language.
- User can choose date format.
- User can choose week start day.
- User can see timezone.
- User can choose library view mode.
- User can toggle confirmBeforeDelete.
- User can manage optional email notifications.
- Settings are saved for current user.
- Settings survive page reload.
- System emails cannot be disabled.
