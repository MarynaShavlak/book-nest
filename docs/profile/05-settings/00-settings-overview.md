# Settings Overview

## Purpose

Settings let user personalize BookNest.

## Stored per user

Each authenticated user has own settings.

## Sections

- theme;
- accent color;
- language;
- date format;
- week start day;
- timezone;
- default library view;
- confirm before delete;
- email notifications;
- password change entry point.

## Important

Application settings should not be stored directly in `UserProfile`.
