# Email Notifications Settings

## Toggles

| Field | Description |
| --- | --- |
| readingReminders | remind to update reading progress |
| readingGoalReminders | reading goals reminders |
| borrowedBookReminders | borrowed books reminders |
| deliveryReminders | books in transit reminders |
| weeklyReadingSummary | weekly reading report |
| monthlyReadingReport | monthly reading report |

## Rule

Each toggle is saved separately.
