# Social Links Overview

## Purpose

User can add links or usernames to book/personal profiles.

## Optional block

If no social links exist, show empty state or hide block depending on UI.

Recommended empty state:

```text
Соціальні мережі ще не додані.
```

## MVP platforms

- Instagram;
- TikTok;
- X / Twitter;
- Threads;
- YouTube;
- Goodreads;
- StoryGraph;
- Telegram;
- Website / Blog;
- Other.
