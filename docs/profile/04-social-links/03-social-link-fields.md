# Social Link Fields

| Field | Type | Required |
| --- | --- | ---: |
| platform | select | Yes |
| username | text input | No |
| url | text input | No |
| label | text input | No |

## Required pair rule

Each social link must have at least one:

- username;
- url.

## Label

Label is especially useful for:

- WEBSITE;
- OTHER.
