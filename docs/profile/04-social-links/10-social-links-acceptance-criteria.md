# Social Links Acceptance Criteria

- User sees Social Links block in profile.
- User can add social link.
- User can select platform.
- User can add username or URL.
- User can edit social link.
- User can delete social link.
- Empty state is shown when list is empty.
- Invalid URL shows validation error.
- Duplicate platform shows validation error.
- Duplicate URL shows validation error.
- Saved social link appears in list.
- Social links are scoped to current user.
