# Domain Rules

Ця папка описує стабільну логіку профілю, яка не залежить від конкретної UI-реалізації.

Тут лежать:

- data models;
- profile fields;
- user scope;
- statistics model;
- validation overview;
- privacy/security boundaries;
- state priority rules.

Для будь-якої задачі по профілю Claude Code варто давати хоча б:

```txt
01-domain/00-purpose-and-scope.md
01-domain/01-user-profile-data-model.md
```
