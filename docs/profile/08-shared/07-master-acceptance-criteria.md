# Master Acceptance Criteria

- User can open own profile.
- User can edit basic profile fields.
- User can upload/remove avatar.
- User can manage favorite genres.
- User can add favorite book quote.
- User can manage social links.
- User can view reading statistics.
- User can open settings.
- User can change settings.
- User can logout.
- User can access password change flow when supported.
- Data is scoped to current user.
- Invalid input shows validation errors.
- Save failures show errors and do not clear forms.
