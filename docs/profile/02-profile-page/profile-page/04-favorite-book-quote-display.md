# Favorite Book Quote Display

## Purpose

The user can show one personal quote about books.

## Display

Recommended in profile header.

Example:

```text
“Книги — це мандрівки, які починаються, не виходячи з дому.”
```

## Rules

- optional field;
- if empty, do not show;
- not linked to a specific book;
- not a quote from Quotes Module;
- editable only through Edit Profile form.
