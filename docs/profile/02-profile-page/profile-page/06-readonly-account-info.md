# Read-only Account Info

## Fields

Show:

- email;
- authProvider;
- createdAt;
- emailVerified if useful.

## Read-only rule

These fields are not editable in profile form.

## Auth provider display

Examples:

- email/password;
- Google;
- Apple.

## Email change

If email change is needed, create a separate security flow.
Do not add email input to Edit Profile form.
