# Profile Header

## Purpose

The profile header gives quick identity context.

## Content

Show:

- avatar or initials placeholder;
- full name;
- nickname if added;
- email;
- favoriteBookQuote if added.

## Full name

Display format:

```text
{name} {lastName}
```

If lastName is temporarily missing, still keep layout stable.

## Quote

Quote belongs near avatar/name/email area.

If `favoriteBookQuote` is empty, do not show quote block.
