# Main Profile Info

## Fields

Show:

- name;
- lastName;
- nickname if added;
- email;
- bio if added;
- dateOfBirth if added;
- createdAt;
- favoriteGenres if selected.

## Email

Email is visible but read-only.

## Bio

If bio is empty, hide bio block or show subtle empty placeholder only in edit mode.

## Favorite genres

Show selected genres as chips/tags.

If no genres selected, hide section or show empty state depending on design.
