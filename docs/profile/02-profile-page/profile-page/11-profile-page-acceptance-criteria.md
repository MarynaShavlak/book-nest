# Profile Page Acceptance Criteria

- User can open profile page.
- User sees avatar or placeholder.
- User sees name, lastName and email.
- User sees nickname if added.
- User sees bio if added.
- User sees favorite book quote if added.
- User sees date of birth if added.
- User sees account creation date.
- User sees short reading statistics or stats empty state.
- User sees social links block or social links empty state.
- User can start edit profile flow.
- User can logout from profile page.
- Email is visible but not directly editable.
- Profile data is scoped to current user.
