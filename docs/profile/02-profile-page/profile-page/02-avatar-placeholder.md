# Avatar and Placeholder

## Avatar

If `avatarUrl` exists, show image.

## Placeholder

If avatar is missing, show initials.

Recommended initials:

```text
first letter of name + first letter of lastName
```

## Fallback

If name/lastName are unavailable, show generic placeholder.

## Actions

On profile page, avatar itself can be read-only.
Editing/removing avatar belongs to Edit Profile flow.
