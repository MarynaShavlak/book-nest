# Reading Statistics Block

## Purpose

Shows short reading overview inside profile.

## Metrics

- totalBooks;
- readBooks;
- currentlyReading;
- favoriteBooks;
- notesCount;
- quotesCount;
- averageRating if available.

## Empty state

If user has no books:

```text
Статистика з’явиться після додавання книг.
```

## Rule

Stats are read-only and calculated automatically.
