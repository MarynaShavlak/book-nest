# Social Links Preview Block

## Purpose

Shows user's added social/book profiles.

## Content

For each item show:

- platform icon;
- username or label;
- external link action;
- edit/delete actions if block is editable on this screen.

## Empty state

```text
Соціальні мережі ще не додані.
```
