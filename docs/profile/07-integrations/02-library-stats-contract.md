# Library Stats Contract

## Profile reads stats from

- My Library;
- Favorites;
- Notes;
- Quotes;
- Ratings.

## Metrics

- totalBooks;
- readBooks;
- currentlyReading;
- favoriteBooks;
- notesCount;
- quotesCount;
- averageRating.

## Rule

Profile does not manually edit stats.
Stats are derived from source modules.
