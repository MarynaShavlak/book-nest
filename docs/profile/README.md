# Profile Module Documentation v2

Це розбита структура документації для логіки профілю користувача в BookNest.

Стара документація була в одному файлі `profile.md`, де одночасно були описані:

- поля профілю користувача;
- форма редагування профілю;
- social links;
- валідація полів;
- читацька статистика;
- налаштування застосунку;
- email-сповіщення;
- зміна паролю;
- acceptance criteria.

У v2 ці відповідальності рознесені по маленьких файлах, щоб Claude Code міг отримувати тільки потрібний контекст.

## Як користуватися

Для реалізації конкретної частини давай Claude Code:

1. `00-module-map.md`
2. один або кілька файлів із `01-domain/`
3. тільки потрібну папку з `02-profile-page/`, `03-edit-profile/`, `04-social-links/`, `05-settings/` або `06-security-account/`
4. потрібний shared-файл із `08-shared/`

## Не робити

Не давай Claude Code старий `profile.md` разом із цією структурою.
Старий файл занадто широкий і знову змішає контекст.
