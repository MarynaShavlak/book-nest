## 18. UI updates after submit

Після успішного збереження позики або повернення мають оновитися:

* Book Details hero section;
* Right sidebar;
* ownership status badge;
* Quick actions;
* My Library card;
* Borrowed Books page;
* summary cards, якщо вони враховують ownership statuses.

---

## 19. UI behavior after mark as borrowed / lent

### After borrowed from someone

Після submit:

* ownership status badge показує **Позичена у когось**;
* у Quick actions з’являється action **Позначити як повернуту**;
* action **Позначити як позичену** зникає;
* книга з’являється на сторінці **Позичені книги**.

### After lent to someone

Після submit:

* ownership status badge показує **Видана комусь**;
* у Quick actions з’являється action **Позначити як повернуту**;
* action **Видати комусь** зникає;
* книга з’являється на сторінці **Позичені книги**.

---

## 20. UI behavior after mark as returned

### If borrowed book returned

Після submit:

* ownership status стає **Немає**;
* action **Позначити як повернуту** зникає;
* книга зникає з активного списку **Позичені книги**;
* книга залишається в бібліотеці.

### If lent book returned

Після submit:

* ownership status стає **Маю**;
* action **Позначити як повернуту** зникає;
* книга зникає з активного списку **Позичені книги**;
* книга залишається в бібліотеці.

## 21. Validation

| Field                       | Validation                                 |
| --------------------------- | ------------------------------------------ |
| У кого взяла / Кому дала    | required, 2–100 символів                   |
| Дата позики / Дата передачі | required, не може бути в майбутньому       |
| Повернути до                | optional, не раніше дати позики / передачі |
| Контакт                     | optional, max 100 символів                 |
| Нотатка                     | optional, max 300 символів                 |
| Reminder                    | якщо увімкнений, потрібна дата повернення  |

Validation messages:

```text
Введіть ім’я людини
Ім’я має містити щонайменше 2 символи
Дата не може бути в майбутньому
Дата повернення не може бути раніше дати позики
Оберіть дату повернення для нагадування
Контакт не може бути довшим за 100 символів
Нотатка не може бути довшою за 300 символів
```

## 22. Loading behavior

Після натискання submit button:

* кнопка стає disabled;
* показується loading state;
* повторний submit блокується;
* modal не закривається до успішного збереження.

Button text:

```text
Збереження...
```

---

## 23. Error behavior

Якщо дію не вдалося виконати:

* modal залишається відкритою;
* введені дані не очищаються;
* Book Details UI не оновлюється;
* користувач бачить error message;
* користувач може повторити submit.

Error message:

```text
Не вдалося оновити статус позики
```

---

## 24. What is not included

Ця фіча не відповідає за:

* reading status;
* purchase status;
* delivery status;
* format;
* full book editing;
* видалення книги;
* повну історію всіх позик.

Історію позик можна додати окремою future feature.

## 25. Acceptance Criteria

* Користувач може відкрити modal **Позначити як позичену** з Book Details.
* Modal показує обкладинку, назву книги й автора.
* Користувач може вибрати сценарій **Я взяла книгу у когось**.
* Користувач може вибрати сценарій **Я дала свою книгу комусь**.
* Для сценарію **Я взяла книгу у когось** показується поле **У кого взяла**.
* Для сценарію **Я дала свою книгу комусь** показується поле **Кому дала**.
* Дата позики / передачі є обов’язковою.
* Користувач може optional вказати дату повернення.
* Користувач може optional вказати контакт.
* Користувач може optional додати нотатку.
* Користувач може увімкнути нагадування.
* Якщо нагадування увімкнене, потрібно вибрати дату повернення.
* Після submit для сценарію **Я взяла книгу у когось** книга отримує `ownershipStatus = borrowed_from_someone`.
* Після submit для сценарію **Я дала свою книгу комусь** книга отримує `ownershipStatus = lent_to_someone`.
* Книга з’являється на сторінці **Позичені книги**.
* Користувач може позначити активну позику як повернуту.
* Якщо користувач повернув чужу книгу, `ownershipStatus` стає `none`.
* Якщо користувачу повернули його книгу, `ownershipStatus` стає `owned`.
* Після повернення книга зникає з активного списку **Позичені книги**.
* Після будь-якої дії Book Details оновлює ownership status.
* Якщо сталася помилка, modal залишається відкритою і показує error message.
