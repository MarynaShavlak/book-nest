# Navigation and Entry Points

## Navigation

Sidebar should include:

```text
Позичені книги
```

Recommended placement near ownership-related pages:

```text
Книги до покупки
Книги в дорозі
Позичені книги
```

---

## Entry points

User can access loan flows from:

* Sidebar → Позичені книги;
* Book Details;
* My Library card menu;
* Book Form;
* Dashboard widget.

---

## Entry point behavior

From Book Details:

```text
Open Mark as Loaned modal for current book.
```

From Borrowed Books Page CTA:

```text
Open modal with selected type or ask user to choose a book first.
```

From My Library card menu:

```text
Open Mark as Loaned modal with selected book.
```

From Book Form:

```text
Show loan section if ownershipStatus is borrowed_from_someone or lent_to_someone.
```
