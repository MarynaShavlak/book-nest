# Loading, Error and Empty States

## Loading

```text
Завантажуємо позичені книги...
```

Use:

* skeleton summary cards;
* skeleton list rows;
* skeleton sidebar.

---

## Empty

```text
У вас поки немає позичених книг
```

Description:

```text
Позначте книгу як позичену, щоб відстежувати, кому її потрібно повернути або у кого ви її взяли.
```

---

## Empty filtered

```text
Нічого не знайдено
```

Action:

```text
Очистити фільтри
```

---

## Error

```text
Не вдалося завантажити позичені книги
```

Action:

```text
Спробувати ще раз
```

---

## Missing active loan

```text
Інформацію про позику не знайдено
```

Show this if book has loan ownership status but active loan record is missing.
