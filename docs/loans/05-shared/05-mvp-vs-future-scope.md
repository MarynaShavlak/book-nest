# MVP vs Future Scope

## MVP

Included:

* two loan types;
* BookLoan entity;
* active loan page;
* create loan modal;
* edit loan;
* mark returned;
* calculated UI badges;
* search;
* filters;
* sorting;
* Book Details integration;
* Book Form integration;
* My Library integration;
* Dashboard contract.

---

## Future

Later:

* full loan history page;
* people/contact page;
* push/email reminders;
* Google Calendar;
* photos before/after lending;
* return condition note;
* trust rating for people;
* loan statistics;
* bulk reminders;
* archived returned books.

---

## Not MVP

Do not include in first version:

* automatic notifications;
* complex contact management;
* ratings for people;
* photo attachments;
* separate archive page;
* mass reminder sending;
* calendar integrations.
