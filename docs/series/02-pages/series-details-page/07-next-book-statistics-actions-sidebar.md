# Series Details Page — Next Book, Statistics, Actions Sidebar

> Source: `series-details-page.md`

### 5.12. Right Sidebar: Next Book

Block title:

```text
Наступна книга
```

Блок показує книгу, яку користувачу логічно читати далі.

Next book logic:

Наступна книга — це перша книга в серії, яка:

* ще не має `readingStatus = finished`;
* має найменший `partNumber` серед непрочитаних книг;
* іде після вже прочитаних книг.

Якщо є книга зі статусом `reading` або `rereading`, вона вважається поточною / наступною.

Example:

```text
Наступна книга:
Облога і буря
Книга 2

[Додати в чергу читання]
[Перейти до книги]
```

Якщо книга вже є в бібліотеці:

* показати кнопку **Перейти до книги**;
* якщо книга ще не в черзі, показати **Додати в чергу читання**;
* якщо книга вже в черзі, показати badge **У черзі**.

Якщо наступна книга ще не додана:

```text
Наступна книга ще не додана
```

Action:

```text
Додати книгу
```

### 5.13. Right Sidebar: Series Statistics

Block title:

```text
Статистика серії
```

У MVP показати:

| Field            | Description                                   |
| ---------------- | --------------------------------------------- |
| Усього книг      | загальна кількість книг у серії               |
| Прочитано        | кількість книг зі статусом finished           |
| Читаю            | кількість книг зі статусом reading            |
| У черзі          | кількість книг серії, доданих у Reading Queue |
| Ще не прочитано  | кількість непрочитаних книг                   |
| Середній рейтинг | якщо ratings уже підтримуються                |
| Сторінок у серії | якщо pages count доступний                    |

Example:

```text
Усього книг: 3
Прочитано: 2
Читаю: 1
У черзі: 1
Середній рейтинг: 4.5
```

Якщо частина даних недоступна, поле можна приховати.

### 5.14. Right Sidebar: Actions

Block title:

```text
Дії
```

Actions у MVP:

```text
Редагувати серію
Додати книгу в серію
```

Behavior:

| Action               | Behavior                                        |
| -------------------- | ----------------------------------------------- |
| Редагувати серію     | відкриває Edit Series flow                      |
| Додати книгу в серію | відкриває Add Book to Series / Create Book flow |

Optional action:

```text
Змінити порядок книг
```

Якщо reorder ще не реалізований, цю дію краще не показувати або залишити на future.

Destructive actions типу **Видалити серію** не потрібно показувати як основну дію в MVP. Їх можна винести в future або в окремий flow після підтвердження.
