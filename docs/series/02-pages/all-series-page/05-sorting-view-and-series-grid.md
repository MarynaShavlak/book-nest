# All Series Page — Sorting, View, Series Grid

> Source: `all-series-page.md`

### 5.7. Sorting Block

Sorting дозволяє змінити порядок серій.

MVP sorting options:

| Option             | Behavior                                                   |
| ------------------ | ---------------------------------------------------------- |
| Назва: А–Я         | сортує серії за назвою від A до Я                          |
| Назва: Я–А         | сортує серії за назвою від Я до A                          |
| Найбільший прогрес | спочатку серії з найбільшим прогресом                      |
| Найменший прогрес  | спочатку серії з найменшим прогресом                       |
| Найбільше книг     | спочатку серії з найбільшою кількістю книг                 |
| Нещодавно оновлені | спочатку серії, де нещодавно змінювалися книги або прогрес |

Recommended default sorting:

```text
Назва: А–Я
```

### 5.8. View Switch Block

У MVP основним виглядом є:

```text
Grid view
```

Optional:

```text
List view
```

Якщо list view не готовий, у MVP можна залишити тільки grid view.

---


### 5.9. Series Grid

Series Grid показує картки серій.

Grid має коректно працювати, якщо:

* у серії є custom cover;
* у серії немає custom cover;
* у серії є книги;
* у серії немає книг;
* у серії тільки одна книга;
* у серії невідомий total books count;
* у серії немає наступної книги;
* серія повністю прочитана.

---


### 5.10. Series Card

Series Card — основний UI-елемент сторінки.

На картці серії потрібно показувати:

| Element             | Description                                           |
| ------------------- | ----------------------------------------------------- |
| Cover / placeholder | custom cover, обкладинка першої книги або placeholder |
| Title               | назва серії                                           |
| Author              | автор серії або автор першої книги                    |
| Series status       | Завершена / Ще виходить / Невідомо                    |
| Books count         | кількість книг у серії                                |
| Read books count    | скільки книг прочитано                                |
| Progress bar        | прогрес читання серії                                 |
| Next book           | наступна книга для читання                            |
| Action              | Переглянути серію                                     |

Example:

```text
Двір шипів і троянд
Сара Дж. Маас

Ще виходить
5 книг

Прочитано 2 з 5
40%

Наступна книга:
Двір мороку і гніву

[Переглянути серію]
```

---


### 5.11. Empty Series Card

Якщо серія створена вручну, але ще не має книг, картка має показувати empty state.

Example:

```text
Двір шипів і троянд
Сара Дж. Маас

Ще виходить
0 книг

Книги ще не додані

[Переглянути серію]
[Додати книгу]
```

Button **Додати книгу** може відкривати Create Book flow з preselected series.
