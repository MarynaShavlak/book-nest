# All Series Page — Summary Cards

> Source: `all-series-page.md`

### 4.2. Header summary cards

Header summary cards показують коротку статистику по серіях користувача.

У MVP потрібно показати 4 cards:

| Card          | Description                                               |
| ------------- | --------------------------------------------------------- |
| Усього серій  | загальна кількість серій користувача                      |
| Прочитано     | кількість серій, які користувач повністю прочитав         |
| Недочитані    | кількість серій, які користувач почав, але ще не завершив |
| Книг у серіях | кількість книг у бібліотеці, які належать до серій        |

---

#### Card: Усього серій

Показує всі серії користувача.

Example:

```text
9
серій
```

У цей показник входять:

* серії з книгами;
* вручну створені серії без книг;
* завершені серії;
* серії, що ще виходять;
* серії з невідомим статусом.

---

#### Card: Прочитано

Показує кількість серій, які користувач повністю прочитав.

Example:

```text
3
прочитано
```

Important:

Label має бути саме **Прочитано**, а не **Завершено**, щоб не плутати з `seriesStatus = completed`.

```text
Прочитано = прогрес користувача.
Завершена = статус книжкового циклу.
```

---

#### Card: Недочитані

Показує кількість серій, які користувач почав, але ще не дочитав.

Example:

```text
5
недочитані
```

Серія вважається недочитаною, якщо:

* користувач прочитав або читає хоча б одну книгу серії;
* не всі книги серії прочитані;
* серія має більше ніж одну книгу або `totalBooksCount > 1`.

---

#### Card: Книг у серіях

Показує, скільки книг з бібліотеки користувача належать до серій.

Example:

```text
48
книг у серіях
```

Цей показник не рахує порожні серії без книг.

---


### 5.3. Header Summary Cards

Header summary cards показують короткий стан сторінки.

Cards у MVP:

```text
Усього серій
Прочитано
Недочитані
Книг у серіях
```

Cards мають бути компактними, візуально схожими на badges/cards з інших сторінок застосунку.
