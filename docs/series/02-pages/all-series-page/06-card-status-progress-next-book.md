# All Series Page — Card Status, Progress, Next Book

> Source: `all-series-page.md`

### 5.12. Series Status Badge

Series status показує стан книжкового циклу.

Options:

| Value     | Label       |
| --------- | ----------- |
| completed | Завершена   |
| ongoing   | Ще виходить |
| unknown   | Невідомо    |

Important:

```text
seriesStatus не означає, що користувач прочитав серію.
```

Тому на картці потрібно окремо показувати:

```text
Статус серії
Прогрес користувача
```

---


### 5.13. Progress Bar

Progress bar показує, яку частину серії користувач уже прочитав.

У прогрес входять тільки книги зі статусом:

```text
finished
```

Base formula:

```text
read books count / total books count * 100
```

Якщо `totalBooksCount` вказаний:

```text
Прочитано 2 з 5
40%
```

Якщо `totalBooksCount` не вказаний:

```text
Прочитано 2 з 4 доданих
50%
```

Якщо серія створена, але книг ще немає:

```text
0 книг
Прогрес ще недоступний
```

Якщо всі книги прочитані:

```text
Усі книги прочитані
100%
```

### 5.14. Next Book Block

Next Book показує, яку книгу користувачу логічно читати далі.

Наступна книга — це перша книга в серії, яка:

* ще не має `readingStatus = finished`;
* має найменший part number серед непрочитаних книг;
* іде після вже прочитаних або поточних книг.

Example:

```text
Наступна книга:
Двір мороку і гніву
Книга 2
```

Якщо всі книги прочитані:

```text
Усі книги прочитані
```

Якщо серія порожня:

```text
Додайте першу книгу в серію
```

Якщо наступна книга ще не додана в бібліотеку:

```text
Наступна книга ще не додана
```
