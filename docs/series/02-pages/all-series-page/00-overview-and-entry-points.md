# All Series Page — Overview and Entry Points

> Source: `all-series-page.md`

## 1. Purpose

Feature **All Series Page** дозволяє користувачу переглядати всі книжкові серії, які є в його бібліотеці BookNest.

Сторінка допомагає користувачу:

* бачити всі книжкові цикли в одному місці;
* створювати нову серію;
* відстежувати прогрес читання по кожній серії;
* швидко знаходити недочитані серії;
* бачити, яку книгу варто читати наступною;
* розуміти загальний стан своїх серій через коротку статистику;
* переходити на детальну сторінку конкретної серії.

All Series Page — це сторінка-огляд серій. Вона не відповідає за повну логіку створення, редагування, видалення або керування книгами всередині серії.

Повна логіка створення та редагування серії описується окремо:

```text
Feature: Create / Edit Series
```

---


## 2. Main idea

Сторінка **Серії** показує всі книжкові серії користувача.

Route:

```text
/series
```

Серія може з’явитися на сторінці двома способами:

* користувач створив серію вручну через Create Series flow;
* користувач додав книгу і вказав, що вона є частиною нової або вже існуючої серії.

У MVP підтримуються обидва сценарії:

```text
Scenario 1:
Користувач створює серію вручну зі сторінки /series.

Scenario 2:
Користувач додає книгу через Create Book flow і прив’язує її до серії.
```

Основна задача сторінки:

```text
Показати всі серії, їхній прогрес, наступну книгу та дати швидкий доступ до створення нової серії.
```

Important:

```text
All Series Page тільки запускає Create Series flow.
Поля, validation rules і submit behavior описуються в Feature: Create / Edit Series.
```

---


## 3. Entry points

Користувач може перейти на сторінку **Серії** з основної навігації застосунку.

Основний entry point:

| Entry point     | Behavior                     |
| --------------- | ---------------------------- |
| Sidebar → Серії | відкриває сторінку `/series` |

Додаткові entry points:

| Entry point       | Behavior                                                          |
| ----------------- | ----------------------------------------------------------------- |
| Dashboard         | перехід до всіх серій або недочитаних серій                       |
| Book Details Page | перехід до серії, до якої належить книга                          |
| My Library Page   | перехід до серії через series badge або meta info на картці книги |
| Create Book Form  | створення або вибір серії під час додавання книги                 |
