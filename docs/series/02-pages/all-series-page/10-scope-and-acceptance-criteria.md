# All Series Page — Scope and Acceptance Criteria

> Source: `all-series-page.md`

## 8. What is not included

У MVP для **All Series Page** не входить:

* повна логіка створення серії;
* редагування серії;
* видалення серії;
* об’єднання дублікатів серій;
* повне керування книгами всередині серії;
* drag-and-drop порядку книг у серії;
* автоматичне визначення серії з інтернету;
* імпорт повного списку книг серії;
* додавання відсутньої наступної книги в wishlist;
* улюблені серії;
* середній рейтинг серії;
* складні рекомендації;
* reading challenge по серіях;
* analytics по жанрах серій;
* окрема сторінка “Незавершені серії” в sidebar.

Important:

```text
Створення нової серії входить у MVP як flow, який запускається з All Series Page.
Деталі створення та редагування серії описуються в Feature: Create / Edit Series.
```

---


## 9. Acceptance Criteria

### Page access

* Користувач може відкрити сторінку `/series` через sidebar.
* Сторінка доступна тільки авторизованому користувачу.
* Користувач бачить тільки свої серії.

### Header

* Користувач бачить title **Серії**.
* Користувач бачить badge з кількістю серій.
* Користувач бачить subtitle сторінки.
* Користувач бачить summary cards у header.
* Header показує кількість усіх серій.
* Header показує кількість повністю прочитаних серій.
* Header показує кількість недочитаних серій.
* Header показує кількість книг у серіях.
* Користувач бачить кнопку **Створити серію** у header.

### Create series entry point

* Користувач може натиснути **Створити серію**.
* Після натискання відкривається Create Series flow.
* Після успішного створення серія з’являється на сторінці `/series`.
* Якщо серія створена без книг, вона показується як empty series card.
* Деталі полів, валідації та submit behavior не описуються в All Series Page.

### Tabs

* Користувач бачить вкладку **Усі серії**.
* Користувач бачить вкладку **Недочитані**.
* Користувач може перемикатися між вкладками.
* Вкладка **Усі серії** показує всі серії користувача.
* Вкладка **Недочитані** показує тільки серії, які користувач почав, але не завершив.
* Порожні серії не показуються у вкладці **Недочитані**.

### Search and filters

* Користувач може шукати серії за назвою.
* Користувач може шукати серії за автором.
* Користувач може шукати серії за назвою книги в серії.
* Користувач може фільтрувати серії за статусом серії.
* Користувач може фільтрувати серії за станом читання.
* Користувач може фільтрувати серії без книг.
* Користувач може сортувати серії.

### Series card

* Користувач бачить картки серій.
* Кожна картка показує cover або placeholder.
* Кожна картка показує назву серії.
* Кожна картка показує автора, якщо він доступний.
* Кожна картка показує статус серії.
* Кожна картка показує кількість книг.
* Кожна картка показує кількість прочитаних книг.
* Кожна картка показує progress bar, якщо прогрес доступний.
* Кожна картка показує наступну книгу, якщо її можна визначити.
* Якщо всі книги серії прочитані, картка показує відповідний стан.
* Якщо серія не має книг, картка показує empty series state.
* Користувач може перейти на детальну сторінку серії.

### Progress

* Прогрес серії рахується по книгах зі статусом `finished`.
* Якщо `totalBooksCount` вказаний, прогрес рахується від нього.
* Якщо `totalBooksCount` не вказаний, прогрес рахується від кількості книг серії, доданих у бібліотеку.
* Progress bar не ламається, якщо в серії немає прочитаних книг.
* Для порожньої серії progress bar може не показуватися.
* Progress bar показує 100%, якщо всі книги серії прочитані.

### Right sidebar

* Користувач бачить right sidebar на desktop.
* Right sidebar містить блок **Швидкі дії**.
* Right sidebar містить блок **Продовжити серію**.
* Right sidebar містить блок **Найближчі до завершення**.
* Right sidebar містить блок **Статус циклів**.
* Right sidebar не дублює основний список серій.
* На mobile right sidebar переходить під основний контент.

### Empty and error states

* Якщо серій немає, користувач бачить empty state.
* Empty state дозволяє створити серію.
* Empty state дозволяє додати книгу.
* Якщо у вкладці **Недочитані** немає серій, користувач бачить окремий empty state.
* Якщо search не має результатів, користувач бачить empty search state.
* Якщо серії не завантажилися, користувач бачить error state.

### Scope

* All Series Page показує всі серії користувача.
* All Series Page дозволяє запустити Create Series flow.
* All Series Page не описує повну логіку створення серії.
* All Series Page не включає редагування серії.
* All Series Page не включає видалення серії.
* All Series Page не включає повне керування книгами всередині серії.
* Перехід на Series Details Page працює, але сама Series Details Page описується окремою документацією.
