# Filter and Sort Rules

## All Series Page filters

Common filters:

- search by title/author;
- series status;
- reading state;
- unfinished only;
- completed only.

## Sorting

Recommended MVP sorting options:

- recently updated;
- title A-Z;
- progress;
- closest to completion;
- most books;
- least books.

## Implementation note

Filters and sorting should operate on normalized derived series summaries, not raw books arrays inside components.
