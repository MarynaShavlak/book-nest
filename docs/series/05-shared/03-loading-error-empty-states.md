# Loading, Error, Empty States

## Loading

Use skeletons for page-level loading and disable mutation buttons during submit.

## Empty states

Common empty states:

- no series yet;
- no unfinished series;
- empty search results;
- series has no books;
- next book is missing;
- duplicate/missing part number in existing data.

## Error states

Common error states:

- failed to load series;
- failed to save series;
- failed to add book;
- failed to remove relation;
- failed to delete series;
- series not found.

## Rule

Error messages should tell the user what failed and what they can do next.
