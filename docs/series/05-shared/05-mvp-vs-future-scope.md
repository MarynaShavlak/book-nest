# MVP vs Future Scope

## MVP

- Create/edit/delete series.
- Add existing book to series.
- Create new book from series.
- Add missing book placeholder.
- Remove/unlink book from series.
- Part number ordering.
- Basic progress and next-book logic.
- All Series Page.
- Series Details Page.
- Series section in Book Form.

## Future

- Drag-and-drop series reorder.
- Multi-series membership for books.
- External metadata import.
- Advanced charts/analytics for series.
- Shared/collaborative series.
- Bulk actions.
- Advanced duplicate merging.
