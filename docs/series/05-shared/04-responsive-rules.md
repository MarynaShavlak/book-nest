# Responsive Rules

## Desktop

- Use a main content area plus right sidebar for Series Details Page and All Series Page.
- Cards can use grid layout.

## Tablet

- Keep cards in 2-column grid when possible.
- Move right sidebar blocks below main content if space is limited.

## Mobile

- Use a single-column layout.
- Convert toolbars into stacked controls or collapsible filters.
- Keep primary actions visible near the top.
- Avoid dense tables; prefer cards or compact rows.
