# Feature: Series Details Page

## 1. Purpose

Feature **Series Details Page** дозволяє користувачу переглянути детальну інформацію про конкретну книжкову серію в BookNest.

Сторінка допомагає користувачу:

* зрозуміти, що це за серія;
* побачити всі книги серії у правильному порядку;
* відстежити свій прогрес по серії;
* побачити, які книги вже прочитані;
* побачити, яка книга читається зараз;
* зрозуміти, яку книгу читати наступною;
* швидко перейти до конкретної книги;
* запустити flow додавання книги в цю серію;
* запустити flow редагування серії;
* побачити коротку статистику серії.

Series Details Page є продовженням сторінки **All Series Page**.

Якщо **All Series Page** показує всі серії користувача, то **Series Details Page** показує одну конкретну серію та книги, які до неї належать.

Series Details Page не відповідає за повну логіку створення, редагування або видалення серії. Вона тільки дає entry points для відповідних flows.

Повна логіка створення та редагування серії описується окремо:

```text
Feature: Create / Edit Series
```

Повна логіка додавання книги до серії може бути описана окремо:

```text
Feature: Add Book to Series
```

---

## 2. Main idea

Сторінка **Series Details Page** показує одну книжкову серію та всі книги, які до неї належать.

Route:

```text
/series/:seriesId
```

Основна задача сторінки:

```text
Показати користувачу повний стан конкретної серії: що вже прочитано, що читати далі, які книги є в бібліотеці і який загальний прогрес.
```

Сторінка має відповідати на головні питання:

```text
Що це за серія?
Скільки в ній книг?
Які книги вже прочитані?
Яка книга читається зараз?
Яку книгу читати наступною?
Яких книг ще немає в бібліотеці?
```

Important:

```text
seriesStatus ≠ user reading progress
```

`seriesStatus` показує стан книжкового циклу:

* Завершена;
* Ще виходить;
* Невідомо.

User reading progress показує, наскільки користувач сам просунувся в читанні серії.

Example:

```text
Серія може бути завершена автором, але користувач прочитав тільки 2 з 5 книг.
```

## 3. Entry points

Користувач може відкрити Series Details Page з різних частин застосунку.

| Entry point       | Behavior                                                 |
| ----------------- | -------------------------------------------------------- |
| All Series Page   | клік по картці серії або кнопці “Переглянути серію”      |
| Book Details Page | клік по блоку серії на сторінці книги                    |
| Dashboard         | клік по блоку “Недочитані серії” або “Продовжити серію”  |
| Reading Queue     | перехід до серії, якщо книга належить до серії           |
| My Library Page   | перехід через series badge або meta info на картці книги |

Основний entry point для MVP:

```text
All Series Page → Series Card → Series Details Page
```

## 4. Page layout

Сторінка має бути побудована як детальна сторінка однієї сутності з основним контентом і правою sidebar-колонкою.

Recommended layout:

```text
[Top navigation / breadcrumb]

[Series hero section]

[Main content layout]
  Left / center:
    [Tabs]
    [Books in series list]
    [Reading order block]
    [About series tab content]

  Right sidebar:
    [Your progress in series]
    [Next book]
    [Series statistics]
    [Actions]
```

---

### 4.1. Top navigation

У верхній частині сторінки потрібно показати breadcrumb або back action.

Recommended breadcrumb:

```text
Серії / Назва серії
```

Example:

```text
Серії / Тінь і кістка
```

Back action:

```text
← Серії
```

Behavior:

* back action повертає користувача на `/series`;
* breadcrumb показує, що користувач знаходиться всередині конкретної серії.

---

### 4.2. Series hero section

Hero section — це головний верхній блок сторінки.

Він має містити:

* cover / placeholder;
* назву серії;
* автора;
* короткий опис;
* жанри / теги;
* series status;
* кількість книг;
* роки виходу, якщо є;
* основні actions.

Example:

```text
Тінь і кістка
Лі Бардуго

Фентезі · Young Adult · Пригоди

Серія завершена · 3 книги · 2012–2014
```

---

### 4.3. Main content area

Main content area містить основну робочу частину сторінки.

У MVP тут мають бути:

* tabs;
* список книг серії;
* кнопка “Додати книгу в цю серію”;
* блок “Порядок читання”, якщо він потрібен.

Main content не має містити повну форму редагування серії або повну форму створення книги. Такі дії відкривають окремі flows.

---

### 4.4. Right sidebar

Right sidebar показує коротку, але важливу інформацію про стан серії.

У MVP right sidebar має містити:

```text
Ваш прогрес у серії
Наступна книга
Статистика серії
Дії
```

Right sidebar не має дублювати весь список книг. Його задача — швидко показати користувачу, що відбувається з серією і що можна зробити далі.

---

### 4.5. Mobile layout

На mobile сторінка має перебудовуватися в одну колонку.

Recommended mobile order:

```text
1. Top navigation
2. Series cover
3. Series title and main info
4. Main actions
5. Your progress in series
6. Next book
7. Tabs
8. Books in series
9. Series statistics
10. Other actions
```

Right sidebar blocks на mobile переходять під hero або під основний контент.

## 5. UI blocks

### 5.1. Series Hero

Series Hero показує головну інформацію про серію.

Content:

| Element             | Description                                                 |
| ------------------- | ----------------------------------------------------------- |
| Cover / placeholder | custom cover серії, обкладинка першої книги або placeholder |
| Title               | назва серії                                                 |
| Author              | автор серії або основний автор                              |
| Description         | короткий опис серії                                         |
| Genres / tags       | жанри або теги серії                                        |
| Series status       | Завершена / Ще виходить / Невідомо                          |
| Books count         | кількість книг у серії                                      |
| Years               | роки виходу серії, якщо є                                   |
| Actions             | редагувати серію, menu actions                              |

---

### 5.2. Cover / Placeholder

Якщо серія має власну обкладинку, показується вона.

Якщо власної обкладинки немає, показати:

* обкладинку першої книги в серії;
* або placeholder, якщо книг немає чи обкладинка відсутня.

MVP recommendation:

```text
Показувати custom cover серії.
Якщо custom cover немає — показувати обкладинку першої книги.
Якщо обкладинки немає — показувати placeholder.
```

---

### 5.3. Series Status Badge

Series status показує стан книжкового циклу.

Options:

| Value     | Label       |
| --------- | ----------- |
| completed | Завершена   |
| ongoing   | Ще виходить |
| unknown   | Невідомо    |

Important:

```text
Series status не означає, що користувач прочитав серію.
```

Тому поруч або в sidebar потрібно окремо показувати прогрес користувача.

---

### 5.4. Hero actions

У hero section можна показати:

```text
Редагувати серію
More actions
```

Recommended MVP:

* у hero показати **Редагувати серію**;
* під списком книг показати **Додати книгу в цю серію**;
* у right sidebar продублювати швидку дію **Додати книгу в серію**.

Behavior:

```text
Редагувати серію → відкриває Edit Series flow.
Додати книгу в цю серію → відкриває Add Book to Series / Create Book flow.
```

Important:

```text
Series Details Page не описує поля, validation rules і submit behavior редагування серії.
Це описується в Feature: Create / Edit Series.
```

---

### 5.5. Tabs

Щоб сторінка не була перевантажена, у MVP достатньо двох вкладок:

```text
Книги серії
Про серію
```

#### Tab: Книги серії

Основна вкладка.

Показує:

* всі книги серії;
* правильний порядок книг;
* номер кожної частини;
* статус читання;
* статус володіння;
* queue badge, якщо книга в черзі;
* прогрес книги, якщо вона читається;
* рейтинг, якщо книга прочитана;
* actions для кожної книги.

#### Tab: Про серію

Показує повнішу інформацію про серію:

* опис серії;
* автора;
* жанри;
* теги;
* роки виходу;
* статус серії;
* загальну кількість книг.

---

### 5.6. Books in Series List

Books in Series List — головний блок сторінки.

Книги мають бути відсортовані за номером частини:

```text
partNumber ASC
```

Для кожної книги потрібно показати:

| Element          | Description                                 |
| ---------------- | ------------------------------------------- |
| Part number      | номер книги в серії                         |
| Cover            | обкладинка книги або placeholder            |
| Title            | назва книги                                 |
| Original title   | оригінальна назва, якщо є                   |
| Author           | автор книги                                 |
| Publication date | дата або рік публікації, якщо є             |
| Reading status   | статус читання                              |
| Ownership status | статус володіння                            |
| Queue badge      | badge “У черзі”, якщо книга в reading queue |
| Progress         | прогрес, якщо книга читається               |
| Rating           | оцінка, якщо є                              |
| Actions          | переглянути книгу, menu actions             |

---

### 5.7. Book row states

Книга в серії може мати різні стани.

#### Finished book

Якщо книга має:

```text
readingStatus = finished
```

Показати badge:

```text
Прочитано
```

Optional:

* дата завершення;
* рейтинг.

---

#### Currently reading book

Якщо книга має:

```text
readingStatus = reading
```

Показати badge:

```text
Читаю
```

Також показати:

* поточну сторінку;
* progress bar;
* відсоток прогресу.

---

#### Not started book

Якщо книга має:

```text
readingStatus = not_started
```

Показати badge:

```text
Не почато
```

---

#### Want to read book

Якщо книга має:

```text
readingStatus = want_to_read
```

Показати badge:

```text
Хочу прочитати
```

---

#### Paused book

Якщо книга має:

```text
readingStatus = paused
```

Показати badge:

```text
На паузі
```

---

#### DNF book

Якщо книга має:

```text
readingStatus = dnf
```

Показати badge:

```text
Покинуто
```

---

#### Rereading book

Якщо книга має:

```text
readingStatus = rereading
```

Показати badge:

```text
Перечитую
```

У MVP `rereading` можна показувати як активний стан читання, якщо цей статус уже доступний у застосунку.

---

#### Book in queue

Якщо книга додана в Reading Queue, показати окремий badge:

```text
У черзі
```

Important:

```text
У черзі — це не readingStatus.
Це окремий стан, пов’язаний з Reading Queue.
```

---

#### Missing book

Якщо книга відома як частина серії, але ще не додана в бібліотеку користувача, показати стан:

```text
Ще не додано
```

Actions:

```text
Додати цю книгу
```

Important:

```text
У MVP missing books показуються тільки тоді, коли вони вже відомі в межах даних користувача.
Автоматичне підтягування відсутніх книг з інтернету не входить у MVP.
```

---

### 5.8. Add Book to This Series Button

На сторінці має бути кнопка:

```text
+ Додати книгу в цю серію
```

Placement:

* під списком книг;
* або в hero / right sidebar як secondary action.

MVP behavior:

```text
Кнопка відкриває Add Book to Series flow або Create Book flow, де ця серія вже вибрана автоматично.
```

Після збереження книги:

* книга додається до цієї серії;
* отримує номер частини;
* з’являється у списку книг серії;
* прогрес серії перераховується.

Important:

```text
Series Details Page тільки запускає Add Book to Series flow.
Повна логіка вибору існуючої книги, створення нової книги, part number і validation описується окремо.
```

---

### 5.9. Reading Order Block

Reading Order Block показує рекомендований порядок читання книг у серії.

Для MVP цей блок можна показувати під списком книг, без окремої вкладки.

Example:

```text
1 Тінь і кістка → 2 Облога і буря → 3 Руїна і відновлення
```

Purpose:

* швидко показати порядок частин;
* допомогти користувачу не загубитися;
* зробити сторінку зручнішою для довгих серій.

Якщо серія має тільки одну книгу або порядок очевидний, цей блок можна не показувати.

---

### 5.10. Right Sidebar: Your Progress in Series

Block title:

```text
Ваш прогрес у серії
```

Показати:

* прочитано книг;
* загальна кількість книг;
* відсоток прогресу;
* progress bar;
* скільки книг читається зараз;
* скільки ще не прочитано.

Example:

```text
2 з 3 книг
67%

Прочитано: 2 книги
Читаєте зараз: 1 книга
Ще не прочитано: 0 книг
```

---

### 5.11. Progress calculation

Прогрес серії рахується по книгах зі статусом:

```text
finished
```

Base formula:

```text
read books count / total books count * 100
```

Якщо `totalBooksCount` вказаний:

```text
Прочитано 2 з 5
40%
```

Якщо `totalBooksCount` не вказаний:

```text
Прочитано 2 з 4 доданих
50%
```

Якщо серія не має книг:

```text
Прогрес ще недоступний
```

Якщо всі книги прочитані:

```text
Усі книги прочитані
100%
```

Important:

```text
Якщо totalBooksCount менший за кількість уже доданих книг, це має вирішуватися у Feature: Create / Edit Series.
Series Details Page тільки відображає актуальний стан.
```

---

### 5.12. Right Sidebar: Next Book

Block title:

```text
Наступна книга
```

Блок показує книгу, яку користувачу логічно читати далі.

Next book logic:

Наступна книга — це перша книга в серії, яка:

* ще не має `readingStatus = finished`;
* має найменший `partNumber` серед непрочитаних книг;
* іде після вже прочитаних книг.

Якщо є книга зі статусом `reading` або `rereading`, вона вважається поточною / наступною.

Example:

```text
Наступна книга:
Облога і буря
Книга 2

[Додати в чергу читання]
[Перейти до книги]
```

Якщо книга вже є в бібліотеці:

* показати кнопку **Перейти до книги**;
* якщо книга ще не в черзі, показати **Додати в чергу читання**;
* якщо книга вже в черзі, показати badge **У черзі**.

Якщо наступна книга ще не додана:

```text
Наступна книга ще не додана
```

Action:

```text
Додати книгу
```

---

### 5.13. Right Sidebar: Series Statistics

Block title:

```text
Статистика серії
```

У MVP показати:

| Field            | Description                                   |
| ---------------- | --------------------------------------------- |
| Усього книг      | загальна кількість книг у серії               |
| Прочитано        | кількість книг зі статусом finished           |
| Читаю            | кількість книг зі статусом reading            |
| У черзі          | кількість книг серії, доданих у Reading Queue |
| Ще не прочитано  | кількість непрочитаних книг                   |
| Середній рейтинг | якщо ratings уже підтримуються                |
| Сторінок у серії | якщо pages count доступний                    |

Example:

```text
Усього книг: 3
Прочитано: 2
Читаю: 1
У черзі: 1
Середній рейтинг: 4.5
```

Якщо частина даних недоступна, поле можна приховати.

---

### 5.14. Right Sidebar: Actions

Block title:

```text
Дії
```

Actions у MVP:

```text
Редагувати серію
Додати книгу в серію
```

Behavior:

| Action               | Behavior                                        |
| -------------------- | ----------------------------------------------- |
| Редагувати серію     | відкриває Edit Series flow                      |
| Додати книгу в серію | відкриває Add Book to Series / Create Book flow |

Optional action:

```text
Змінити порядок книг
```

Якщо reorder ще не реалізований, цю дію краще не показувати або залишити на future.

Destructive actions типу **Видалити серію** не потрібно показувати як основну дію в MVP. Їх можна винести в future або в окремий flow після підтвердження.

## 6. Actions

### 6.1. Open series details

Користувач може відкрити сторінку конкретної серії.

Behavior:

* користувач натискає на картку серії на All Series Page;
* відкривається сторінка `/series/:seriesId`;
* користувач бачить детальну інформацію про серію.

---

### 6.2. Go back to all series

Користувач може повернутися до сторінки всіх серій.

Behavior:

* користувач натискає breadcrumb або back action;
* відкривається `/series`.

---

### 6.3. Edit series

Користувач може натиснути:

```text
Редагувати серію
```

Entry points:

* hero section;
* right sidebar actions;
* more menu, якщо він є.

Behavior:

1. Користувач натискає **Редагувати серію**.
2. Відкривається Edit Series flow.
3. Користувач редагує серію.
4. Після збереження Series Details Page оновлює дані.

Important:

```text
Series Details Page не описує поля, validation rules і submit behavior редагування.
Це описується в Feature: Create / Edit Series.
```

Expected update after edit:

* hero section оновлюється;
* series status оновлюється;
* cover оновлюється, якщо його змінили;
* right sidebar statistics можуть перерахуватися;
* список книг не змінюється, якщо редагувалися тільки поля серії.

---

### 6.4. Add book to this series

Користувач може додати книгу в поточну серію.

Behavior:

1. Користувач натискає **Додати книгу в цю серію**.
2. Відкривається Add Book to Series або Create Book flow.
3. Поточна серія вже вибрана автоматично.
4. Після submit книга додається до цієї серії.
5. Список книг і прогрес серії оновлюються.

Important:

```text
Детальна логіка вибору існуючої книги, створення нової книги, partNumber і validation описується окремо.
```

---

### 6.5. Open book details

Користувач може перейти до конкретної книги зі списку книг серії.

Behavior:

* користувач натискає **Переглянути** або клікає по книзі;
* відкривається Book Details Page;
* route:

```text
/books/:bookId
```

---

### 6.6. Add next book to reading queue

Якщо наступна книга є в бібліотеці і ще не додана в Reading Queue, користувач може натиснути:

```text
Додати в чергу читання
```

Behavior:

* книга додається в Reading Queue;
* на книзі з’являється badge **У черзі**;
* duplicate в черзі не створюється.

Якщо книга вже в черзі:

```text
Показати badge “У черзі” і не додавати дубль.
```

---

### 6.7. Add missing book

Якщо наступна книга або книга зі списку серії ще не додана в бібліотеку, користувач може натиснути:

```text
Додати книгу
```

Behavior:

* відкривається Add Book to Series / Create Book flow;
* серія вже вибрана автоматично;
* part number може бути prefilled, якщо він відомий;
* після збереження книга з’являється у списку серії.

Important:

```text
Автоматичне підтягування missing books з інтернету не входить у MVP.
```

---

## 7. States

### 7.1. Loading state

Показується, коли сторінка завантажує дані серії.

Recommended UI:

* skeleton для hero section;
* skeleton для списку книг;
* skeleton для sidebar blocks.

---

### 7.2. Empty state: series has no books

Показується, якщо серія створена, але в ній ще немає книг.

Content:

```text
У цій серії ще немає книг
Додайте першу книгу, щоб почати формувати серію.
```

Action:

```text
Додати книгу
```

---

### 7.3. State: all books are finished

Показується, якщо всі книги серії прочитані користувачем.

Content:

```text
Серію прочитано
Ви прочитали всі додані книги цієї серії.
```

Якщо `totalBooksCount` вказаний і всі книги прочитані:

```text
Прогрес: 100%
```

Important:

```text
“Серію прочитано” означає user reading progress.
Це не те саме, що seriesStatus = completed.
```

---

### 7.4. State: next book is missing

Показується, якщо наступна книга визначена, але її ще немає в бібліотеці.

Content:

```text
Наступна книга ще не додана
Додайте її в бібліотеку, щоб продовжити серію.
```

Action:

```text
Додати книгу
```

---

### 7.5. State: duplicate part number

Якщо дві або більше книги мають однаковий номер частини, потрібно показати warning.

Content:

```text
У серії є книги з однаковим номером частини
Перевірте порядок книг, щоб серія відображалася правильно.
```

Behavior:

* книги все одно показуються;
* користувач бачить warning;
* редагування номера частини може бути винесене в Edit Book або Add Book to Series flow.

---

### 7.6. State: missing part number

Якщо книга належить до серії, але не має номера частини, вона показується в кінці списку.

Content:

```text
Номер частини не вказаний
```

Behavior:

* книга показується після книг із part number;
* користувач може перейти до редагування книги, щоб додати номер частини.

---

### 7.7. Not found state

Якщо серія не існує або не належить користувачу, показати generic state.

Content:

```text
Серію не знайдено
```

Action:

```text
Повернутися до серій
```

---

### 7.8. Error state

Якщо сторінку не вдалося завантажити, показати error state.

Content:

```text
Не вдалося завантажити серію
Спробуйте оновити сторінку.
```

Action:

```text
Спробувати ще раз
```

---

## 8. What is not included

У MVP для **Series Details Page** не входить:

* повна логіка редагування серії;
* повна логіка додавання книги до серії;
* створення серії;
* видалення серії;
* вкладка Нотатки по серії;
* вкладка Рекомендації;
* вкладка Відгуки;
* схожі серії;
* поділитися серією;
* копіювати посилання;
* улюблений персонаж серії;
* улюблений момент серії;
* персонажі серії;
* спойлерні нотатки по серії;
* drag-and-drop порядок книг;
* складний reading order для спін-офів;
* тип книги: основна / спін-оф / новела / бонус;
* автоматичне підтягування відсутніх книг із зовнішніх джерел;
* автоматичні рекомендації схожих серій;
* повна статистика по часу читання;
* видалення серії як основна дія;
* повне керування всіма книгами серії без переходу в Book Details / Edit Book.

Important:

```text
Series Details Page може мати action “Редагувати серію”, але повна логіка Edit Series описується окремо.
Series Details Page може мати action “Додати книгу в серію”, але повна логіка Add Book to Series описується окремо.
```

## 9. Acceptance Criteria

### Page access

* Користувач може відкрити сторінку конкретної серії.
* Сторінка має route `/series/:seriesId`.
* Користувач бачить тільки свої серії.
* Якщо серія не існує, користувач бачить not found state.
* Якщо серія не належить користувачу, користувач не бачить її дані.

### Navigation

* Користувач бачить breadcrumb або back action.
* Користувач може повернутися на All Series Page.
* Breadcrumb показує назву поточної серії.

### Hero section

* Користувач бачить cover або placeholder серії.
* Користувач бачить назву серії.
* Користувач бачить автора, якщо він доступний.
* Користувач бачить опис серії, якщо він доданий.
* Користувач бачить жанри або теги, якщо вони додані.
* Користувач бачить статус серії.
* Користувач бачить кількість книг у серії.
* Користувач бачить роки виходу, якщо вони доступні.
* Користувач бачить action **Редагувати серію**.
* Action **Редагувати серію** відкриває Edit Series flow.

### Tabs

* Користувач бачить вкладку **Книги серії**.
* Користувач бачить вкладку **Про серію**.
* Вкладка **Книги серії** показує список книг серії.
* Вкладка **Про серію** показує повну інформацію про серію.

### Books list

* Усі книги серії відображаються у правильному порядку.
* Порядок книг базується на `partNumber`.
* Для кожної книги показується номер частини.
* Для кожної книги показується обкладинка або placeholder.
* Для кожної книги показується назва.
* Для кожної книги показується автор.
* Для кожної книги показується reading status.
* Для кожної книги показується ownership status, якщо він доступний.
* Якщо книга є в Reading Queue, показується badge **У черзі**.
* Якщо книга читається зараз, показується progress.
* Якщо книга прочитана і має rating, показується rating.
* Для кожної книги є action **Переглянути книгу**.
* Якщо книги немає в бібліотеці, показується state **Ще не додано**.
* Якщо книги немає в бібліотеці, користувач може натиснути **Додати книгу**.

### Add book to series entry point

* Користувач бачить кнопку **Додати книгу в цю серію**.
* Після натискання відкривається Add Book to Series або Create Book flow.
* Поточна серія вибрана автоматично.
* Після успішного додавання книги список книг оновлюється.
* Після успішного додавання книги прогрес серії перераховується.
* Деталі полів, валідації та submit behavior не описуються в Series Details Page.

### Progress

* Користувач бачить блок **Ваш прогрес у серії**.
* Прогрес рахується по книгах зі статусом `finished`.
* Якщо `totalBooksCount` вказаний, прогрес рахується від нього.
* Якщо `totalBooksCount` не вказаний, прогрес рахується від кількості доданих книг.
* Користувач бачить кількість прочитаних книг.
* Користувач бачить загальну кількість книг.
* Користувач бачить progress bar.
* Користувач бачить відсоток прогресу.
* Якщо серія не має книг, прогрес не ламається.
* Стан **Серію прочитано** не плутається зі статусом серії **Завершена**.

### Next book

* Користувач бачить блок **Наступна книга**.
* Наступна книга визначається автоматично.
* Якщо є книга зі статусом `reading`, вона вважається поточною / наступною.
* Якщо є книга зі статусом `rereading`, вона може вважатися поточною / наступною.
* Якщо наступна книга є в бібліотеці, користувач може перейти до неї.
* Якщо наступна книга є в бібліотеці і не в черзі, користувач може додати її в Reading Queue.
* Якщо наступна книга вже в черзі, показується badge **У черзі**.
* Якщо наступна книга ще не додана, користувач може додати її через Add Book to Series / Create Book flow.

### Right sidebar

* Користувач бачить right sidebar на desktop.
* Right sidebar містить блок **Ваш прогрес у серії**.
* Right sidebar містить блок **Наступна книга**.
* Right sidebar містить блок **Статистика серії**.
* Right sidebar містить блок **Дії**.
* Right sidebar не дублює повний список книг.
* На mobile right sidebar переходить під основний контент.

### States

* Якщо серія не має книг, користувач бачить empty state.
* Якщо всі книги прочитані, користувач бачить state завершення читання серії.
* Якщо наступної книги немає в бібліотеці, користувач бачить відповідний state.
* Якщо є дублікати part number, користувач бачить warning.
* Якщо у книги немає part number, вона показується в кінці списку.
* Якщо сторінка не завантажилася, користувач бачить error state.

### Scope

* Series Details Page показує одну конкретну серію.
* Series Details Page показує список книг серії.
* Series Details Page показує прогрес користувача по серії.
* Series Details Page показує наступну книгу.
* Series Details Page дозволяє запустити Edit Series flow.
* Series Details Page дозволяє запустити Add Book to Series flow.
* Series Details Page не описує повну логіку редагування серії.
* Series Details Page не описує повну логіку додавання книги до серії.
* Series Details Page не включає drag-and-drop reorder.
* Series Details Page не включає рекомендації, відгуки, нотатки по серії та схожі серії в MVP.
