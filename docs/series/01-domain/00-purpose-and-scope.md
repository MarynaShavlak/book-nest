# Purpose and Scope

## Purpose

The Series module lets the user create and manage book series, connect books to a series, order books by part number, track reading progress, and navigate from a series to the next book.

## MVP scope

Included:

- All Series Page.
- Series Details Page.
- Create / Edit Series.
- Add existing book to series.
- Create new book inside series.
- Add missing book placeholder.
- Remove / unlink book from series.
- Delete series safely.
- Series section in Create / Edit Book Form.
- Part number and progress calculation logic.

Not included in MVP:

- Multi-series membership for one book.
- Drag-and-drop reorder as the primary MVP ordering method.
- Collaborative/shared series.
- Advanced analytics beyond basic progress and counts.
- Automatic metadata import from external APIs.
