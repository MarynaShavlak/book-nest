# Create / Edit Series — Scope and Acceptance Criteria

> Source: `create-edit-series.md`

## 12. What is not included

У MVP для **Create / Edit Series** не входить:

* видалення серії;
* merge duplicate series;
* автоматичне підтягування інформації про серію з інтернету;
* автоматичне визначення всіх книг серії;
* додавання книг до серії всередині цієї форми;
* відв’язування книг від серії;
* зміна part number книг;
* drag-and-drop порядку книг;
* складний reading order для спін-офів;
* типи книг у серії: основна, новела, спін-оф, бонус;
* спойлерні нотатки по серії;
* персонажі серії;
* рекомендації схожих серій.

Important:

```text
Create / Edit Series відповідає тільки за поля самої серії.
Керування книгами всередині серії описується окремо.
```

## 13. Acceptance Criteria

### Create mode

* Користувач може відкрити Create Series flow з All Series Page.
* Користувач може відкрити Create Series flow з empty state.
* Користувач може створити серію вручну.
* Користувач може створити серію без книг.
* Після створення серія з’являється на All Series Page.
* Якщо серія створена без книг, вона показується як empty series.
* Якщо Create Series flow відкритий з Create Book Form, створена серія може бути автоматично вибрана у формі книги.

### Edit mode

* Користувач може відкрити Edit Series flow з Series Details Page.
* Форма редагування відкривається з поточними даними серії.
* Користувач може змінити назву серії.
* Користувач може змінити автора серії.
* Користувач може змінити статус серії.
* Користувач може змінити загальну кількість книг.
* Користувач може змінити опис серії.
* Користувач може змінити жанри або теги серії.
* Користувач може змінити або прибрати custom cover.
* Після збереження оновлена інформація показується на Series Details Page.
* Після збереження оновлена інформація показується на All Series Page.

### Required fields

* Назва серії є required.
* Статус серії є required.
* Якщо required поля не заповнені, серія не створюється і не оновлюється.
* Користувач бачить validation errors для required полів.

### Series status

* Користувач може вибрати тільки один статус серії.
* Доступні статуси: Завершена, Ще виходить, Невідомо.
* Default status у create mode — Невідомо.
* Статус серії не змінює reading statuses книг.
* Статус серії не означає, що користувач прочитав серію.

### Total books count

* Поле загальної кількості книг optional.
* Якщо поле заповнене, значення має бути цілим числом.
* Значення має бути більше або дорівнювати 1.
* Значення не може бути меншим за кількість книг, уже доданих у серію.
* Якщо поле очищене, прогрес серії рахується по доданих книгах.

### Duplicate check

* При створенні серії система перевіряє potential duplicate title.
* Duplicate check виконується в межах поточного користувача.
* Duplicate check є case-insensitive.
* Якщо знайдено potential duplicate, користувач бачить warning.
* Користувач може перейти до існуючої серії або створити нову серію все одно.

### Cover

* Користувач може додати custom cover серії.
* Користувач може змінити custom cover.
* Користувач може прибрати custom cover.
* Якщо custom cover немає, використовується обкладинка першої книги.
* Якщо обкладинки першої книги немає, показується placeholder.

### Cancel and unsaved changes

* Користувач може скасувати створення серії.
* Користувач може скасувати редагування серії.
* Якщо є незбережені зміни, користувач бачить confirmation.
* Якщо користувач підтверджує закриття, зміни не зберігаються.

### Scope

* Create / Edit Series відповідає тільки за створення та редагування даних серії.
* Create / Edit Series не видаляє книги з серії.
* Create / Edit Series не змінює порядок книг у серії.
* Create / Edit Series не змінює part number книг.
* Create / Edit Series не змінює reading status книг.
* Create / Edit Series не змінює ownership status книг.
* Delete Series описується окремою feature documentation.
* Add Book to Series описується окремою feature documentation.
