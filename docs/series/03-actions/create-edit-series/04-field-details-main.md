# Create / Edit Series — Main Field Details

> Source: `create-edit-series.md`

## 7. Fields

### 7.1. Fields overview

| Field                   | Required | Type                        | Description                        |
| ----------------------- | -------- | --------------------------- | ---------------------------------- |
| Назва серії             | Так      | text input                  | основна назва серії                |
| Автор                   | Ні       | autocomplete / text input   | автор серії або основний автор     |
| Статус серії            | Так      | select / chips              | Завершена / Ще виходить / Невідомо |
| Загальна кількість книг | Ні       | number input                | скільки книг у серії всього        |
| Опис серії              | Ні       | textarea                    | короткий опис без спойлерів        |
| Жанри                   | Ні       | multi-select                | жанри серії                        |
| Теги                    | Ні       | tag input / multi-select    | користувацькі теги                 |
| Обкладинка серії        | Ні       | image upload / image picker | custom cover серії                 |

### 8.1. Назва серії

| Parameter         | Value                 |
| ----------------- | --------------------- |
| Label             | Назва серії *         |
| Placeholder       | Введіть назву серії   |
| Type              | Text input            |
| Required          | Так                   |
| Min length        | 1 символ після `trim` |
| Max length        | 150 символів          |
| Empty spaces only | Заборонено            |
| HTML tags         | Заборонено            |

#### Logic

* назва серії є required полем;
* без назви серія не може бути створена;
* у edit mode назву можна змінити;
* після зміни назви вона оновлюється на All Series Page, Series Details Page і в breadcrumbs;
* назва використовується для пошуку серій.

#### Error messages

```text
Введіть назву серії
Назва серії не може бути довшою за 150 символів
Назва серії не може складатися тільки з пробілів
```

---


### 8.2. Автор

| Parameter   | Value                     |
| ----------- | ------------------------- |
| Label       | Автор                     |
| Placeholder | Вкажіть автора серії      |
| Type        | Autocomplete / text input |
| Required    | Ні                        |
| Min length  | 2 символи, якщо заповнено |
| Max length  | 100 символів              |
| HTML tags   | Заборонено                |

#### Logic

* поле optional;
* автор може бути вибраний зі списку існуючих авторів;
* автор може бути введений вручну;
* якщо автор не вказаний, на картках серії можна показувати автора першої книги;
* якщо немає автора серії і немає книг, поле автора просто не показується в UI;
* зміна автора серії не змінює авторів окремих книг.

#### Error messages

```text
Ім’я автора має містити щонайменше 2 символи
Ім’я автора не може бути довшим за 100 символів
```

### 8.3. Статус серії

| Parameter     | Value                       |
| ------------- | --------------------------- |
| Label         | Статус серії *              |
| Type          | Select / chip single-select |
| Required      | Так                         |
| Default value | `unknown`                   |
| Empty value   | Замінити на `unknown`       |

#### Options

| Value       | Label       | Meaning                                |
| ----------- | ----------- | -------------------------------------- |
| `completed` | Завершена   | серія завершена автором / видавництвом |
| `ongoing`   | Ще виходить | нові книги ще можуть виходити          |
| `unknown`   | Невідомо    | користувач не знає статус серії        |

#### Logic

* користувач може вибрати тільки один статус;
* status required, але може мати default `unknown`;
* status показується на All Series Page і Series Details Page;
* status не означає, що користувач прочитав серію;
* status не змінює reading statuses книг.

#### Error message

```text
Оберіть статус серії
```

### 8.4. Загальна кількість книг

| Parameter       | Value                   |
| --------------- | ----------------------- |
| Label           | Загальна кількість книг |
| Placeholder     | Наприклад, 5            |
| Type            | Number input            |
| Required        | Ні                      |
| Min value       | 1                       |
| Decimal values  | Заборонено              |
| Negative values | Заборонено              |

#### Purpose

`totalBooksCount` потрібний для коректного прогресу серії.

Якщо загальна кількість книг відома, прогрес рахується від неї.

Example:

```text
Прочитано 2 з 5
40%
```

Якщо загальна кількість книг не вказана, прогрес рахується по доданих книгах.

Example:

```text
Прочитано 2 з 4 доданих
50%
```

#### Logic

* поле optional;
* якщо серія ще виходить, поле можна залишити порожнім;
* якщо користувач не знає точну кількість книг, поле можна залишити порожнім;
* якщо значення вказане, воно впливає на progress calculation;
* якщо значення очищене в edit mode, progress починає рахуватися по доданих книгах.

#### Important validation

У edit mode `totalBooksCount` не може бути меншим за кількість книг, які вже додані в серію.

Example:

```text
У серії вже 4 книги.
Користувач не може встановити totalBooksCount = 3.
```

Error message:

```text
Загальна кількість книг не може бути меншою за кількість уже доданих книг у серію
```
