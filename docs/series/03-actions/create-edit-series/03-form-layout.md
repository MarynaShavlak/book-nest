# Create / Edit Series — Form Layout

> Source: `create-edit-series.md`

## 6. Form layout

Create / Edit Series може бути реалізована як modal або окрема форма.

Recommended MVP:

```text
Modal / drawer form
```

Форма має бути компактною і не перевантажувати користувача.

Recommended layout:

```text
[Header]
[Basic information]
[Series status and count]
[Description]
[Genres / tags]
[Cover]
[Actions]
```

---

### 6.1. Modal header

Create mode title:

```text
Створити серію
```

Edit mode title:

```text
Редагувати серію
```

Subtitle для create mode:

```text
Додайте книжковий цикл, щоб відстежувати прогрес і порядок книг.
```

Subtitle для edit mode:

```text
Оновіть інформацію про серію.
```

---

### 6.2. Form actions

Create mode buttons:

```text
Скасувати
Створити серію
```

Edit mode buttons:

```text
Скасувати
Зберегти зміни
```
