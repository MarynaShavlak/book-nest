# Feature: Create / Edit Series

## 1. Purpose

Feature **Create / Edit Series** дозволяє користувачу створювати нові книжкові серії та редагувати вже існуючі серії в BookNest.

Фіча потрібна для того, щоб користувач міг:

* створити серію вручну, навіть якщо книги ще не додані;
* задати базову інформацію про серію;
* вказати статус серії;
* додати загальну кількість книг у серії;
* додати опис, автора, жанри, теги та обкладинку;
* редагувати інформацію про серію після створення;
* підтримувати коректний прогрес серії на All Series Page та Series Details Page.

Create / Edit Series не відповідає за повне керування книгами всередині серії. Додавання, відв’язування або зміна порядку книг описується в окремих feature docs.

---

## 2. Main idea

Серія в BookNest — це окрема сутність, яка групує книги в книжковий цикл.

Серія може існувати у двох станах:

```text
1. Серія з книгами
2. Серія без книг
```

Серія без книг можлива в MVP, тому що користувач може захотіти спочатку створити книжковий цикл, а вже потім поступово додавати до нього книги.

Основна ідея:

```text
Користувач може створити серію вручну або створити її під час додавання книги.
Після створення серія з’являється на All Series Page.
Після редагування оновлюється інформація на All Series Page та Series Details Page.
```

Important:

```text
seriesStatus ≠ user reading progress
```

`seriesStatus` показує статус книжкового циклу:

* Завершена;
* Ще виходить;
* Невідомо.

А прогрес користувача показує, скільки книг із цієї серії користувач прочитав.

Наприклад:

```text
Серія може бути завершена автором, але користувач прочитав тільки 2 з 7 книг.
```

## 3. Entry points

Користувач може створити або редагувати серію з кількох місць застосунку.

### Create Series entry points

| Entry point                                        | Behavior                                               |
| -------------------------------------------------- | ------------------------------------------------------ |
| All Series Page → Header button “Створити серію”   | відкриває Create Series flow                           |
| All Series Page → Right sidebar → “Створити серію” | відкриває Create Series flow                           |
| All Series Page → Empty state → “Створити серію”   | відкриває Create Series flow                           |
| Create Book Form → створити нову серію             | відкриває Create Series flow або inline-create pattern |

### Edit Series entry points

| Entry point                                 | Behavior                         |
| ------------------------------------------- | -------------------------------- |
| Series Details Page → “Редагувати серію”    | відкриває Edit Series flow       |
| Series Details Page → Right sidebar actions | відкриває Edit Series flow       |
| More menu на Series Details Page            | може відкривати Edit Series flow |

## 4. Create mode

Create mode використовується, коли користувач створює нову серію.

### 4.1. Behavior

У create mode:

* форма відкривається з порожніми або default значеннями;
* користувач має заповнити required поля;
* optional поля можна залишити порожніми;
* серія може бути створена без книг;
* після створення серія з’являється на All Series Page;
* якщо серія створена без книг, вона показується як empty series card;
* користувач може пізніше додати книги до серії через Create Book / Edit Book / Add Book to Series flow.

### 4.2. Create mode default values

Recommended defaults:

| Field                   | Default value |
| ----------------------- | ------------- |
| Назва серії             | empty         |
| Автор                   | empty         |
| Статус серії            | `unknown`     |
| Загальна кількість книг | empty         |
| Опис серії              | empty         |
| Обкладинка серії        | empty         |
| Жанри                   | empty         |
| Теги                    | empty         |

### 4.3. After successful create

Після успішного створення:

* серія зберігається;
* Create Series flow закривається;
* користувач бачить success state;
* нова серія з’являється на All Series Page;
* якщо користувач створив серію зі сторінки `/series`, він залишається на `/series`;
* якщо користувач створив серію з Create Book Form, створена серія може автоматично вибратися в полі Series.

Success message:

```text
Серію створено
```

---

## 5. Edit mode

Edit mode використовується, коли користувач редагує вже існуючу серію.

### 5.1. Behavior

У edit mode:

* форма відкривається з поточними значеннями серії;
* користувач може змінити required і optional поля;
* користувач може очистити optional поля;
* редагування серії не видаляє книги з серії;
* редагування серії не змінює reading status книг;
* редагування серії не змінює ownership status книг;
* після збереження оновлюються All Series Page та Series Details Page.

### 5.2. What can be edited

Користувач може редагувати:

* назву серії;
* автора;
* статус серії;
* загальну кількість книг;
* опис серії;
* обкладинку серії;
* жанри;
* теги.

### 5.3. What edit mode does not change

Edit Series не має змінювати:

* список книг у серії;
* порядок книг у серії;
* part number книг;
* reading status книг;
* ownership status книг;
* progress конкретних книг;
* позицію книг у Reading Queue;
* належність книг до Custom Lists.

Ці дії мають бути описані в інших feature docs.

### 5.4. After successful edit

Після успішного редагування:

* форма закривається;
* користувач бачить success state;
* Series Details Page оновлює hero section;
* All Series Page оновлює series card;
* якщо змінено `totalBooksCount`, прогрес серії може перерахуватися;
* якщо змінено cover, оновлюється обкладинка серії;
* якщо змінено title, оновлюється breadcrumb і назва серії.

Success message:

```text
Серію оновлено
```

## 8. Field details

### 8.1. Назва серії

| Parameter         | Value                 |
| ----------------- | --------------------- |
| Label             | Назва серії *         |
| Placeholder       | Введіть назву серії   |
| Type              | Text input            |
| Required          | Так                   |
| Min length        | 1 символ після `trim` |
| Max length        | 150 символів          |
| Empty spaces only | Заборонено            |
| HTML tags         | Заборонено            |

#### Logic

* назва серії є required полем;
* без назви серія не може бути створена;
* у edit mode назву можна змінити;
* після зміни назви вона оновлюється на All Series Page, Series Details Page і в breadcrumbs;
* назва використовується для пошуку серій.

#### Error messages

```text
Введіть назву серії
Назва серії не може бути довшою за 150 символів
Назва серії не може складатися тільки з пробілів
```

---

### 8.2. Автор

| Parameter   | Value                     |
| ----------- | ------------------------- |
| Label       | Автор                     |
| Placeholder | Вкажіть автора серії      |
| Type        | Autocomplete / text input |
| Required    | Ні                        |
| Min length  | 2 символи, якщо заповнено |
| Max length  | 100 символів              |
| HTML tags   | Заборонено                |

#### Logic

* поле optional;
* автор може бути вибраний зі списку існуючих авторів;
* автор може бути введений вручну;
* якщо автор не вказаний, на картках серії можна показувати автора першої книги;
* якщо немає автора серії і немає книг, поле автора просто не показується в UI;
* зміна автора серії не змінює авторів окремих книг.

#### Error messages

```text
Ім’я автора має містити щонайменше 2 символи
Ім’я автора не може бути довшим за 100 символів
```

---

### 8.3. Статус серії

| Parameter     | Value                       |
| ------------- | --------------------------- |
| Label         | Статус серії *              |
| Type          | Select / chip single-select |
| Required      | Так                         |
| Default value | `unknown`                   |
| Empty value   | Замінити на `unknown`       |

#### Options

| Value       | Label       | Meaning                                |
| ----------- | ----------- | -------------------------------------- |
| `completed` | Завершена   | серія завершена автором / видавництвом |
| `ongoing`   | Ще виходить | нові книги ще можуть виходити          |
| `unknown`   | Невідомо    | користувач не знає статус серії        |

#### Logic

* користувач може вибрати тільки один статус;
* status required, але може мати default `unknown`;
* status показується на All Series Page і Series Details Page;
* status не означає, що користувач прочитав серію;
* status не змінює reading statuses книг.

#### Error message

```text
Оберіть статус серії
```

---

### 8.4. Загальна кількість книг

| Parameter       | Value                   |
| --------------- | ----------------------- |
| Label           | Загальна кількість книг |
| Placeholder     | Наприклад, 5            |
| Type            | Number input            |
| Required        | Ні                      |
| Min value       | 1                       |
| Decimal values  | Заборонено              |
| Negative values | Заборонено              |

#### Purpose

`totalBooksCount` потрібний для коректного прогресу серії.

Якщо загальна кількість книг відома, прогрес рахується від неї.

Example:

```text
Прочитано 2 з 5
40%
```

Якщо загальна кількість книг не вказана, прогрес рахується по доданих книгах.

Example:

```text
Прочитано 2 з 4 доданих
50%
```

#### Logic

* поле optional;
* якщо серія ще виходить, поле можна залишити порожнім;
* якщо користувач не знає точну кількість книг, поле можна залишити порожнім;
* якщо значення вказане, воно впливає на progress calculation;
* якщо значення очищене в edit mode, progress починає рахуватися по доданих книгах.

#### Important validation

У edit mode `totalBooksCount` не може бути меншим за кількість книг, які вже додані в серію.

Example:

```text
У серії вже 4 книги.
Користувач не може встановити totalBooksCount = 3.
```

Error message:

```text
Загальна кількість книг не може бути меншою за кількість уже доданих книг у серію
```

### 8.7. Теги

| Parameter    | Value                    |
| ------------ | ------------------------ |

| Parameter | Value                       |
| --------- | --------------------------- |
| Label     | Обкладинка серії            |

| Required  | Ні                          |

#### Logic

* поле optional;

* якщо в серії немає книг або обкладинки першої книги немає, показується placeholder;
* у edit mode користувач може замінити або прибрати custom cover.

#### Missing cover behavior

```text
custom cover → показати custom cover

```

## 9. Validation rules

### 9.1. Required fields

Required поля:

```text
Назва серії
Статус серії
```

Якщо required поля не заповнені, серія не створюється і не оновлюється.

---

### 9.2. Text normalization

Перед submit потрібно нормалізувати текстові поля:

```text
title = title.trim()
author = author?.trim() || null
description = description?.trim() || null
tags = tags.map(tag => tag.trim())
```

Якщо optional поле після `trim` стало порожнім, його потрібно зберігати як empty / null.

---

### 9.3. HTML validation

HTML-теги заборонені в текстових полях:

* назва серії;
* автор;
* опис;
* custom tags.

---

### 9.4. Duplicate title check

При створенні або редагуванні потрібно перевіряти, чи вже існує серія з такою самою normalized назвою в межах користувача.

Duplicate check має бути:

* case-insensitive;
* після `trim`;
* з урахуванням зайвих пробілів.

Example duplicates:

```text
Throne of Glass
throne of glass
Throne   of   Glass
```

#### MVP behavior

У MVP краще не блокувати створення повністю, а показувати warning.

Warning:

```text
Серія з такою назвою вже існує
```

Користувач може:

* скасувати створення;
* перейти до існуючої серії;
* все одно створити нову серію, якщо це справді інша серія.

---

### 9.5. Total books count validation

Rules:

* значення має бути цілим числом;
* значення має бути більше або дорівнювати 1;
* значення не може бути меншим за кількість книг, уже доданих у серію;
* поле може бути порожнім.

Error messages:

```text
Введіть ціле число
Кількість книг має бути більшою за 0
Загальна кількість книг не може бути меншою за кількість уже доданих книг у серію
```

---

## 10. Actions

### 10.1. Create series

Користувач може створити нову серію.

Behavior:

1. Користувач відкриває Create Series flow.
2. Заповнює required поля.
3. Опційно заповнює додаткові поля.
4. Натискає **Створити серію**.
5. Система перевіряє validation rules.
6. Якщо є помилки, користувач бачить validation errors.
7. Якщо є potential duplicate, користувач бачить warning.
8. Якщо дані валідні, серія створюється.
9. Серія з’являється на All Series Page.
10. Якщо серія створена без книг, вона показується як empty series.

---

### 10.2. Edit series

Користувач може редагувати існуючу серію.

Behavior:

1. Користувач відкриває Edit Series flow.
2. Форма заповнюється поточними даними серії.
3. Користувач змінює потрібні поля.
4. Натискає **Зберегти зміни**.
5. Система перевіряє validation rules.
6. Якщо є помилки, користувач бачить validation errors.
7. Якщо дані валідні, серія оновлюється.
8. Series Details Page і All Series Page показують оновлену інформацію.

---

### 10.3. Cancel create / edit

Користувач може скасувати створення або редагування.

Behavior:

* якщо користувач не змінював поля, flow закривається одразу;
* якщо є незбережені зміни, можна показати confirmation;
* після cancel зміни не зберігаються.

Confirmation text:

```text
Закрити без збереження?
Внесені зміни буде втрачено.
```

Actions:

```text
Продовжити редагування
Закрити
```

---

### 10.4. Remove custom cover

У edit mode користувач може прибрати custom cover.

Behavior:

* custom cover видаляється з серії;
* після збереження серія використовує fallback cover;
* fallback cover — це обкладинка першої книги або placeholder.

* loading indicator.

## 12. What is not included

У MVP для **Create / Edit Series** не входить:

* видалення серії;
* merge duplicate series;
* автоматичне підтягування інформації про серію з інтернету;
* автоматичне визначення всіх книг серії;
* додавання книг до серії всередині цієї форми;
* відв’язування книг від серії;
* зміна part number книг;
* drag-and-drop порядку книг;
* складний reading order для спін-офів;
* типи книг у серії: основна, новела, спін-оф, бонус;
* спойлерні нотатки по серії;
* персонажі серії;
* рекомендації схожих серій.

Important:

```text
Create / Edit Series відповідає тільки за поля самої серії.
Керування книгами всередині серії описується окремо.
```

## 13. Acceptance Criteria

### Create mode

* Користувач може відкрити Create Series flow з All Series Page.
* Користувач може відкрити Create Series flow з empty state.
* Користувач може створити серію вручну.
* Користувач може створити серію без книг.
* Після створення серія з’являється на All Series Page.
* Якщо серія створена без книг, вона показується як empty series.
* Якщо Create Series flow відкритий з Create Book Form, створена серія може бути автоматично вибрана у формі книги.

### Edit mode

* Користувач може відкрити Edit Series flow з Series Details Page.
* Форма редагування відкривається з поточними даними серії.
* Користувач може змінити назву серії.
* Користувач може змінити автора серії.
* Користувач може змінити статус серії.
* Користувач може змінити загальну кількість книг.
* Користувач може змінити опис серії.
* Користувач може змінити жанри або теги серії.
* Користувач може змінити або прибрати custom cover.
* Після збереження оновлена інформація показується на Series Details Page.
* Після збереження оновлена інформація показується на All Series Page.

### Required fields

* Назва серії є required.
* Статус серії є required.
* Якщо required поля не заповнені, серія не створюється і не оновлюється.
* Користувач бачить validation errors для required полів.

### Series status

* Користувач може вибрати тільки один статус серії.
* Доступні статуси: Завершена, Ще виходить, Невідомо.
* Default status у create mode — Невідомо.
* Статус серії не змінює reading statuses книг.
* Статус серії не означає, що користувач прочитав серію.

### Total books count

* Поле загальної кількості книг optional.
* Якщо поле заповнене, значення має бути цілим числом.
* Значення має бути більше або дорівнювати 1.
* Значення не може бути меншим за кількість книг, уже доданих у серію.
* Якщо поле очищене, прогрес серії рахується по доданих книгах.

### Duplicate check

* При створенні серії система перевіряє potential duplicate title.
* Duplicate check виконується в межах поточного користувача.
* Duplicate check є case-insensitive.
* Якщо знайдено potential duplicate, користувач бачить warning.
* Користувач може перейти до існуючої серії або створити нову серію все одно.

### Cover

* Користувач може додати custom cover серії.
* Користувач може змінити custom cover.
* Користувач може прибрати custom cover.
* Якщо custom cover немає, використовується обкладинка першої книги.
* Якщо обкладинки першої книги немає, показується placeholder.

### Cancel and unsaved changes

* Користувач може скасувати створення серії.
* Користувач може скасувати редагування серії.
* Якщо є незбережені зміни, користувач бачить confirmation.
* Якщо користувач підтверджує закриття, зміни не зберігаються.

### Scope

* Create / Edit Series відповідає тільки за створення та редагування даних серії.
* Create / Edit Series не видаляє книги з серії.
* Create / Edit Series не змінює порядок книг у серії.
* Create / Edit Series не змінює part number книг.
* Create / Edit Series не змінює reading status книг.
* Create / Edit Series не змінює ownership status книг.
* Delete Series описується окремою feature documentation.
* Add Book to Series описується окремою feature documentation.
