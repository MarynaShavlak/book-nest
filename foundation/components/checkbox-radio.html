Checkbox & Radio

Вибір у формах: Checkbox — кілька незалежних опцій (або одна згода), Radio — один варіант із групи. Обидва на нативних <input>: працюють без JS, у формах і з клавіатури. Позначене — --primary.

Коли що

Checkbox
кілька незалежних опцій або одна згода (фільтри, «прийняти умови»)
Radio
рівно один варіант із 2+ (тип обкладинки, статус) — коли всі варіанти варто бачити
vs Segmented
2–4 короткі варіанти в один рядок → Segmented; довший список з описами → Radio
vs Toggle
увімк/вимк налаштування з миттєвою дією → Toggle, не Checkbox
Семантика
нативні input: Space/стрілки, групам — спільний name; без тексту — aria-label
