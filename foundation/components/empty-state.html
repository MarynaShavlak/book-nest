Бібліотека компонентів EmptyState

EmptyState

Єдиний компонент порожнього стану: ілюстрація → заголовок → опис → дії → опц. чипи/підказка. Усі 16 сценаріїв описані в конфізі EMPTY_STATES.

16 сценаріїв3 розміриconfig-drivendark-ready плашка

Анатомія

Плашка з ілюстрацією тримає світлий фон і в темній темі (читається як рамка-картина, а не світла пляма).

  • Ілюстрація — у плашці, відносний шлях illustrations/<id>.png
  • Заголовок — serif, коротко й по суті
  • Опис — 1–2 рядки, що зробити далі
  • Primary — головна дія
  • Secondary — альтернативна дія (опц.)
  • Чипи-підказки — переваги/приклади (опц.)
  • Tip-банер — мʼяка порада (опц.)
  • Спецблоки — 404 (швидколінки), offline (доступне офлайн + дії)

Розміри

Один компонент, три контексти: lg — повна сторінка, md — у картці-віджеті, sm — у списку.

lg · сторінка
md · картка
sm · список

Сценарії

Прев'ю керується конфігом. Обери сценарій нижче — 404, offline і «помилка» рендеряться зі своїми додатковими блоками.

Як це працює

Компонент бере запис із EMPTY_STATES і підставляє ілюстрацію за id:

import { EMPTY_STATES } from './empty-states.js';
const s = EMPTY_STATES['library'];
<img src={`illustrations/${s.illu}.png`} alt={s.title} />   // у плашці
<h3>{s.title}</h3> <p>{s.desc}</p>
<button class="btn">{s.primary.label}</button>
{s.secondary && <button class="btn ghost">{s.secondary.label}</button>}
