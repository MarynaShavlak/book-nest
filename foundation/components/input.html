Інпут

Текстове поле в усіх станах і варіантах, побудоване на токенах. Базова геометрія збігається з полем зі сторінки «Додати книгу»: фон --field, бордер --border, радіус --radius (12px). Перемкни тему вгорі, щоб побачити все в темному режимі.

Стани

Стани зафіксовано примусово, щоб бачити їх поруч. Наприкінці є інтерактивний майданчик.

Default
Спокій: бордер --border, фон --field, плейсхолдер --muted.
Hover
Курсор наведено: бордер темнішає до --accent-border (персиковий).
Focus / Active
У фокусі: бордер --primary + кільце 0 0 0 3px var(--focus-ring).
Filled
Заповнене: текст значення кольором --text.
Error
Невірний формат e-mail
Помилка: бордер --danger, повідомлення + кільце фокуса в --danger.
Disabled
Вимкнено: фон --surface-alt, текст --muted, opacity .6, курсор not-allowed.
Success
Нікнейм вільний
Валідне (бонус): бордер --success + підтвердження.
Helper text

Надішлемо лист для підтвердження

Мінімум 8 символів

Підказка під полем: --muted, --fs-xs. Інфо-іконка зліва — опційна. На помилці/успіху ховається й заміняється повідомленням.

Варіанти

Слоти для іконок ліворуч і праворуч, префікс/суфікс одиниці, селект, текстова область, пароль, пошук.

Без іконки
Як прості поля на «Додати книгу».
Іконка зліва
Як на екранах входу/реєстрації.
Іконка справа
Службова іконка-афорданс (видавництво/мова/рейтинг).
Селект
Нативний select + шеврон праворуч.
Текстова область
Без спойлерів0/500
Лічильник символів справа.
Пароль
Іконка зліва + перемикач показу праворуч.
Пошук
Поле пошуку з лупою.
Суфікс одиниці
грн
Текстовий суфікс із роздільником (грн, стор., шт.).
Суфікс «/ 320»
/ 320
Інлайн-суфікс без роздільника — як у модалці «Оновити прогрес».
Префікс
₴
Префікс зліва з роздільником (валюта, протокол тощо).

Типи вводу

Поля з обмеженням вводу та правильною клавіатурою на мобільному — кожне зі своєю іконкою.

E-mail
type="email" + inputmode="email" · іконка i-mail.
Телефон
type="tel" + inputmode="tel" · іконка i-phone.
Посилання
type="url" + inputmode="url" · іконка i-link.
Число
type="number" + inputmode="numeric" · іконка i-hash. Для «− N +» — NumberStepper.

Анатомія

Що саме змінюється в кожному стані.

Базове
фон --field · бордер 1px --border · радіус --radius · текст --text · паддінг 12/14 (іконка → 42)
Hover
бордер → --accent-border
Focus
бордер → --primary + box-shadow 0 0 0 3px var(--focus-ring)
Error
бордер → --danger · повідомлення --danger · кільце фокуса в --danger
Success
бордер → --success · підтвердження --success
Helper
підказка під полем: --muted, --fs-xs · опційна інфо-іконка зліва · ховається на error/success
Disabled
фон --surface-alt · текст --muted · opacity .6 · cursor not-allowed
